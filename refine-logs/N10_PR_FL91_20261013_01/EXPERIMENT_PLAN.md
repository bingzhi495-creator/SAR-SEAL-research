# N10：直接先例结构对照的执行计划

日期：2026-10-13。本文是预登记计划，不包含新训练结果；当前作业状态见同目录实验追踪表。总目标保持：形成有明确先例差异、公平效用、重复及跨集证据支持的核心创新。

## 主张与竞争解释

本阶段仅检验一个候选：在冻结 E24 的相同表征、采样、监督和固定原生评分下，已有 C 的结构组合是否仍优于普通粗掩膜条件共享点头。竞争解释是常规点精修与近似容量即可解释现有收益。C 显式读取 e，PR 不额外拼接 e，但 L 已包含 e·F，因此不是“无实例条件”对照，也不单独隔离 e 的因果作用。

N09 已核验：原生 AP 67.0710566，FIT-only 全局偏移 67.1466401，C 历史两种子均值 68.1661355；只排除了该全局偏移近似替代 C，不构成新颖性证明。旧 A/B 首24+追加48的 NO_GO 保持，不重启旧种子2/3。

## 锁定的数据与训练

- 复用独立 CPU 合格的冻结 E24 缓存；FIT 741 图、1,661 原始 GT。每 GT 1,024 点：768 原生带内点与256均匀点，有放回、跨轮固定，沿用旧空带规则和一对一教师分配。
- 两个下游种子固定为 202610120701、202610120702，共享原生初始化来源。同一私有图像顺序生成器每种子生成顺序供两臂共用，图内保持原 GT 顺序。不同形状网络不能称逐权重相同初始化；C 工厂与历史 exact 路径保留，PR 使用同种子和原生恒等冷启动。
- 两臂均固定8轮，每模型13,288次 instance-mean BCE/AdamW 更新。lr=3e−4，weight_decay=1e−4，betas=(0.9,0.999)，eps=1e−8，恒定学习率，无累积、额外增强或梯度裁剪。每轮重算全1,661实例点BCE，仅作为训练诊断；本轮不自动延长。
- C 使用旧 562→64→64→1 头，49个patch通道恒零，40,257总参数。PR-FL-91 使用 LN(F256)/clamp(L)/8；257→91，后两层及输出层重新拼接 coarse L，三隐藏层，40,497参数、40,223单点 Linear MAC。C dense Linear MAC为40,128。此匹配不证明等效函数类或优化难度。
- 完全冻结教师；不更新骨干、像素解码器、query、类别与最终mask embedding，不新增teacher前向。只在原生原图 |L|≤2 内施加残差；带外原生保持不变。

## 固定评价与独立核验

评价保留历史 DEV187 图、380个原始 GT 和每图全部100 query、原生类别/S0/顺序及空掩膜；原生输出必须先精确复现强 E24 参考。无 NMS、分数筛选、GT选择或阈值扫描。使用官方 COCO segm/maxDets=[1,10,100]、AP/AP75/AR及可计算尺度指标。

训练资格核查权重来源、完整参数/AdamW状态、每模型实际更新计数、相同图像顺序和固定轮次；CPU 独立重建 PR 公式并核查完整FIT末轮BCE，不调用训练头 forward。该端点核查不是完整优化轨迹重放。

像素分析分别保留官方重新匹配及原生固定 query–GT 配对，检查 FP/FN、面积和相同query IoU。图像统计不能替代训练种子波动。CPU practical误差容差沿用已资格规则，不宣称CUDA位级重放或认证误差界。

## 结果前锁定的下一步规则

若两个配对种子的 C−PR 均为正且均值至少 +0.30 AP 百分点，视为值得进一步研究的结构候选；随后另行预登记两臂公平固定24轮及至少第三下游种子，再判断充分训练表现。+0.30是计算投入优先级规则，不是统计显著性、发表或最终效用门槛，不替代总目标。

未满足条件时保留全部结果，停止将当前结构组合优先扩张为已成立贡献，转向经实际误差支持的特征/机制问题。若 PR 接近或优于 C，只能说普通点头在当前8轮预算中能解释效用，不能宣称 C 在所有预算下无效。两臂均未收敛而机制仍有明确独立依据时，可另行事前登记公平充分训练检验；不得据 DEV 事后只延长有利一臂。

实现或资格失败必须修复具体错误并使用新 SOURCE/新阶段，原失败保留，不赋一个低 AP。观察超时只复查原活作业，不自动重启。

## 顺序、成本及资源

先新头 CPU 资格，再四模型固定训练，再独立端点资格及固定DEV评价/独立复核。科学执行只由 ROOT 所有。文献与未绑定SOURCE独立审阅可以并行，不能并行读取活作业绑定载荷。

历史 N07 四头8轮实际训练约672秒，仅供估算。新结构预计相近至约2倍，首次作业上限仍14,400秒，不承诺实际完成时间。头资格上限600秒；独立端点资格及DEV/复核分别在新阶段预登记有限上限。复用缓存而不重复教师前向，初始教师/缓存成本另列。

保持CPU01/线程2、分配器4,096MiB、整卡观测8,192MiB、可用RAM至少16GiB、磁盘至少20GiB，隐藏窗口启动。实际墙钟、显存观测和各阶段成本均按真实回执报告；静态MAC不替代时延。

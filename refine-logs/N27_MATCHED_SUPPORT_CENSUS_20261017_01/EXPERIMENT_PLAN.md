# N27：真实匹配实例的固定精修支持范围诊断

2026-10-17。状态：预先设计，尚未数值执行。N26 的三个固定质量头种子均已完成实际训练/评价与 Root 接收，平均 mask AP 为69.53736694，相对固定强 R 增加1.43798199点。其掩膜完全不变；该结果支持排序效用，尚未解决轮廓或证明核心创新。本轮不重新训练或调参 N26，不重开 N20/N23 已停止配方。

本轮只问一个问题：在已有 R 的真实训练匹配实例中，把所有允许写入的 Ω 像素都用 GT 完美纠正后，固定 Ω 外的错误是否仍阻止达到高 IoU？这会给“当前写入范围限制了进一步精修”的解释提供可测依据；不预设 Ω 外错误占主导，也不把大绝对 logit 当作已校准置信概率。

## 人口与输入

- 主人口为原 FIT 的741图、1661个冻结真实 matcher 配对。沿原 image/query/GT 身份与顺序，只纳入 raw_GT_index_by_query>=0；不把未匹配或忽略 query 伪标背景，不改匹配、不选择更高 IoU 的 GT。
- 只用已经捕获和接受的原图 CPU FP32 native_L、原 packet 的匹配和 K_counts_all100、N26 完整 R 的 AUDIT RLE、原 FIT 实例 GT。N26 合并特征、质量头权重与分数不参与本诊断。
- DEV/TEST 都不读取。本轮不提供推理性能、AP 或跨集结论。未来若检查 DEV，必须另锁真实配对或明确 GT oracle 的候选选择规则，不能将其与本轮人口混合。
- 原 L 的自然 query 索引与 image/query 身份保持一致。逐配对核原形状、native/R/GT 的已记录摘要，当前 R IoU 须逐位恢复 N26 的 FP64 目标；实际完整 Ω 的计数须恢复原 K。

## 冻结计算

P = native_L > 0；Ω = abs(native_L) <= FP32(2)。不得使用旧4096点抽样标签近似完整支持。验证 R 在 Ω 外逐像素等于 P，否则停止并保留原任务失败记录，不得继续解释为支持范围效应。

逐实例分别统计原生 P 和 R 的 TP/FP/FN，以及 FP/FN 在 Ω 内外的数量。对 R 记录域外错误占总错误的比例；总错误为0的实例记未定义并另计，不能伪填0后混入均值。聚合报告像素总量比例、非零错误实例的中位数及计数、空预测/K0，并保留当前 IoU 档位，避免少数大目标支配唯一判断。

只作不可部署的 GT 诊断：Ω 内设为 GT，Ω 外保持 R。设 GT 面积为 G，Ω 外的 FP/FN 分别为 FPo/FNo，则该固定实例/支持条件下的最优二值 IoU 为 (G-FNo)/(G+FPo)。同时直接构造这个诊断掩膜，以完整交并计数核对公式。非空 GT 使分母严格为正。

该量只约束同一个真实匹配实例在固定写入范围内的掩膜；不称 AP 上界，不证明当前网络能够达到它，也不排除换 query、扩大支持或重训载体的作用。

预先报告全部 IoU 阈值0.50、0.55、0.60、0.65、0.70、0.75、0.80、0.85、0.90、0.95。主要关注0.90/0.95：当前达标数、诊断完美纠错后达标数、仍受域外错误阻挡数。全部1661实例保留，不按结果删除不利样本或只报改善档位。

## 解释与后续约束

若域外错误为零，或在关注阈值下全部当前未达标实例均可由 Ω 内纠错达到，则不支持将扩大写入范围作为当前主要解释。若存在无法消除的域外错误，报告其实际频率、幅度和 IoU 档位；“存在约束”与“它是主要瓶颈”必须分开判断，不能由少数例子外推全域。

只有该诊断及真实错误分布支持，才继续将用户自设计的跨尺度传输/细节保留路由作为单一结构假设；两臂共用相同的真实实例读出与可写区域，并保持同预算，不能把新增可写区域本身误归给门控。若两臂仍只允许改 Ω，就不能声称检验了修复域外错误的机制。

该阶段不执行新的结构训练，不补核心创新数，不宣称可投稿。先得到完整诊断，再锁后续最小公平对照。N26 的质量排序收益必须作为已知强替代保留，不能在后续论文中当成新结构的几何收益。

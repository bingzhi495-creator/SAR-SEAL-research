# 下一研究批次：监督机制诊断与有限公平检验

## 目标与边界

## N02 有限四臂方案

所有臂从同一个合格 E24 开始，不加残差头、不换采样坐标、不改评分规则。固定 8 轮端点，每臂两个下游种子，共最多 64 个单臂轮次。不能把旧 A 的 E96 端点代替本批 U 的 E32。

| 臂 | 训练配方 | 控制的解释 |
| --- | --- | --- |
| N | 原生损失续训 | 阶段/原生续训本身造成退化 |
| U | N + 当前 λ=1 均匀点 BCE | 当前额外监督的效果 |
| S | N + c×均匀点 BCE | 仅改变全局强度是否足够 |
| R | N + c×类别平衡 BCE | 类别配比是否具有额外作用 |

类别平衡使用相同点坐标，对匹配实例归一化：
Lbal = -sum(y log p)/(2 max(sum(y),1))
       -sum((1-y) log(1-p))/(2 max(sum(1-y),1))。

保持实例间归一化一致；没有前景采样时记录事实，不补采样后声称只改权重。类别平衡是常规诊断干预，不是新贡献。

系数 c 只用固定 FIT 初始梯度诊断校准一次，使 R 与 U 的辅助参数梯度范数大致匹配，随后冻结；S 用同一个 c。不用 DEV AP 选择 c。具体校准汇总、参数块和零梯度处理在 N02 SPEC 前冻结。初始范数匹配不能消除后续 AdamW、裁剪及训练轨迹差异，限制须保留。

每个种子内各臂的图像顺序、原生损失随机过程、点坐标、精度、优化器重建、学习率日程、图像访问/更新预算和评价规则可比。下游种子、随机流分离及每臂恢复初始状态的实际实现必须在运行前验证；这里不声称已完成。全部臂与全部种子一起报告，不因第一种子较好而跳过第二种子。

主效用指标：固定 native official 规则下的 COCO mask AP；辅以 AP75。几何诊断使用事先确定的一对一匹配和尺度分组，面积分组边界来自 FIT；保留未匹配 GT，不能仅报告容易实例。原有可复用 query 的 best100 单列辅助诊断，不能当作一对一召回。

## 预先约束结果解释

1. N 稳定、U 退化且 R 在两个种子均优于 U 与 S，并支持预锁几何预测，才支持类别配比解释。
2. N 与 U 类似退化，优先接受续训/优化竞争解释；不继续用类别配比作既成结论。
3. S 足以解释 R 的收益，优先接受全局强度解释。
4. 仅训练损失好转、或 AP 收益仅来自分数变化，撤回几何改善解释。
5. R 只恢复 E24 水平：报告有用的监督配方修正，核心创新仍未成立。
6. 若考虑继续充分预算，以 R 相对同预算 N 与强 E24 中较高者的效用和两种子一致性为依据；实用阈值须在 N02 执行前明确锁定。既有 1 AP 百分点可作为候选筛选阈值，不是期刊标准。
7. 短批次负结果只否定当前预算/配方下的预测；若后续主张依赖充分训练，必须给方法和强对照合理的充分预算及收敛证据，不能用短训总体否定方法。

## 方法决定

1. 优先检验真实原JPEG细局部信息能否改善固定强E24的高IoU几何。现有F256/e256/M200经bilinear放大不产生新增高频信息；需要共享载体与容量控制，固定query/S0分数，确认收益超出普通点精修。
2. 不将法向位移命名为新创新：[SharpContour](https://xyzhang17.github.io/SharpContour/)已有从粗掩膜沿法向预测方向/步长/步数的直接先例；[PointRend](https://openaccess.thecvf.com/content_CVPR_2020/html/Kirillov_PointRend_Image_Segmentation_As_Rendering_CVPR_2020_paper.html)已有不确定点与细边界精修。新原语组合或SAR适配仍需证明具体差异。
3. 先补一个便宜强简单控制：唯一预锁IoU0.80的mask greedy NMS，仅移除候选，保留原分数与几何。它不能作为创新，但若有效将成为必须面对的强参考。

下一有限训练设计为同一冻结E24、同一采样/标签/容量下比较F/e点精修与增加真实7x7原图patch的点精修。该设计检验信息可用性，尚不代表论文核心机制或新颖性成立。SOURCE正在实现，缓存/训练/评价均未科学运行。标注离散化、表示能力和普通阈值/精修解释继续保留，不推断散射物理。

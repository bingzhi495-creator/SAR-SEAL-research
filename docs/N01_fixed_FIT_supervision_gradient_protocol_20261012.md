# N01 固定 FIT 监督/梯度诊断预锁协议（2026-10-12）

任务定位：检验合格 E24 初始点的局部监督配比与方向关系，决定是否值得有限四臂跟进。没有优化器、权重更新、DEV/TEST/AP；本实验不能证明已经产生有害训练漂移、不能作为新核心创新。

固定输入：现有合格 native0 E24 与原始 FIT741/1661。数据索引用 Python 标准库 random.Random(2026101201).sample(range(741),32) 一次选择，并把索引、图像ID和实际文件引用写入不可变 SPEC。原图点种子基数2026101203000，原生损失种子基数2026101204000，每个位置加其0..31序号。每个匹配GT12544点、有放回；不根据面积、损失或诊断结果挑图。

一次原生 model.loss、十阶段当前匹配、原有30损失；复用同一图、最后阶段匹配和点坐标。新增原图监督从 bool GT 整数索引取得，是硬标签。另通过原生 loss_mask 被动钩子记录十阶段实际点标签的软/硬质量，不能混称同一种标签。

使用原图硬点 BCE 前景/背景分解 U=U+ + U-，并记录逐GT输出梯度质量 G+=mean[y(1-p)]、G-=mean[(1-y)p]。类别平衡 R 使用现有任务书的实例内正/负分别归一化，仅为诊断干预。

同一图分别 backward native_total、U+、U-、R；前三次保留图。首图额外原始U backward，核对 U 梯度与分量梯度之和。每次清所有参数grad和retain_grad的F/e/M；保留原生backbone checkpointing、FP32、TF32关闭、typed BN冻结。不用全参数autograd.grad替代既有checkpoint路径。

梯度主范围：mask_embed六个张量与pixel_decoder.mask_feature两个张量，共八个不重复参数张量。只有这八个参数可合并求范数/夹角，不能宣称代表全native345。F256、e0、M200分别报告，不将链上的三个节点合并。观察所有native参数的梯度有限性不等于独立CPU重放完整反向。

固定候选门槛（探索性分配规则，不是统计显著性或期刊门槛）：32图中有效非零主梯度至少24；U与native主参数梯度夹角cos<0至少20图；R的cos比U更高至少20图；U-cos中位数<0；R-cos减U-cos的配对中位数至少0.10。满足且CPU资格通过，才值得进一步锁定N/U/S/R有限训练；不把本门槛写成因果证明。

FIT初始范数校准候选c为有效图的 norm(U八参数)/norm(R八参数) 比值的中位数，分母下限1e-12。该c只在本测量范围有效；不得声称匹配全模型梯度或后续AdamW轨迹。这里输出c，不执行训练、不用DEV选择c。

完整保存32图的点logits/硬标签/索引与八参数梯度，前五图额外保存M200、原始GT、局部M梯度和十阶段原生点标签，供后续独立CPU数值核验。首图U线性检查rtol1e-3/atol1e-7；后续CPU原图投影/局部VJP沿用forward rtol1e-4/atol1e-4、gradient rtol1e-3/atol1e-7。CPU资格范围明确，不宣称原生30损失或全native反向重放。

全native610权重和缓冲必须与输入E24完全一致。32图全部完成后再判定，保存所有结果；资源/执行失败单列，单次所有者、无自动重试。CPU0/1、线程2、本机CUDA0、allocator4096 MiB、whole-GPU观测上限8192 MiB、诊断deadline1800s。前五图记录真实耗时，完成同一32图，不改样本。

SOURCE和SPEC本身不证明运行成功。必须实际终止0，先检查本次和全部祖先RAW，再核对来源与产物，完成CPU资格后解释结果。门槛未过只说明局部诊断不支持当前类别平衡跟进，不证明所有监督设计失效；转向仍需新的真实误差证据。

# HRSID 划分来源与外部证据范围

日期：2026-10-12。范围仅为原论文正文与作者公开说明/仓库树元数据；没有下载或读取影像、实例标注、权重，也没有运行新的科学实验。当前 A/B 配方、端点与继续规则保持不变。

## 有限核查结论

所读公开材料不能证明官方 train/test 按原始父场景或地理来源隔离；也不能证明已经发生跨侧重叠。后续可以保留官方切片级评价，但不得直接把它写成独立父场景泛化。

## 已读证据

- [原论文全文镜像](https://www.researchgate.net/publication/342541002_HRSID_A_High-Resolution_SAR_Images_Dataset_for_Ship_Detection_and_Instance_Segmentation)，IEEE Access，DOI 10.1109/ACCESS.2020.3005861：II.A（p.120237）描述 800×800 窗与 600 像素步长；摘要写 25% 重叠，正文另写 20%。按窗口/步长计算的单轴相邻重叠为 25%，不能把两处文字当作完全一致。
- 同文 II.B–C（p.120238–120240）描述先在大图标注再裁切，报告 65%/35% 的图像划分，未在所读段落说明父场景隔离。Table2 的 serial number 成像参数分组不等于地理或父场景划分。
- [固定作者 README](https://raw.githubusercontent.com/chaozhong2010/HRSID/2d682fe0c023df03a8fe1b1bf2e2ac76811e43b5/README.md)展示 P0094 等前缀与坐标形态的样例文件名；其完整映射语义未定义，不能只据前缀断言原始采集身份。
- [固定仓库树](https://api.github.com/repos/chaozhong2010/HRSID/git/trees/2d682fe0c023df03a8fe1b1bf2e2ac76811e43b5?recursive=1)：ROOT 实际取得非截断的 20 条元数据。所列文件未包含显式 test split 或父场景映射脚本。仅检查目录元数据，未读取 annotations/train2017.json；不能由此推出下载档案内不存在额外映射或划分材料。
- [data/readme.txt](https://raw.githubusercontent.com/chaozhong2010/HRSID/2d682fe0c023df03a8fe1b1bf2e2ac76811e43b5/data/readme.txt)仍为 ISSID 说明，数量与仓库主 README 不同。它不是当前 HRSID 实际数据清单；未来实验的数据身份必须来自实际档案与转换结果，不能据旧说明填入计数。

## 对后续评价的实际约束

1. 官方切片级测试与按父场景/地理隔离的测试是不同协议。未知隔离状态不使官方测试自动失效，但限制泛化主张。
2. 在称作本模型的外部零调参评价前，核验本模型全部训练/预训练来源及项目历史选型记录。不得仅因数据集名字不同就认定未见数据；既有测试选型历史继续披露。
3. 若要主张未见父场景泛化，先取得可验证的采集/父图映射与切片位置，再锁定分组留出协议、预算和强对照，保留官方结果并分别报告。不能根据外部结果挑选新 split。
4. 后续实际数据核查应区分完全重复、同父图空间重叠、同场景非重叠及来源未知。命名前缀只能在映射核验后用于归组；无法核验时明确未知，不生成虚假的独立性证明。

当前训练结束、实际产物合格并得到固定主结果后，仍按既有合同决定是否推进重复/机制实验。正式或外部评价启动前，才依据实际档案核验数据身份、模型来源和历史使用，并事前冻结外部主路线。本次有限核查不启动跨集评价，不新增数据集搜索或模块分支。

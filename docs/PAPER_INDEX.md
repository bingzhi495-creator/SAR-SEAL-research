# 论文版本索引与阅读边界

更新：2026-10-12。本仓库保留研究过程中的不同论文主线。现有稿件均为内部工作稿或历史档案，没有一个入口已经成为当前研究的投稿定稿。文件名中的 `tgrs`、`submit` 或 `main` 不表示已完成投稿审查。

## 建议阅读顺序

先读仓库 README 的当前进展和研究目标，再读本索引及 [论文源码审阅](paper_review_20261011.md)。当前实验的有效范围由最新实际结果与固定协议决定；旧稿中的结果、显著性、机制解释和期刊定位不能自动继承到当前方法。

## 当前研究与旧稿的关系

2026-10-12 的固定 8 轮点精修控制已经在普通研究记录中报告：同一强 E24 初始化下，粗特征点头 C 的两个下游种子有开发集收益；加入真实 JPEG 7×7 patch 的 R 与 C 几乎持平，未满足预先锁定的 patch 跟进条件。该证据支持保存当前配方的开发集效用，不支持新增 patch 机制、统计显著性、正式 TEST、跨集收益或 SOTA。当前 FIT 全局 logit 偏移属于简单替代解释控制，不能改名为新的算法贡献。

现有论文入口没有把这条最新链条写成与证据一致的完整方法、实验和讨论。需要在核心创新及验证范围成立后，选定一条主线重新组织正文，而不是把历史稿标题直接改成最新模型名。

## PDF、图件和编译

本机存在 `paper/seal.pdf`、`paper/tgrs.pdf`、`paper_tgrs/main.pdf`、`paper_tgrs/main_submit.pdf` 以及独立修订目录的 `main.pdf`、`supplement.pdf` 等历史产物。是否随本次仓库发布，以实际文件清单为准；仅存在 PDF 不证明它对应当前 `.tex`，本次索引没有重新编译、验证 PDF 内容或重核其结果。

早期稿依赖 `paper/figs/`，融合稿依赖 `paper_tgrs/figs/`；独立修订稿依赖自己的 `figs/`。图件包括概念示意、统计图和真实 SAR/标注/预测样例，后者涉及原始数据的再分发条件。只有 `.tex/.bib` 清单不能保证离线编译，IEEEtran 和相应 TeX 包也需另行安装。历史改稿脚本不是科学复现入口。

## 作者信息与结论边界

保留原有作者、单位、日期和其他未定元数据；不补造机构、会员身份、资助或通讯作者信息。修订稿的两位作者次序是当时的暂定信息，不等于最终作者名单。占位符仍需由作者提供正式内容。

本索引依据普通论文源码、既有源码审阅和文件元数据整理，没有读取科学 RAW、SPEC、资格记录、权重或结果载荷，也没有执行训练或评价。它是版本导航，不是实验完整性认证、引用真实性认证或 TGRS 投稿就绪声明。

% fig1_framework.pdf — Section III overview: the three-rung cascade, plus a
% to-scale expansion of the frozen Stage-A base underneath it.
% Stage A  : frozen COCO-init Mask2Former-R50 (lock glyph), 3 seeds.
% Stage B  : rung 1 training-free (soup / wide TTA / consensus fusion),
%            rungs 2-3 optional trained correctors on disjoint write fields
%            (BPR -> mask pixels only, re-ranker -> score field only).
% Band     : the tensor geometry of one forward pass, DRAWN to a single scale
%            (1 mm of edge per 40 px; slab depth +0.55 mm per channel
%            doubling).  Shapes from sec_method.tex III-A / Eq. (readout):
%            800^2x3 -> {256@200^2, 512@100^2, 1024@50^2, 2048@25^2}
%            -> F 256@200^2 + 3 memory levels -> Q 100x256 -> 100x200^2
%            -> U_4x -> 100x800^2.
% Rails    : the AP progression (T1) drawn as bars, and the error-axis spine.
% Numbers  : docs/ALL_TABLES.md T1 + sec_exp.tex Table I.  Nothing invented.
%
% v3 CHANGES
%  * REAL DATA.  The input chip, the four ResNet stage maps, the mask feature
%    and the output mask stack are now the actual tensors of one forward pass
%    of runs/c0_maskiou_v2/soup_s023/iter_100872.pth on HRSID inshore chip
%    P0101_1200_2000_3000_3800.jpg (image_id 1528), dumped by
%    carrier/dump_figure_assets.py; provenance in assets/manifest.json.
%    The schematic \sarchip glyph is gone: it drew ships ~90x larger than the
%    real HRSID inshore median instance (0.0280% of the chip = 13.4 px on
%    800x800, measured over 369 images / 2841 instances of test_inshore.json).
%  * The 179 mm prose banner is deleted; the scale rule lives in the caption.
%  * The AP progression is drawn as bars on a shared 0-75 axis, not as text.
%  * G1 floor: the 2048@25^2 slab alone is drawn at the 1.2 mm legibility
%    floor instead of its true 0.63 mm, marked with "~" in its label.
%
% CODE AUDIT (A7.1): the drawn order (x) -> 100x200^2 -> U_4x -> 100x800^2 was
%  diffed against the installed implementation, not against the prose:
%  mmdet/models/dense_heads/mask2former_head.py:364 computes
%  mask_pred = einsum('bqc,bchw->bqhw', mask_embed, mask_feature) at the
%  1/4-stride mask_feature (200^2), and maskformer_head.py:595 then applies
%  F.interpolate(..., size=batch_input_shape, mode='bilinear') to 800^2.
%  The read-out therefore precedes the upsample, as drawn.
% Authored at exactly 18.2 cm = 516 pt = \textwidth  ->  include at scale 1.
%
% v5 (submission review, R1 #8 / P1-1): the weight soup and the wide TTA are
%  CARRIERS -- established practice the fusion operator rides on -- not
%  contributions of this article, so they no longer wear the solid heavy
%  vermillion rule.  That rule now marks the consensus operator alone; the two
%  carrier boxes take a thin long-dash vermillion rule on a paler tint with a
%  hollow step badge, and the legend gains a "carrier" swatch.  No number in
%  the figure changed.

% figm_fusion.pdf — consensus-gated mask-IoU vote fusion (Sec. III-D, Alg. 1).
% Row 1 : the candidate pool drawn as K overlapping 800x800 planes -> the REAL
%         pairwise mask-IoU matrix with its real clusters boxed -> class-wise
%         greedy clustering (seeds in score order, tau=0.5) -> the agreement
%         gate -> the fused instance read-out.
% Panels: what the gate does TO THE PLANES, drawn rather than named.  On the
%         yes side |C| planes collapse into a single plane of exactly the same
%         size (pixel majority); on the no side one plane -- the seed --
%         survives and the rest are deleted.  Nothing changes shape either
%         way: 800x800 in, 800x800 out.
%
% v3 CHANGE.  The matrix used to be a hand-picked 6x6 of INVENTED values
% ({100,78,10,6,4,2},...).  It is now the real thing, produced by
% figs/dump_iou_matrix.py and stored as assets/iou_matrix.png with full
% provenance in assets/manifest.json and assets/iou_matrix_meta.json:
%   * the real 8-view wide msTTA path on chip P0101_1200_2000_3000_3800.jpg
%     (image_id 1528) driven through the actual CocoDataset + cfg.tta_pipeline
%     + model.test_step + MaskTTAModel._flip_mask_back; pool = 8x100 = 800;
%   * K = 16, the 16 highest-scoring pooled candidates of the single ship
%     class (score 0.6896 down to 0.6742), no extra threshold;
%   * IoU by pycocotools maskUtils.iou on RLEs, cross-checked against exact
%     dense numpy intersection/union, max |diff| = 0.0;
%   * tau = 0.50 read from tta_cfg.vote_iou of
%     carrier/configs/c0_v2_mstta_wide_voteconsensus_hrsid.py;
%   * greedy clustering gives sizes 6 / 7 / 1 / 2, i.e. index ranges
%     [0,5] [6,12] [13,13] [14,15] after permuting into cluster order, and
%     off-block IoU is EXACTLY 0 -- the four objects are disjoint.
%   * The real data exercises BOTH gate branches: 6 and 2 fall inside
%     2 <= |C| <= 6 (majority vote), 7 and 1 fall outside (keep the seed).
%     The cluster boxes below are therefore drawn in two styles, and that
%     distinction is a measurement, not a decoration.
% The 176 mm "why a gate" prose banner is reduced to two failure chips; the
% reasoning is in the caption.

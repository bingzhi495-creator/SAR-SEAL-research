% figm_tta.pdf — wide multi-scale flip TTA (Sec. III-C).
% The geometric point of this figure is an ASYMMETRY:
%   different size in  ->  ONE frozen model  ->  the SAME size out.
% Upper band: one 800x800 chip is resized to R in {640,800,960,1088}; the four
%   views are drawn at TRUE relative size (16.0 / 20.0 / 24.0 / 27.2 mm under
%   the article-wide scale of 1 mm per 40 px), each behind its horizontally
%   flipped twin, so V = 8 views enter one frozen checkpoint.
% Lower band: the eight raw outputs live on four different rasters (drawn as a
%   corner-aligned size ladder); rescale=True and f^{-1} map every one of them
%   back to the native 800x800, drawn as eight planes of IDENTICAL size, which
%   is what makes the pool of K <= 800 candidates commensurable.
% Facts: sec_method.tex III-C, Eq. (views); ALL_TABLES.md T1 rows 2'-3, T11.
% Authored at exactly 18.2 cm = 516 pt = \textwidth -> include at scale 1.

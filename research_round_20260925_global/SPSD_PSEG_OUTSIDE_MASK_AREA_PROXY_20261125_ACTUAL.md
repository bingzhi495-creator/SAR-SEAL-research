# 采样端点以外的面积近似误差

推理的面积估计将采样端点之外的静态前景当作参考前景。为了量化该假设，将原 183 张已用源域图的端点内预测替换成真值，并对两份作者标注各自的原生 COCO 0.50 匹配和正预算候选计算固定静态掩膜的外部误差。完整复现 311／308 个原生匹配。
设固定静态掩膜面积为 P，参考面积为 T，交集为 I。净新增面积为 d，交集变化为 g，真实 IoU 增加需要 g 大于 dI/(P+T)。若端点之外的静态掩膜有 F 个假阳性和 N 个假阴性，则在端点内完美标注的情况下，代理交集为 I+F，代理面积为 T+F−N。净新增门槛系数的差精确等于下式。

```text
((P + T − I)F + IN) / ((P + T)(P + T + F − N))
```

差值非负。符合条件的候选需要更高的交集收益才会被代理判为值得净新增。实际预测端点的误差可能抵消或加强这一作用，效果由独立评分确定。

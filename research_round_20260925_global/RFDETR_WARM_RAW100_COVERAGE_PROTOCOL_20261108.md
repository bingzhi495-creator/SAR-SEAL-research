# RF-DETR 全部原始查询与保留候选覆盖诊断

已观察到原生 A、均匀 B、校正分层 D 相对 E24 都有 IoU≥0.90 的覆盖回落。要区分高质量掩膜仍在原始查询中与原始掩膜本身退化，重新用同一 Windows FP32/TF32 入口，在固定 DEV187 对四个已闭合端点逐图计算全部 100 个原始查询。原图双线性插值与原生阈值 0 一致。逐图逐查询核对已验收保留候选的原图二值掩膜，核对不通过则不解释新统计。保留集合以原件的原生 top100 船舶槽位为准。此诊断不改分数、模型、训练或 AP 门槛。

在同一整数 GT 下，对每个 GT 取全部原始查询和保留查询的最高掩膜 IoU，报告 0.50、0.75、0.90 三个阈值和大小组。重点在 E24 保留集合覆盖、对应热启动保留集合未覆盖的 GT。若其在热启动全部查询中仍有达阈值掩膜，归入保留筛选未选中。若全部查询均未达阈值，归入当前原始掩膜覆盖缺失。在 0.90 处若筛选未选中占比超过一半，优先研究候选保留，否则优先研究原始掩膜或热启动过程。覆盖是分数无关的掩膜诊断，筛选未选中不能直接换算成 COCO AP。此为已观察结果后的机制诊断，原 B/D 停止决策保持。 [A 和交叉实测](RFDETR_E24_NATIVE_WARM_A_CONTROL_ACTUAL_20261108.md)

# 同一原生候选下的双参考边界误差分解

在已使用的 232 张同图 SSDD 影像上，逐值复现两套参考的原指标和全部八臂写回。预先固定三个已报道的对照，分别将 SPSD 与 PSeg-SSDD 的效果差拆分为参考轮廓、原生匹配候选、图内参考数和无法配对船体的贡献。零新前向，无优化更新。本轮是事后归因，仍沿用原来的图像分组。[前序同图比较](SPSD_PSEG232_ANNOTATION_SENSITIVITY_20261125_ACTUAL.md)

## 对照与精确分解

逐图以最大总栅格 IoU 一对一关联两套参考。544 对中的 493 对达到 0.50，268 对达到 0.75。对达到 0.50 的 493 对，两套参考的原生 COCO IoU 0.50 指派有 358 对共享同一候选，10 对用不同候选，17 对仅一侧有匹配，108 对均未匹配。原分母继续包含 PSeg 的 546 艘与 SPSD 的 547 艘。权重和不合格配对的贡献逐图精确补齐。

同候选时，将改动像素分为双前景、双背景及两种独占前景。写回前后总面积相同，所以每套参考的 IoU 差是有符号交集变化乘以由原交集、预测面积和参考面积决定的系数。交集差的部分完全来自两套标签的分歧像素，独立的归一化项保留参考面积和原交集等作用。候选不同或单侧缺失时，以两个变化顺序的均值区分轮廓和匹配作用。未匹配候选的策略效应记零。[预锁公式和判据](code/SPSD_PSEG232_SHARED_HULL_DECOMPOSITION_20261125/PRELOCK.md)

## 实测

表内是从 PSeg 换成 SPSD 后的全船体、影像等权 IoU **效应差**，单位为百分点。各分量按 232 图权重汇总，逐图和与原结果的最大差小于 3.3×10⁻¹⁴ 点。

| 分量 | 自然量独立减原生 | 同量独立减距离配对 | 同量学习减静态吸引力 |
| --- | ---: | ---: | ---: |
| 同一候选上的分歧像素 | −0.286 | −0.037 | −0.313 |
| 同一候选的 IoU 归一化 | −0.013 | −0.001 | −0.036 |
| 候选不同或缺失时的参考差异 | −0.009 | −0.002 | −0.017 |
| 候选存在与缺失 | −0.002 | −0.002 | −0.006 |
| 候选更换 | −0.012 | −0.004 | −0.009 |
| 双参考数量权重差 | +0.001 | −0.000 | +0.002 |
| 低重叠或未配对参考 | −0.038 | −0.001 | −0.014 |
| 合计 | **−0.359** | **−0.047** | **−0.394** |

自然量组在 **137 图的 262 对共享候选**上实际改动。PSeg 独占前景增加 599 个像素、删除 384 个，SPSD 独占前景增加 51 个、删除 99 个。33 对从 PSeg 改善变为 SPSD 退化，反向有 5 对。分歧像素效应是 **−0.286［−0.388，−0.193］**点，占总差点估计约八成，超过预锁的机制门槛。只保留参考间 IoU ≥0.75 的共享候选时，仍从 84 图的 131 对改动样本得到 **−0.102［−0.163，−0.046］**点，单位仍是原 232 图权重。

原主对照的同候选分歧效应为 **−0.037［−0.081，+0.006］**点。学习排序相对等量静态吸引力的同候选分歧效应为 **−0.313［−0.440，−0.193］**点。三项差值采用同一 4,096 次配对影像重采样；图像组间采集独立性未确认。结果支持对强静态对照检验双参考下的同量收益上界。作者参考不能用来选择实际推理端点，当前结果也不能确定哪套参考更接近物理船体。

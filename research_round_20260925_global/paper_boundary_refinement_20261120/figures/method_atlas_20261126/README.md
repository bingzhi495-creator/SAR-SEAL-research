# NORA 方法图

本轮以真实 SAR 场景和原生像元为视觉主线，重画五张旧图并加入四张解释图。正式稿的定量、定性、消融图沿用上版。作者审阅稿中的观测裁片来自已核验的本地图件。公开目录保留矢量示意和可公开的空间汇总。

| 图 | 内容 | 表达 |
| --- | --- | --- |
| 1 | 一像元偏移 | 4 格宽、3 格交、5 格并的几何示意 |
| 2 | NORA 总览 | 同一个 SAR 目标、原生网格局部和写回结果 |
| 3 | 原生取样 | 两侧边界环、裁剪、签名端点列表 |
| 4 | 分数读出 | 多边形覆盖面积和中心处双线性采样 |
| 5 | ROH | 14 项特征、标准化与拼接、层片、logit 残差、sigmoid 与监督 |
| 6 | 端点选择 | F/L/I 共享端点预算，成对连线及独立排序 |
| 7 | 交并比 | 相同交集增益下，等分和变分写入改变的并集 |
| 8 | 签名预算 | 固定总数，改变正负分配及面积 |
| 9 | 冻结细化器 | 一张固定响应、两类支持及两类写入规则 |

暖色作为结构编码。矿绿表示新增或共享区域，酒红表示移除，赭橙用于约束和定位。边界以线型、面积以网格表示。图注交代示意和观测的界线，公式及实验解释在正文。

[九页 Draw.io 工程](NORA_method_atlas.drawio)用于逐元素编辑。期刊排版使用同目录下的矢量 PDF。SVG、图件生成代码和可重建的 Draw.io 转换源均随稿提供。

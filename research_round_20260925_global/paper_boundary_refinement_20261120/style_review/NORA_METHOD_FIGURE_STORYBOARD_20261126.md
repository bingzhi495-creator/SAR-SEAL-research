# NORA 方法图画面说明

以下构图说明用于生成方法图草案。稿件图使用既有真实 SAR 审阅裁片及可追溯的掩膜。草案内的生成图块只表示构图位置。

| 图 | 实物和构图 | 图中文字与证据边界 |
| --- | --- | --- |
| 1 NORA 总览 | 左端展示一个真实近岸船目标和冻结掩膜，上方给出紧凑场景与定位框。从框引出同坐标的格网细化，中段安排端点、ROH、受约束写入，右端回到同一原生 SAR 裁片，叠加独立写入后的轮廓。下方分开画训练监督和 Phoenix 对照。 | 主轴依次是 SAR / Frozen mask / Native cells / ROH / Write / Edited mask。案例有真实来源，算子图格为示意，数据流实线，定位线用细折线。 |
| 2 ROH 局部图 | 顶部左侧是已核验船体裁片及一处边界位置。右侧放大同一个原生窗，底部将真实位置观察与原生取样、分数估计并置。下面是像元中心插值和源域覆盖率训练两个小分面。输出显示残差叠加和占据概率。 | 实测裁片提供场景，符号格、覆盖率示例和分数示意各自标明。作者轮廓只作来源明确的例示，目标评估图的参考轮廓不连向训练轨。 |
| 3 等符号计数选点 | 真实同一候选在上排并列 F、L、I，带作者参照或共享边界。下排在同形网格上展开距离优先、限距重配和独立排序，配对只在线路对应的两栏画线。 | 真实示例标实际每侧计数。示意用原两加两删和估计交集增益，每组用一致青绿加号和铁锈减号。 |
| 4 固定总数分配 | 上部以固定检测的真实 SAR 裁片给出船体方向和边界背景。下部两栏在相同示意掩膜上表示等分与变分，两边画同数量的编辑标记和原面积及改后面积。 | 真实裁片仅提供成像上下文，分配图展示两加两删与三加一删的独立示意。页内明确实际结果由定量图和表给出。 |
| 5 Phoenix 支持及计数对照 | 真实 PSeg-SSDD 单目标上部小条并排原掩膜、完整图域阈值和固定总数结果，下面显示一个冻结响应、两个可写支持及两个规则的 2×2 示意，再点出窄支持固定总数下的均衡与自由分配。 | 明确实例、冻结响应与图中正在比较的写入条件。能从实际图确认的局部误差留在真实图，示意网格沿用手稿核验过的预算。 |

版式采用暖白背景和鞍棕标题。赭橙、酒红和矿绿标示不同功能分面。矿绿色加号和砖红色减号用于编辑端点。栅格、箭头、公式、轮廓、图例和分面字母都可以编辑。深灰 SAR 画面及真实轮廓以同一视野和对比度显示。图内只保留英文短标签、必要变量和图例，取样、分配和误差的解释写回正文。可公开版继续使用受许可核验的数据范围，真图作者版以原始裁片和已核验轮廓呈现。


配色的参考是暖皮革色与局部的橙、红、绿搭配。图中色值按背景、主流程和编辑符号重设。[Hermès 色彩参考](https://www.hermes.com/es/es/product/bolso-evelyne-16-amazone-H078999CCAB/)

# RF-DETR E24 的 FIT 邻船重叠实测

以已验收的 RF-DETR E24、种子 5201、完整原生候选与整数 GT 为输入，仅使用既有 FIT `head_fit` 516 图。保持候选、掩膜、得分及 COCO IoU 0.50 一对一匹配原样。两份真值掩膜任意像素的最小 Chebyshev 距离不超过 4 即定义为邻接。预测掩膜交集至少一像素即记为重叠。高重叠未匹配候选指与任一已匹配预测的掩膜 IoU ≥0.50。统计范围覆盖所有保留候选，包括低分和空掩膜。

| 观察量 | 实测 |
| --- | ---: |
| 图像 / GT / 候选 / 匹配候选 | 516 / 1,149 / 42,481 / 1,149 |
| 同图不同 GT 的已匹配候选对 | 2,459 |
| 真值邻接对 / 图像 | 36 / 15 |
| 有实际预测重叠的不同 GT 配对 | 23 |
| 其中真值邻接对 / 图像 | 20 / 11 |
| 涉及邻船预测重叠的独立匹配实例 | 38 |
| 匹配 IoU <0.90 / 其中涉及邻船预测重叠 | 857 / 33 |
| 未匹配候选 / 其中与匹配预测高重叠 | 41,332 / 13,982 |
| 高重叠未匹配候选中位于各图保留顺序前十的个数 | 1,719 |
| 高重叠未匹配候选中，得分达到至少一个重叠匹配候选的个数 | 3 |

原执行先遇到 NumPy 计数无法写 JSON 的问题，修正为标准整数后，两个回归用例通过，完整实测 7.20 秒。独立程序使用像素最近邻查询及 RLE 交并重新计算，主表全项一致，另核对候选顺序和分数。没有改预测或测 AP，本诊断没有读取用于选择器校准和评估的另外 225 张 FIT 图像，也没有使用 DEV/TEST。

在这批固定预测里，直接触及重叠像素的邻船互斥改动所对应的低 IoU 实例为 33/857，即 3.85%。这个范围支持把标记分水岭或图优化留作邻船密集子集对照。它未度量断裂、漏检、没有预测交集的邻船，或更密集的跨数据集场景。大量高重叠未匹配候选多数得分低于关联的匹配候选。这一分布本身不等于删除它们能提升 AP，后者需独立冻结评分和完整候选实验。

# Prospective Umbra SAR annotation feasibility cohort

Use the public Umbra `sar-data/tasks/ship_detection_testdata/` collection. This supplies independent prospective image acquisition opportunities, with outcome and annotation status established separately. The existing HRSID and PSeg-SSDD results retain their benchmark roles. [Umbra open program](https://umbra.space/open-data/) · [AWS registry and CC BY 4.0](https://registry.opendata.aws/umbra-open-data/)

List the official task prefixes and sort them by UUID. For up to 64 metadata probes, take midpoint indices `floor((2i+1)N/128)` with `i=0,...,63` in the full sorted catalog, using all unique positions if the catalog has fewer than 64 tasks. From each task, take the first GEC key in lexical order with a same-stem metadata object. Admit dates from 2021 onward, valid original collect ID and UTC, finite WGS84 center, valid polygon footprint, and product target IPR between 0.35 and 2.00 m. Target IPR denotes the catalog product setting. Read the native GeoTIFF spacing separately during intake.

Exclude the three November technical pilot tasks and collect IDs. Exclude all matching task and collect IDs in the archived 120-collect, ten-port manifest (SHA `b669b72e7d50185d998d8a56d5bab52ba172ed7c6118e6a9c71fc110180c3f5a`), and exclude any center within 100 km of an archived footprint centroid from the companion STAC snapshot (SHA `d7345af229cb815923164b41a616abe2cdb66c5795f05ebf319eb132438b7805`). This accounts for the September Umbra development exposure as well as the earlier sealed port study. Use at most one unique collect per selected window and require at least 100 km between selected centers. Select in predetermined candidate order, first up to six 1.00–2.00 m target-IPR items and then up to six 0.35–below-1.00 m items. Fill any remaining seats up to 12 from the same deterministic candidate order and distance constraints. Preserve missing metadata and rejected counts. The minimum for this intake is eight groups. Archive the complete chosen order and bind it before any image pixels are read.

For each selected GEC, take a single native 1,024×1,024 window from four adjacent complete 512×512 tiles. On each axis use the tile-aligned full interval whose center is nearest to the raster center, with ties toward the smaller index. Preserve the native unsigned single-band integers, pixel grid and original georeferencing. Use opaque window IDs and no pixel-based recentering or substitution. Record and retain transfer or decoder failures on the original list. The reviewer file contains the lossless native crop and an identity roster. Keep acquisition mapping and raw author metadata separate from reviewer work.

Two reviewers independently outline the visible SAR ship response in native continuous image-edge coordinates. Each hull is its own polygon. Tail wake, shadow, quay and detached sidelobe energy are excluded. Each image explicitly records complete, searched-empty, incomplete or unreviewed. Uncertain and clipped shapes are retained as separate labels. Both reviewers see the same original grayscale and the same optional display-only two-times brightness. They work independently without model predictions, vessel tracks or each other's labels. Freeze both raw returns before comparing one-to-one instance matches and continuous polygon IoU at 0.50. Preserve unmatched labels, incomplete windows, matched IoU and agreement on jointly completed windows. Any adjudicated reference requires independent review of disparities and the original source-only imagery. Freeze it before opening predictions.

This stage tests whether the available windows can be labeled. It claims neither a completed mask benchmark nor a transfer gain. A later frozen evaluation retains the project requirement of at least 20 original matched hulls exposed to positive fixed-pair edits across at least eight source groups. Use the standard benchmarks separately for their scored task. No model fitting, threshold or scope selection follows from the image intake.

# 单图反向定位与同梯度 AdamW 首步实测

## 单图双反向

使用同一真实 FIT 首个微批次，仅执行一次原生 BF16 CUDA 前向。输入和全部模型输出均与先前闭合 F0 的同一微批次逐字节相同。保留同一计算图，两次反向前清空参数梯度并复用记录的随机状态。两个反向的 RNG 记录一致。原进程退出 0，无优化器或 EMA 更新。对 2,659 个图节点中按固定规则选出的 128 个做被动观测，全部可比较。

同一节点两次收到的反向输入张量一致、传出的梯度不同，共观察到 **11 个**：

| 局部反向算子 | 节点数 |
| --- | ---: |
| GridSampler2DBackward0 | 9 |
| UpsampleBilinear2DBackward0 | 2 |

叶子梯度的相对 L2 为 1.158268%，分歧在骨干中复现。一次真实微批次的被动观测识别出两个算子族，尚不能穷尽其他输入及未选节点。前一项只替换网格采样反向，因此不足以覆盖本次观察到的上采样反向差异。 [单图实际安全汇总](results/RFDETR_E24_SAME_GRAPH_BACKWARD_NODE_ACTUAL_SAFE_20261108.json) · [单图观察源码](code/RFDETR_E24_SAME_GRAPH_BACKWARD_NODE_TRACE_20261108/same_graph_backward_node_trace.py) · [先前单算子族对照](RFDETR_E24_GRID_BACKWARD_CONTROL_ACTUAL_20261108.md) · [PyTorch 上采样算子说明](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.interpolate.html)

## 同梯度的四个首步单元

把此前真正采集、已经封存的 F 与 S 首步裁剪梯度分别送入完全相同在线权重下的新建 F 与保留历史 S。应用同一学习率与 CPU 原生 AdamW，各执行一个更新。原进程退出 0，实际 16.84 秒，四个单元均有 543 个计数。F 到 1，S 到 4465。未做新前向、读图或 EMA。

| 梯度来源 | F 全模型更新 L2 | S 全模型更新 L2 | F 掩膜头 L2 | S 掩膜头 L2 |
| --- | ---: | ---: | ---: | ---: |
| F 实际首梯度 | 0.221722 | 0.053226 | 0.079596 | 0.017031 |
| S 实际首梯度 | 0.221721 | 0.053225 | 0.079596 | 0.017031 |

在固定梯度的两次比较中，保留历史使全模型更新范数约缩小 76.0%，掩膜头约缩小 78.6%，全模型方向余弦约 0.380。比例缩放学习率无法重现这一首步向量。固定 AdamW 状态而更换已观测梯度时，全模型更新向量相对变化 F 为 1.068%，S 为 0.088%。这支持历史状态改变首步幅度及方向，范围仅限闭合实际梯度上的 CPU 算术复放。原 GPU 配对资格与效用结论保持冻结。 [首步安全汇总](results/RFDETR_E24_ADAMW_SHARED_GRAD_CPU_ACTUAL_SAFE_20261108.json) · [复放源码](code/RFDETR_E24_ADAMW_SHARED_GRAD_CPU_20261108/cross_replay.py)

## 下一项固定组合控制

在相同 F0/F1 的首四个真实增强 FIT 微批次上，同时将已确认的两类有梯度 CUDA 双线性采样和普通上采样的反向改为 CPU 原生算子。保持原生 CUDA 前向，记录实际两类覆盖、形状与成本，无参数或 EMA 更新。前向、匹配、采样及损失须与原 F0/F1 精确一致。固定首梯度相对 L2≤10⁻⁵、余弦≥0.999999。只有真实组合控制过关，才预锁新的可复现 F/S 训练。若未过，记录剩余差异并重新评估本数值路径的成本，不用未入围的旧端点计算 AP。

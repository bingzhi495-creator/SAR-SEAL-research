# HRSID 大船核心漏分的补充查询诊断

在固定共同监督的 HRSID DEV705 中，逐步中心臂的大目标 AP 在栅格和连续口径下均下降约 6.67 点。固定匹配经真值辅助平移后，15 条大目标的中心臂仍多漏 16,623 个核心像素。新诊断只检验一个问题，即同一视图的第二个查询是否含有可选择的互补船体信号，足以超过普通膨胀和候选内的最佳单掩膜。MNC 已做重叠掩膜的加权投票，SAHI 已做相邻预测掩膜合并。旧项目诊断也核对过其他候选能覆盖的漏分。本轮增加同预算的整掩膜 IoU、核心覆盖和邻船误分对照。 [大目标原诊断](HRSID_MASK_PHASE_COMMON_SUPPORT_AND_SSDD_TRANSFER_DESIGN_20261109.md#大船内部与两像素边带的漏分复算) · [MNC 原文](https://www.cv-foundation.org/openaccess/content_cvpr_2016/papers/Dai_Instance-Aware_Semantic_Segmentation_CVPR_2016_paper.pdf) · [SAHI 掩膜合并源码](https://github.com/obss/sahi/blob/main/sahi/postprocess/utils.py#L303)

## 已完成的固定 FIT 导出

取 HRSID FIT2937 中全部 28 张含大目标的图，预定 50 条大目标标注，覆盖 4 个文件名前缀代理组。用种子 5202 固定共同监督的两份 E24 EMA，分别完成 28 次原生 CPU FP32 单线程前向。每臂输出 4,592 条 Q164 掩膜及原始两类别联合排序的 2,800 个位置。原生 A 与逐步中心 B 映射到船类的原生候选分别为 2,786 和 2,800，全查询空掩膜为 80 和 72。每个映射位置的原生掩膜与全查询掩膜逐值一致。两次原工作进程及协调器均退出 0，原等待 84.656 和 83.625 秒。导出未读取真值，未执行 DEV、TEST、评分或训练。CPU 与既往 CUDA 导出允许数值差异，本轮两臂只在同一 CPU 执行路径比较。

## 在计算诊断指标前锁定的规则

1. 原生 A 与逐步中心 B 各自使用原始联合前 100 位置中已映射、非空的船类掩膜，顺序、分数和查询 ID 保持原样。不使用候选分数另设阈值。按固定 IoU 0.50、原分数顺序和原 COCO 忽略规则在每张图的全部真值上冻结一对一锚匹配，再取预定 50 条大目标。无锚、无补充候选均保留在人口表。
2. 对每个锚，从同一候选池的其他查询中按原始顺序取首个合格补充掩膜。合格要求掩膜交集至少为较小掩膜面积的一半、裁至画布后的预测框 IoU 至少 0.30，且存在可通过八邻接从锚到达的补充前景。选取和生长均只使用预测。新增预算为可达残差像素数与锚面积 5% 向下取整的较小者，像素按从锚出发的八邻接路径距离、行、列顺序添加。同预算膨胀从同一锚开始，在同一图幅内按八邻接距离、行、列添加精确相同的像素数。无合格补充或预算为零时，两臂均保持锚掩膜。
3. 另在同一个原生候选池内取真值 IoU 最高的单掩膜，平局保留原顺序。它是逐目标参照，允许同一查询在不同目标的上界计算中重复使用。真值仅用于固定锚、该参照与评分。固定阈值对照和分数不变。核心为真值做两像素切比雪夫腐蚀后的区域。报告整体 IoU、核心召回、IoU 0.75／0.90 达标新增和失守、背景误分、邻船独占前景新增及新连通桥。对邻船采用同图全部其他非 crowd 真值，独占前景排除当前真值。若新增像素使包含锚的预测连通分量接触此前未触及的邻船独占前景，记为新连通桥。
4. 中心臂为推进判定对象，原生臂为同规则机制对照。主表在固定锚匹配、核心非空的目标上比较，按 4 个前缀代理组等权。另报告包含未匹配目标的 50 条覆盖统计及每组人口。只有中心臂相对两个对照的核心召回均至少提高 1.0 点、整掩膜 IoU 均至少提高 0.5 点、至少 3 个组在两项上均为正，且至少 3 个组出现正编辑预算，才进入下一阶段。任何新连通桥或任何邻船独占前景的新增侵入达到 1%，均停止推进。保留失败和无编辑病例，不据结果调整候选门槛。

本次方案只进入 FIT 误差诊断。固定锚、逐目标上界和来源代理组限制了推断范围。后续若通过，仍需验证无需真值的实例选择、训练成本和独立评价。

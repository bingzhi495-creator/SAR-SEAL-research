## 独立核验与失败记录

六件已闭合的 E24 输入按原字节摘要转移到 Windows。参考 DGX 使用原锁定的 CPU 栅格化代码，对每对原始预测和两版 GT 生成掩膜位图指纹。本机使用官方 pycocotools 2.0.11 Windows wheel 与 NumPy 1.26.4，224 对共 672 个位图指纹全部逐对一致。适配器还逐项复现原 IoU 和漏分、溢出计数。原本机工作进程实际退出 0，工作体约 0.875 秒，采样进程 RSS 峰值约 65 MB。独立复算枚举每个 K 的可行编辑量，复核最少编辑数、不限额与全部分组统计。本次诊断只使用 E24 的闭合文件，DGX E100 原进程持续运行。 [适配器与独立复算源码](code/RFDETR_E24_SIGNED_EDIT_ORACLE_ADAPTER_CANDIDATE_20261107/) · [官方 Windows wheel 与摘要](https://pypi.org/project/pycocotools/2.0.11/#pycocotools-2.0.11-cp310-cp310-win_amd64.whl)

保留三处接线失败。首个参考栅格过程在隔离 Python 启动时找不到 NumPy，修正到原锁定的模块目录。首个本机诊断把逐行迭代器直接传给要求完整列表的接口，在人口核对阶段退出，修正版完整读入并核验同一文件。独立复算入口先修正本地模块引用，随后将运行环境字段与科研汇总分开校验，对同一成功原结果完成验收。无新训练、AP、TEST 或 COCO 重匹配。

## 下一项预登记：用实际推理的掩膜和候选区

主格固定原生产保留及整数 COCO 0.50 已配对的查询，不重排分数、不重分配。仅从预测掩膜本身生成有限网格 2 像素切比雪夫边界带，即膨胀减腐蚀。两版 GT 仅用于离线计算许可正确的编辑和评估。主格的分母为原 377 个配对，预定主预算为 K=16。新增双达标定义为编辑前至少一版未达 0.90，至多 16 次两版共同认可的像素翻转后均达到 0.90，用整数交并集判断。报告原双达标、合格失败分母、总双达标、新增数、涉及图像和最少编辑数分布。原未配对 3 例不填补。

在已锁的原 224 对上执行四格诊断。查询取原整数最佳或生产已分配，支持取 GT 共同边界带或该查询自己的预测边界带。核对每格同一原身份，记录支持像素面积与交集、逐对共同或单格救回。固定查询时可以比较支持差异，切换查询会同时改变起始 IoU、距阈值差和预测边界。四格的作用是描述机会来源。全 377 的生产查询同时计算两类支持，K=0、1、2、4、8、16、32 与不限额维持报告，主判断固定 K=16。

选用 K=16 的依据是本次已公开的 GT 上限曲线。生产主格须至少新增 **20/377** 双达标，才投入一次 FIT 小型选择器试验。20 是预设的资源投入口径，约占已配对实例 5.31%。若低于门槛，停止当前半径与预算的选择器训练，保留全部曲线。其他预算、原 224 子集和尺寸分层仅用于描述。该四格真实诊断尚未执行。

两侧灰度成对秩有直接先例。Girón 等已把 Mann–Whitney 用于 SAR 两侧分段的边缘检测。Ranklets 已使用同类归一化统计，作者 MATLAB 实现核对了平均并列秩，授权注明非商业使用。若进入选择器试验，独立实现秩特征，同一候选集、窗口、头与预算对照两侧有符号均值对比和预测不确定性。SAR-SIFT 的两侧均值比提供物理启发，当前显示灰度只作图像特征。真实选择器对标注分歧处的任何编辑也要计入 K，并单列伤害。FIT 留出图只用于训练侧机制检验，因为载体已见过 FIT741。 [SAR 非参数边缘原文](https://arxiv.org/pdf/1207.1915) · [Ranklets 原文](https://www.ranklets.net/Bibliography/icpr02-paper/ranklets-smeraldi-icpr02.pdf) · [作者源码](https://raw.githubusercontent.com/fsmeraldi/www.ranklets.net/master/Downloads/RankletFilter.m) · [SAR-SIFT 原文](https://perso.telecom-paristech.fr/tupin/PUB/Dellinger12.pdf) · [PointRend 源码](https://github.com/facebookresearch/detectron2/blob/main/projects/PointRend/point_rend/mask_head.py#L26-L46)

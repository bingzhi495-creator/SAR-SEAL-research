# E24 AdamW 配对实测与首梯度资格失败

按照[前瞻协议](RFDETR_E24_OPTIMIZER_PRESERVATION_PROTOCOL_20261108.md)，F 与 S 均在同一 Windows GPU 上完成 1,488 个微批次、372 次新优化器更新和 372 次新 EMA 更新，原进程均退出 0。EMA 计数都到 4836。F 的 543 条已用 AdamW 状态均到 372，S 的 543 条均到 4836。实际 FIT 访问、初始在线及 EMA 权重、增强后首批输入和学习率的摘要一致。训练测时 F 209.65 秒、S 211.12 秒，峰值 CUDA 保留量分别 2.305 与 2.324 GB。

首个累积窗口结束后，对两份闭合全量裁剪梯度在 CPU 独立逐张量复算：

| 指标 | 实测 | 预锁门槛 |
| --- | ---: | ---: |
| 梯度相对 L2（相对 S） | 1.008503% | ≤0.001% |
| 梯度余弦 | 0.999949146 | ≥0.999999 |
| 梯度差异的最大绝对值 | 4.1847×10⁻⁵ | 汇报项 |

首步实际在线参数更新 L2 为 F 0.22172、S 0.05323，掩膜头分别为 0.07960、0.01703。它们同时受到历史状态和观测到的梯度不一致影响。**该配对未达到首梯度资格，自动评价没有开启，未产生 DEV AP 或优化器效用结论。** 保留两个真实端点和原始退出记录。 [独立安全汇总](results/RFDETR_E24_OPTIMIZER_FIRST_GRADIENT_GATE_ACTUAL_SAFE_20261108.json)

独立 CPU 复算按模型分组，骨干占梯度差异平方和的 99.999935%，骨干相对 L2 约 1.01881%。Transformer、掩膜头及其他非骨干组的相对 L2 接近 0.00573%。该模式与共享全局裁剪缩放吻合，是待核实的解释。当前聚合量还不能定位到某一算子或断言 CUDA 随机性。 [分组计算结果](results/RFDETR_E24_OPTIMIZER_FIRST_GRADIENT_COMPONENTS_SAFE_20261108.json)

## 固定首窗复放

只在 FIT 复放已锁种子的首四个真实增强微批次。F0、S0、F1、S1 分别独立初始化，保留实际 BF16、TF32、原生点采样和匹配。首步裁剪完成后停在更新前，记录可验证的前向、匹配和采样事件、裁剪前梯度范数及裁剪后梯度，不进入后续训练或读取 DEV/TEST。比较两组同臂差异和所有跨臂差异，并核对最早出现分叉的实际阶段。若同臂差异已覆盖跨臂差异，优先排查可复现路径。若只出现稳定跨臂差异，优先排查实现及运行路径差异。原配对资格与容差保持冻结，复放用于定位问题。

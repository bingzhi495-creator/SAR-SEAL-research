# 同一批 SAR 影像上两套作者船体参考的敏感性

在相同的 232 张 SSDD 测试 JPEG、23,200 个冻结 D-FINE 候选、分数和写回掩膜上，单独换用 SLGSea 作者发布的 SPSD 船体参考，原来相对原生的 **+0.344 mask AP** 成为 **−0.491 点**。同头、逐候选同编辑量的独立选点优势由 **+0.081 AP** 变为 **−0.007 点**。实验显示主要收益依赖参考轮廓定义，研究范围仍是已有的 SSDD 图像。[SLGSea 作者发布](https://github.com/deng1218/SLGSea/blob/8225c680d3e991aa2cb5b22af3918b8704ec7b02/README.md#datasets) · [官方 SSDD 论文](https://doi.org/10.3390/rs13183690)

## 参考、覆盖和分母

SLGSea 的 SPSD 与官方 PSeg-SSDD 的原始 JPEG 编码在训练 928/928、验证对测试 232/232 的成员名及内容上完全一致。测试端另与原已接收模型输入清单的字节、长度和 SHA-256 逐项一致。SPSD 包含类别 0 的船舶实例和海、陆背景区域。使用作者发布的原生 RGB 实例编号。547 个船体均非空、非 crowd，其 JSON 面积和边框字段与原生栅格逐项有差异。首次执行由严格的字段等值检查在模型评分前退出。保留失败记录，依据预先明确的参考定义，以 PNG 像元计算 SPSD COCO 面积及紧框，按更正后的输入规则保留全部实例。PSeg 原始浮点多边形和元数据不变。[原协议](code/SPSD_PSEG232_ANNOTATION_SENSITIVITY_20261125/PRELOCK.md) · [评分前澄清](code/SPSD_PSEG232_ANNOTATION_SENSITIVITY_20261125/ERRATUM.md)

在同一图像内最大化总栅格 IoU 做两套标签的一对一诊断，匹配 544 对。中位 IoU 为 **0.747**，493 对达 0.50、10 对达 0.90，完全相同的单船掩膜和影像船体并集均为零。配对 SPSD 与 PSeg 面积比的中位数为 **0.822**。这种诊断使用两套作者发布的参考，其来源不足以判断哪套标注更接近物理船体，亦不足以确认重新独立人工判读。

原生在 PSeg 的 546 艘中匹配 **402 艘、203 个解码影像组**，在 SPSD 的 547 艘中匹配 **403 艘、202 组**。各套参考分别按原生 COCO 0.50 匹配冻结关联，未匹配船体保留且 IoU 计零。全体船体先在图内平均，再对全部 232 个解码影像组等权。区间为 4,096 次同索引配对影像重抽样，采集场景间的关系未核验。

所有指标为百分制。两种参考下的原生绝对 AP 衡量对各自轮廓的吻合，此处判断依赖同一参考内的配对策略差。两套标签间的效应差显示，自然量相对原生的固定 IoU 降低 **0.359 点［−0.479，−0.247］**。同量解除配对的效应在两套参考间减少 **0.047 点［−0.0932，−0.0005］**。这两项都允许各参考保留其原生匹配，不能把变化完全归因于同一物理船体的轮廓差。静态吸引力在 SPSD 上仍保留高于原生的 AP 和固定几何点估计。船体的两套参考共同支持限制对学习排序普适性的表述。

全部八臂 PSeg 原值和 104 项原始 COCO 记录逐值复现。原距离配对与同量独立选点各交换 29,304 对像元，动态、同量静态和同量学习各交换 73,770 对。新前向和优化更新均为零。观察进程实际退出 0，耗时 24.98 秒并通过尾行和结果散列检查。结果 SHA-256 为 `dd152bd587d64453b874a9a34e6531adacbd7bf163de4f9b22ffb25c4dea52fc`，成功终态 SHA-256 为 `3db31ce1be04638f80fd227b8c6656925ba580c2e12c54d6b7a4a0c5188964c3`。[全部指标](results/SPSD_PSEG232_ANNOTATION_SENSITIVITY_20261125_SAFE.json) · [复现入口](code/SPSD_PSEG232_ANNOTATION_SENSITIVITY_20261125/README.md)

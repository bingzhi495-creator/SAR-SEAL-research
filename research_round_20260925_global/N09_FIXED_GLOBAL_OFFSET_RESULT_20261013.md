# N09：FIT-only 单一全局偏移控制的独立核验结果

日期：2026-10-13。状态：**全 DEV GPU 评价与独立 CPU 复核均真实退出 0；当前控制已核验，核心创新仍未确认**。

## 问题与固定规则

冻结同一 Mask2Former/R50 E24 后，原生 mask AP 为 67.0710566。已有 C 在相同载体上用空间特征 F、最终 mask embedding e 和原生 logit L 预测带内残差；两个下游种子的开发集 AP 均值为 68.1661355。本控制检验这部分收益能否由一个更简单的 FIT-only 全局偏移近似解释。

偏移 δ = −0.169106405372359，只由 FIT 的匹配 GT 点样本 BCE 拟合，斜率固定；没有用 DEV 拟合、扫阈值或选择 δ。只在原图原生 |L|≤2 内施加偏移。保持同一候选、类别、原生分数及顺序，保留每图全部 100 个 query 和空掩膜；不做 NMS、分数筛选或 GT 引导推理。数据沿用当前历史 FIT/DEV 协议：FIT 741 图、1,661 GT；DEV 187 图、380 GT。该实验不是公开正式 TEST 或跨数据集测试。

评价前预登记的开发判断规则为：全局偏移 AP 达到 C 均值减 0.10 个百分点，即至少 68.0661355，才视作近似替代。这个容差是研究决策规则，不是统计非劣效检验。

## 结果

下表 AP 使用百分数尺度，差值单位为百分点。

| 方法 | DEV mask AP | AP75 | 相对原生 AP |
| --- | ---: | ---: | ---: |
| 原生 E24，固定原生分数 | 67.0710566 | 83.8426647 | 0 |
| FIT-only 单一全局带内偏移 | 67.1466401 | 83.7982281 | +0.0755834 |
| 已有 C，两下游种子均值 | 68.1661355 | 本表不合并其 AP75 | +1.0950789 |

偏移仍比 C 均值低 1.0194955 个 AP 百分点，没有达到预登记的近似替代规则。它产生了小幅 AP 收益，AP75 则下降约 0.0444 个百分点。因此只能说**本次拟合目标、采样分布和固定斜率下的单一偏移不足以近似替代 C**；不能写成“所有校准都无效”。两种子 C 的效用继续保留，也不能由这张表认定它的新颖性、收敛表现或显著性。

δ 为负，本次候选掩膜只收缩：全部 18,700 个候选合计删除 189,959 个像素、增加 0 个；15,316 个候选发生变化。这不是 15,316 个船舶实例获得改善，不能用候选总面积变化替代 GT 对照。

独立核验将固定原生 query–GT 配对与官方 COCO 重新匹配分开。在原生 IoU≥0.75 的固定 348 对中，像素 FP 从 24,827 降至 24,177，FN 从 24,087 升至 24,639；同一 query 保持 IoU≥0.75 的数量为 347。官方重新匹配则有 1 个实例获得匹配、1 个失去匹配，TP 总数仍为 348。在原生 IoU≥0.90 的固定 107 对中，同一 query 保持该阈值的数量降至 99；官方重新匹配的 TP 从 107 变为 109。这些条件结果说明收缩与匹配变化需要分别评估，不能仅由 AP 或重新匹配数量断言轮廓改善。

## 执行、修复及核验范围

首个 GPU 实现真实退出 1，失败记录保留；它没有可比较的 AP。[首图诊断](N09_NATIVE_EXPORT_BATCH_DIAGNOSTIC_RESULT_20261013.md)发现，chunk4 渲染的掩膜、logit、类别概率与原生一致，但分块质量计算使少量原生分数出现约 10⁻⁷ 的差异。

新版本恢复原始 all100 渲染、排序、质量及分数计算，先逐图逐候选精确复现原生归档，再对相同 logit 的切片施加固定偏移。没有放宽一致性容差、替换参考分数或重拟合 δ。**完整 187 图、18,700 候选的原生输出及 COCO 指标均精确复现**，修复后 GPU 作业真实退出 0，约 58.95 秒；整卡观测峰值 3,691 MiB。

独立 CPU 作业真实退出 0，约 323.83 秒；两组官方 COCO 12 项指标独立重算，固定候选、评分、类别和顺序核查通过。CPU 重放原生 M200 渲染和偏移操作，并独立计算官方一对一匹配及固定配对像素。此次 CPU/GPU 二值支持差异计数均为 0，但仍采用原有 practical atol=rtol=10⁻⁴ 的数值核查规则，**不主张 CUDA 逐位等同或认证误差界**。没有重放教师、点头前向、F/e→M、训练轨迹或完整 FIT 重拟合。

ROOT 在两项作业实际终止后核查了原始进程身份、持有句柄退出码、回收及原出生进程消失；28 个正常祖先及 3 个历史失败均按各自状态保留。整卡观测不是每进程或全过程峰值认证。仅评价和复核，没有新增训练。

## 下一步及禁止扩大主张

目前仅排除了一个简单替代解释。空间 F、显式 e 拼接、非线性映射、额外容量、优化差异和采样效应仍没有独立隔离；尤其 L 已包含 e·F 信息，移除显式 e 不等于消除实例信息。PointRend 和 Implicit PointRend 已有直接先例，不能将共享点 MLP 或实例条件函数本身当新贡献。[先例综述](CALIBRATION_PRECEDENT_REVIEW_20261012.md)。

下一步优先准备 [PR-FL-91 公平结构适配对照](FAIR_POINT_HEAD_CONTROL_DESIGN_20261013.md)：相同冻结载体、缓存、点采样、BCE、固定评分和两下游种子，固定 8 轮、13,288 次更新，近似匹配参数及每点 Linear MAC。这个新对照尚未执行。它用于检验已知粗掩膜条件共享头能否解释现有 C 的效用，不冒充作者完整复现；后续仍需公平长训、更多种子、正式测试及跨数据集证据。

当前没有确认新的核心创新，没有胜过外部 SOTA 的公平证据，也没有达到 TGRS 投稿就绪状态。

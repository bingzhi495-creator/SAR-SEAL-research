# SAR Ship Gulf 跨采集 AIS 船长外测

从作者的 Sentinel‑1A 墨西哥湾发行版按轨道日期组预先抽取 244 张裁块。242 张生成了合格的原栅格输入，25 艘船、19 个轨道日期组完成四种策略的共同物理测量。等量独立选点相对固定配对把 AIS 船长 MAE 降低 **0.168 米**，配对 95% 区间 **[−1.523, +1.692] 米**。正预算覆盖达标，效应未达到预定的 +0.5 米和正下界要求。[预锁协议](GULF_AIS_FROZEN_PRELOCK_20261123.md) · [作者数据](https://zenodo.org/records/21000650) · [复现入口](code/GULF_AIS_FROZEN_20261123/README.md)

## 样本与关联

作者固定目录含 18,342 个归档条目、194 个源景、78 个轨道日期组，覆盖 2024 年 8 月至 12 月的 67 个 UTC 日期。排除已检查的整个轨道日期组后，按固定哈希选 64 组。选中的 244 个文件名船舶标识不重复，来自 97 个源景和 59 个 UTC 日期。244 个归档的公开字节长度和 LFS SHA-256 均验证成功。97 个 VV 产品源景的公开 XML 均声明双轴 10 米采样间距。两张 VV 按独立复核均为 512×512 float32 全零阵列，无法完成正振幅百分位转换，原样保留排除原因。242 张输入在解码后的灰度像素上无完全重复。[作者固定目录](https://huggingface.co/datasets/mshaya/sar-ship-gulf/tree/820ae84a00677d535c4db315adffb129b0d4a835/chips) · [作者裁切程序](https://github.com/mousashaya/sar-atr-study/blob/31387b3f2dbda1a05ca30e48ba5742add5463564/scripts/chip_ships_gulf.py) · [ESA 产品定义表 7-6](https://sentiwiki.copernicus.eu/__attachments/1673968/S1-RS-MDA-52-7440-Sentinel-1-Product-Definition-2025-2.8.pdf)

作者 Zenodo 和 Hugging Face README 逐字节一致，均写有 2,088 个船舶标识。目录统计在 18,334 个符合命名规则的文件中识别到 3,942 个不同的九位船舶文件名前缀，另 8 个文件名未进入标识解析。两种统计的差异尚未核清。入组按固定目录和明确的文件名前缀去重，评分另核对入组归档的标识、源景和时刻。[作者数据说明](https://zenodo.org/api/records/21000650/files/README.md/content)

时间、报告航速乘时间差和邻船计数的预设条件，使 242 张中的 32 张进入关联。210 条排除中，36 条未通过报告时差条件，41 条未通过航速乘时差条件，178 条存在作者计数的其他船，三项可重叠。32 张中有 25 张的原候选掩膜在裁块中心三个原像元内找到匹配。余下七张保留在关联分母中。25 艘在四种策略下均得到共同可测分量，其中 23 艘、18 组有正固定编辑量，另外两艘作零编辑锚点。在整个入组清单中的共同测量覆盖为 25/244，在合格影像中为 25/242。

关联固定使用原掩膜的原生排名和 AIS 中心附近八连通分量。其他策略使用与固定原分量重叠最多的分量，沿同一原分量主轴计算全像元投影跨度。10 米为名义采样间距，产品的地距向和方位向空间分辨率约为 20–23 米。作者计数基于其 AIS 记录和至少 50 米的船长筛选，报告时差基于场景中点。筛选条件无法独立核实每艘船的 SAR 回波身份。估计端点为相对于声明值的原生雷达表观长度误差，采用原栅格轴而无需与地理真航向配准。

## 船长误差

每个轨道日期组等权，对固定共同样本计算。四种策略共享同一 AIS 船长均值 193.30 米。

| 策略 | 表观长度均值（米） | 相对 AIS 平均偏差（米） | MAE（米） |
| --- | ---: | ---: | ---: |
| 原生 | 298.722 | +105.424 | 112.037 |
| 同头固定配对 | 300.357 | +107.059 | 113.190 |
| 同量独立选点 | 299.972 | +106.674 | 113.022 |
| 自然独立选点 | 300.237 | +106.939 | 113.287 |

同量独立选点的主效应在 4,096 次轨道日期组配对重采样中得出。按 UTC 日期分组的敏感性结果相同，因为这 19 个共同测量组也对应 19 个日期。分量诊断在同一 25 艘上计算。若使用整张原生掩膜，表观跨度平均再增加 8.128 米，原生 MAE 从 112.037 增到 117.370 米。整掩膜下的同量 MAE 改善量改为 **−0.358 米 [−2.197, +1.316]**。限制到中心关联分量压低了部分长度误差，原生分量的组等权平均偏差仍达 105.424 米，整体误差量级远高于本次局部精修的估计改善。

## 独立执行和证据范围

242 次冻结 RF-DETR 推理产生 24,095 个原生船类候选和 16,559 个面积合格概率平面。两种等量策略在同一批 15,986 个候选上各完成 **109,853 次**补删交换。五阶段均有实际退出 0 和有效结束摘要。影像摄入、原生推理和独立编辑验证全部闭合后，才读取用于关联的 AIS 标量。25 个 AIS 船长在四种策略的匹配分量与跨度全部冻结后读取。阶段观察耗时约 25.36、227.58、65.20、87.82 和 3.43 秒，依次对应目录、下载转换、检测器、回放和分数。各阶段耗时用于离线复现。按冻结模型和既有源域训练配置验证，新裁块未参与选型。[聚合结果及回执](results/GULF_AIS_FROZEN_ACTUAL_SAFE_20261123.json)

这轮 Sentinel‑1A 物理外测在新采集上达到正编辑覆盖门槛，未通过物理长度收益门槛。单独的 NovaSAR 结果也未达到船长改善判据。两套物理证据共同界定现有局部编辑器适合支持的主张，作者人工船体轮廓上的边界与实例分数继续各自报告。[NovaSAR 对照](NASTAR_AIS_PHYSICAL_ACTUAL_20261123.md) · [论文证据矩阵](SAR_SHIP_MASK_TGRS_EVIDENCE_MATRIX_20261112.md)

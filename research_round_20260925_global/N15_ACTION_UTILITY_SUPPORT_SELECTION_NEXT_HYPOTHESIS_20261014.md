# N15候选：从“可能错”到“当前行动确实能修”

状态：UNBOUND / 尚未正式实验前登记 / 未执行。此为N14固定24收益门失败后的下一单一研究假设，不声称创新成立。

证据：N14 MEMORY单seed同预算AP−0.003132点，低于强E24参考−0.415905点，停止扩展；此前同K GEO支持/监督联合配方三seed均负，均值−0.189583 AP点。既有374固定原生匹配条件群体中旧编辑域只覆盖22.53%错分；GEO提高至24.67%但条件oracle IoU仅+0.000728650。不能把条件覆盖扩大为全数据瓶颈证明，或把GT oracle当可部署方法/AP。

## 单一假设与关键质疑

在更宽、GT无关的候选点池中，预测既定精修行动的正/零/负效用，可能比只预测错误概率/不确定性更有效地分配相同K的精修动作。候选与收益监督须分别定义：GT可用于FIT标签及诊断，不能参与部署时候选、query或支持选择。

最强反例：更宽池含大量错误，但固定refiner根本不会正确翻转它们；或oracle更好而实际效用预测不可泛化；或收益只来自更多扫描、额外监督/参数。任一情形都不能用模块重命名或追加budget掩盖。

必须正视计算：如果为了排点先对所有候选算完整PR残差，就不能宣称仍是K点计算。考虑廉价scout从相同F/e/L预测实际refiner行动收益，仅对K点做昂贵精修；完整记录候选M、scout、全图F渲染和最终refiner成本。固定K不自动等计算。具体候选池、M/K和scout架构尚未锁定，不能提前视作最终方案。

## 最小推进顺序

1. 以旧较强701 LOG E24为固定refiner，保留native L、自然all100 query、S0和原支持规则作为直接参照。先用GT无关的更宽候选池做一次有限条件机会诊断，同时量化覆盖、实际可翻转比例、帮助/损害像素及IoU；不先训练新模型。必须包括旧LOG与简单几何/常规选择对照。
2. 诊断须区分“GT可任意纠正”的理想oracle与“只能使用此固定refiner实际输出”的行动oracle；后者无明显收益就不进入selector长训。旧374匹配群体只支持该条件范围；正式策略必须覆盖全部自然query并完整评价18,700预测。候选池本身须包含足够合法点支持K，K0及空query规则预先确定。
3. 查明直接先例的差异，再锁一次公平检验：同scout容量、输入、候选池、数据、匹配/监督预算、初始化、轮次和完整指标，比较实际行动效用目标、错误概率目标及简单置信/常规排序。额外生成行动标签的refiner调用、跨拟合及任何原E24训练数据接触均披露，不能伪称完全未见样本。
4. 实用收益按较高强参照及重复seed门判断；AP75、AR、实例IoU、像素FP/FN和成本补足范围。若oracle/覆盖上升而AP不升，否定当前配方。方法选择冻结后再做正式测试/跨集。

像素有符号正确性增益不等于IoU或AP；群体内阈值变化和固定分数下的排序/重复预测影响应保留。若只能证明工程效用，收缩机制主张；若普通错误预测/常规排序足以解释收益，不宣称核心创新。

# 四次首窗复放定位到反向传播

沿用[前瞻首窗协议](RFDETR_E24_OPTIMIZER_FIRST_GRADIENT_GATE_ACTUAL_20261108.md)，Windows CUDA 依次完成 F0、S0、F1、S1 四个独立进程。每次运行同一首四个真实增强 FIT 微批次，使用原 BF16、TF32、匹配、采样、损失和裁剪。四个原始 OS wait 均为 0，优化器和 EMA 更新均为 0。独立 CPU 读取闭合梯度和所有回执，复算六个固定配对。

| 比较 | 裁剪后全梯度相对 L2 |
| --- | ---: |
| F0 对 F1 | 0.946393% |
| S0 对 S1 | 0.921025% |
| 四个跨臂配对范围 | 0.858916%–1.135025% |

六配对、每配对四微批次共 24 个比较，输入和目标、前向张量、骨干与 patch 投影输出、匹配、点坐标、损失和记录的随机状态均一致。全部 24 个比较中，首个观测到的差异出现在传入骨干首个输出特征的梯度，此后 patch 投影的输出梯度也不同。裁剪前全局范数在 F0/S0/F1/S1 中为 192.68915/192.57358/192.72568/192.93073。骨干占复放差异平方和的 99.919%–99.999%，patch 投影权重占 88.388%–92.908%。

原配对的闭合梯度还支持单一缩放解释。对 295 个非骨干张量拟合一个 F 到 S 的比例 0.999942690，去掉它后相对残差从 5.73×10⁻⁵ 降到 6.45×10⁻⁷。原先最大的 patch 投影权重形状为 384×3×12×12，贡献 91.499% 的平方差异。同臂在任何参数更新前已出现接近跨臂的差异，因此 AdamW 历史并非产生所观察不一致的必要条件。证据定位到反向阶段，还不能归因到某个具体 CUDA 算子。原实验的首梯度资格仍失败，DEV/TEST 和 AP 未发生。 [复放安全结果](results/RFDETR_E24_FIRST_GRADIENT_REPLAY_ACTUAL_SAFE_20261108.json) · [裁剪缩放安全结果](results/RFDETR_E24_FIRST_GRADIENT_SCALE_PATCH_SAFE_20261108.json) · [可复核源码](code/RFDETR_E24_FIRST_GRADIENT_REPLAY_20261108)

## 双线性采样反向的定位试验

RF-DETR 的可变形注意力与掩膜点采样在 CUDA 上使用双线性 `grid_sample`，PyTorch 官方记录该算子的 CUDA 反向可能出现不可复现结果。因已观测到骨干收到的梯度先分叉，先检验位于下游的采样反向。固定新窗口的 CUDA 前向、自动混合精度、匹配和点坐标。仅对有梯度的二维 CUDA 双线性调用，以同一算子的 CPU 实现计算反向，转回原设备和类型。运行两次同一 F 初始化的首窗，零更新，核对完整前向逐字节一致，并记录实际替换次数、形状范围及成本。

只有改动前后的输入、前向、匹配、采样与损失一致，且新同臂裁剪后相对 L2≤10⁻⁵、余弦≥0.999999，才支持这组双线性采样反向在当前首窗中解释观测差异。局部下降将按部分证据报告。替换覆盖多个调用点，仍需区分可变形注意力与掩膜点采样。该试验只用于定位，不改变原配对资格，也不批准完整训练。 [固定 RF-DETR 可变形采样源码](https://github.com/roboflow/rf-detr/blob/639eac4555ceb89ef399ccda3fde716bbcfe34cb/src/rfdetr/models/ops/functions/ms_deform_attn_func.py#L74-L88) · [PyTorch 原算子说明](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.grid_sample.html)

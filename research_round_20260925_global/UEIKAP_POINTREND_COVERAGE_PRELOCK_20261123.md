# Frozen whole-RoI PointRend and native hull coverage on UEIKAP

The earlier 108-chip UEIKAP study had 100 adequate box associations on 139 released hulls but only 17 native-mask matches. Ideal eight-pair equal-area edits increased coverage to 18. The 342-chip historical evaluation retained 407 unmatched hulls among 528. Test whether already source-fitted whole-RoI refinement raises actual mask coverage when candidates, boxes and scores remain unchanged. The alternative is that the available coarse query and the same source-trained point head cannot recover the missed hulls at its existing rendering footprint. The previously reported 108-chip bound motivates the test. [108-chip geometry](UEIKAP_RFDETR_CANDIDATE_GEOMETRY_ACTUAL_20261122.md) · [342-chip results](UEIKAP_ADDITIONAL_FAMILIES_ACTUAL_20261123.md)

Use all 342 original native PNG chips, 528 released hull polygons and 13 acquisition families from the accepted 342-image study. The cohort belongs to the same Danish-region release and has prior evaluation exposure. Keep HRSID RF-DETR center5202 E24, val576 preprocessing, joint-class top 100 and native ship identities, rankings, confidences and clipping exactly. Recapture only the detached projected mask bases needed to run the existing PointRend adaptation. Require exact original image digests, candidate identities, scores, boxes, native masks and eligible raw logit planes. Reconstruct the native logit planes from the retained bases and query weights as a further identity check. Use the original UEIKAP CUDA numerical settings. No source or target training is part of this experiment. [Prior capture](code/UEIKAP_ADDITIONAL_FAMILIES_20261123/README.md)

The three comparison arms are N, the original mask; C, the rough query sampled at the same 56-by-56 RoI and pasted by the same operator; and P, the existing single FIT109 PointRend head rendered and pasted over that entire RoI. Use the same input features, point rendering, chart geometry, interpolation, threshold and original area range [32,1024) as the previously published carrier adaptation. Unsupported areas and degenerate boxes retain the native mask. Retain empty P outputs and all native candidates. C shares RoI mapping, coarse query, paste threshold and output support with P. Only P performs point subdivision. Both output populations must close and pass independent render verification before labels enter scoring. Report actual per-path counts, changes, time and feature capture cost. [PointRend original](https://arxiv.org/abs/1912.08193) · [Source fit and previous adaptation](INSTANCE_RSDD_POINTREND_TRANSFER_ACTUAL_20261122.md)

Score each arm separately with the original score-ordered, one-to-one greedy hull assignment using raster mask IoU. Primary threshold is 0.50; also report 0.75. Pair matched status by actual author hull within each image. Keep all 528 released hulls in every arm, zero matched status for all missing hulls, original acquisition identities and equal family weights. Rerun the original native N matching and reproduce the prior 121/528 native count. Report changed-status matches, newly covered and lost hulls, per-family results and equal-family mean. Use 4,096 paired family bootstrap replicates with PCG64 seed 5217 and ordinary 95% percentile bounds. Case-focused author labels support released-hull coverage; complete-scene precision, recall and AP require exhaustive scene labels.

As a fixed-candidate check, associate each labeled hull using the original score-ordered box IoU 0.50 matching rule and reuse that association for all three mask policies. Report polygon IoU and true intersection or FP/FN normalized by polygon area. Include the all-hulls paired difference with zero contribution for hulls without a box association. Also report the prespecified weak subgroup whose original associated mask has raster IoU below 0.50, including no-op policies and the number crossing 0.50. Fix this group solely from original native masks and associated boxes. Retain all exact signed adds/removals and area changes in masks. The paired fixed-box contrast checks shape changes without the alternative explanation of reassignment between queries.

Advance the whole-RoI recipe only if P exceeds both N and C in primary group-equal .50 released-hull matched fraction with both lower paired 95% bounds positive, at least 20 changed per-hull match indicators in at least eight families versus each, and positive lower bounds for P minus N and P minus C in fixed-box continuous IoU on the all-hull denominator. Report all results regardless of advancement. The threshold and cohort stay fixed even if only one contrast improves. No rotated or expanded boxes, no new detector filtering, no target tuning or new source refits. This tests mask recovery within an exposed release. The distinct Umbra blind-review test remains a separate geographic validation and does not enter this analysis.

# 原生 CUDA 前向与 CPU 双线性反向的实际对照

依[预注册方案](RFDETR_E24_FIRST_GRADIENT_REPLAY_ACTUAL_20261108.md)，对同一 F 初始化实际运行两次固定首窗。各四个 FIT 微批次，两个原进程退出 0。每次有 36 个可微二维 CUDA 双线性调用通过原算子前向和 CPU 原生反向完成，未发现未路由的同范围调用。CPU 反向与传输分段耗时分别 0.1812 和 0.1710 秒。两次独立复算验证原生 CUDA 前向、匹配、点坐标、损失和随机状态逐字节相等。实际更新、EMA 更新均为 0。

替换后同臂的全量裁剪梯度相对 L2 为 **1.096200%**，余弦 0.999939917，仍超过预锁 0.001% 容差。四个微批次均在传入骨干第一个输出特征的梯度首次观察到分歧。原生两次 F 的相对差异为 0.946393%。此次两个运行无法估计替换对差异幅度的期望影响。当前可作的判断是，**只替换该范围的双线性采样反向不足以消除差异**。它仍可能是多个来源之一。原 F/S 优化器效用资格维持失败，未读取 DEV/TEST。 [独立安全结果](results/RFDETR_E24_GRID_BACKWARD_CONTROL_ACTUAL_SAFE_20261108.json) · [诊断源码](code/RFDETR_E24_GRID_BACKWARD_PROBE_20261108/grid_backward_probe.py)

## 单图双反向定位

在完全相同的首个 FIT 真实增强微批次上执行一次原生前向，保留同一计算图，重新清空参数梯度后重复反向。用有限的被动 autograd 节点观察比较两次反向的入梯度和出梯度。优先检查投影卷积、注意力、双线性采样、上采样和索引归约。若某节点两次收到的张量完全相同、传出的梯度不同，记录为实际局部差异来源候选。若观察改变执行时序或未复现差异，保留诊断范围限制。零优化器、EMA 更新，未触及 DEV/TEST；定位后才锁定最小复现修正。

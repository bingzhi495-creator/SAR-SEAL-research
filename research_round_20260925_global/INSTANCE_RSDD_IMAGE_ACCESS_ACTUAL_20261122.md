**原始 RSDD-SAR 影像可以公开分段获取。Instance-RSDD 的人工船体标注仍待取得。** 已用 Point2RBox-v2 作者提供的 Google Drive 镜像实际读取 ZIP 前缀、尾部、中央目录和一对公开示例文件。标准下载确认页无登录要求，这些读取均返回 HTTP 206。文件总长 1,334,274,952 字节，中央目录 1,040,704 字节，SHA-256 `0d270fdb35120a341dff3940790d13173d603ee05b99ec9dd57efa1f82521d9e`。7,000 张 JPEG 与 7,000 份旋转框 XML 按文件名全部一一对应，另有 2 张未切片图像。[固定镜像入口](https://github.com/VisionXLab/point2rbox-v2/blob/932576b104c153b030175e42c5af1baac73999cf/tools/data/rsdd/README.md#download-rsdd-dataset) · [公开 Drive 文件](https://drive.google.com/file/d/1PJxr7Tbr_ZAzuG8MNloDa4mLaRYCD3qc/view?usp=sharing)

样本 `86_6_14` 的 JPEG 和 XML 均通过 ZIP CRC32 检查。JPEG 可解码为 512×512 RGB，XML 的 VV 极化、3 米分辨率和框参数与原始发布说明示例一致。字段为旋转框，`segmented=0`。雷达学报的整包入口在本次检查返回 403，原始发布的 139,738 字节说明 PDF 可直接取得，其 SHA-256 为 `9b8644095284654b3d93097066c279ac48684046fb467f59eb409b92cc0254cf`。[原始数据说明](https://radars.ac.cn/fileLDXB/cms/news/info/2022/07/af9ec429bab44aa49d5e506c54b98283/RSDD-SAR%20Dataset%20Instructions.pdf)

镜像根目录亦有四份同名格式的转换 JSON。分段取得并经 ZIP CRC32 核验的 `train.json` 含 5,000 张图和 7,271 个实例，所有 `segmentation` 均为一个四顶点多边形。文件大小 1,555,850 字节，SHA-256 `30959dd306c077b2c00e0b44879b18345bb77c5f6ece3055298a9d3169e46259`，与 Instance-RSDD 作者的训练标注大小和成员数均不同。它只能作为原旋转检测数据的转换版本。本次仅取得源索引、样本与这一训练 JSON，测试 JSON 只核对目录。[镜像来源](https://github.com/VisionXLab/point2rbox-v2/blob/932576b104c153b030175e42c5af1baac73999cf/tools/data/rsdd/README.md#download-rsdd-dataset)

原始论文完整 PDF 已下载并解析附录表 1，SHA-256 `2ea1bf0486b701a385829128a0274f4e54f2fcea991eb1d942eda37d4c71bc6a`。表中 127 个景号含 125 个裁块来源以及 2 个未裁块来源。125 个裁块来源有 193 个带编号的极化产品。镜像出现 188 个前缀，全部能映射至论文的 125 个来源。高分三号 84 景、5,629 图，TerraSAR-X 41 景、1,371 图，均为原始旋转框数据镜像的计数。多极化的前缀需合并到论文景号。该映射可用于核验未来取得的 Instance-RSDD 划分，当前尚无该划分的影像清单，无法核验其与 HRSID、PSeg-SSDD 的独立性。[原始论文与采集表](https://files.sciengine.com/pdfs/2095-283X/23A1C428928844EC809FB12C4F5A7A6B.pdf)

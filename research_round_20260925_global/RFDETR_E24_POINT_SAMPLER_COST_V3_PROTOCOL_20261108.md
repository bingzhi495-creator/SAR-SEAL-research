# RF-DETR 分层采样 V3 成本复测锁定

V2 的 GPU 实测中，分层对均匀的配对前反向中位时延比为 1.10255，超过 1.10。V3 仅改变分层实现中重复查询的发射方式。每个唯一 GT 的匹配行分组后按层批量独立有放回抽样，再用逆置换恢复原匹配顺序。每个位置的抽样分布、每实例点数、面积权重、损失目标和原生 Dice 规则相同。V3 在固定种子下的具体点序列与 V2 不同。六项分配测试覆盖乱序恢复、独立重复抽样、面积权重和补集枚举。

在同一台本机 GPU 上沿用 V2 的八图、16 组配对、增广种子、输入组顺序和三臂预热。沿用逐次全部梯度有限、五层 Dice 最大绝对差至多 $10^{-6}$、D/B 配对前反向时延比中位数至多 1.10 的门槛。V2 结果作为失败历史独立报告。该复测以 V3 的新原进程为准。 [V2 实测](RFDETR_E24_POINT_SAMPLER_COST_V2_ACTUAL_20261108.md) · [共同成本协议](RFDETR_E24_POINT_SAMPLER_FULL_STEP_COST_PROTOCOL_20261108.md)

# 直接先例点头的最小公平对照设计

日期：2026-10-13。状态：**普通设计文档；下述新对照均未执行、未形成科研结论**。本轮只读取独立 GitHub 发布副本的综述与源码文本，并核查原论文和作者代码；没有读取或哈希原科研 RAW、SPEC、GT、权重或缓存，没有导入科学代码或运行数值。

## 1. 当前问题与证据边界

ROOT 提供、此前已核验的固定协议事实：冻结同一 Mask2Former/R50 E24 后，原生 DEV mask AP 为 67.0710566；C 的两个下游种子均值为 68.1661355。C 使用原生空间特征 F、最终 mask embedding e 和原生 logit L，在原图预测不确定带内增加共享点 MLP 残差。当前全局 FIT-only 偏移的 GPU 与独立 CPU 核验均已真实退出 0，DEV AP 为 67.1466401；它没有达到预登记的近似替代规则。完整范围见 [核验结果](N09_FIXED_GLOBAL_OFFSET_RESULT_20261013.md)。本文不独立重算这些数值；下述 PR/IPR 新对照仍未执行。

该已核验偏移结果只能说明这一个 FIT 拟合、斜率固定的全局偏移未近似替代 C；不能据此证明显式 e、空间 F、新颖机制或 TGRS 级创新成立。L 本身由 e 与 F 的点积及既定渲染得到，去掉点头的显式 e 拼接仍然保留了实例信息；因此禁止把下述对照称为“无实例条件头”。

本轮只保留一个主问题：**在同一冻结表征、采样点、候选和预算下，C 是否比普通的粗掩膜条件共享点头具有可重复的实用收益？** 支持性问题是：若存在差距，显式拼接 e 是否比已有的动态参数条件化更有价值。这里的“有价值”首先指本项目固定开发协议，尚不是新颖性结论。

## 2. 已有先例要求我们面对什么

PointRend 以共享点 MLP 结合图像特征与实例粗预测；原实例分割配置使用 P2 特征、三层 256 维隐藏层，并在各隐藏层再注入 coarse prediction。训练点偏向不确定位置，推理使用自适应细分。这些原语都已有明确先例。[原论文 §3–4](https://arxiv.org/html/1912.08193v2)、[作者点头代码](https://raw.githubusercontent.com/facebookresearch/detectron2/main/projects/PointRend/point_rend/point_head.py)

Implicit PointRend 则为每实例生成点 MLP 的全部权重和偏置，输入图像细粒度特征及框内相对坐标编码；它不依赖 coarse mask。完整掩膜监督配置使用均匀点采样。仅拼接 e 的共享 MLP 不等于这一动态参数机制。[原论文 §4](https://arxiv.org/html/2104.06404v2)、[作者实现](https://raw.githubusercontent.com/facebookresearch/detectron2/main/projects/PointRend/point_rend/point_head.py)、[坐标与采样代码](https://raw.githubusercontent.com/facebookresearch/detectron2/main/projects/PointRend/point_rend/point_features.py)

以下设计均是**冻结 Mask2Former 载体上的结构适配对照**。统一缓存、残差输出、不确定带、固定评分和 dense 原图推理用于隔离当前机制，同时改变了作者方法。不能称官方完整复现，也不能与原论文数字跨协议排名。

## 3. 首先执行一个强且便宜的 PointRend 式适配

推荐名称：`PR-FL-91`，中文为“粗掩膜条件共享点头适配”。

输入保持同一 `LN(F256)` 和 `c=clamp(L,-8,8)/8`；不额外拼接 e，不读取 JPEG patch，不引入坐标或新的 fine feature。使用三层 ReLU 隐藏层，宽度 91，并保留作者共享头的 coarse 再注入形式：

```text
[LN(F), c]257 → Linear91 → ReLU
[hidden91, c]92 → Linear91 → ReLU
[hidden91, c]92 → Linear91 → ReLU
[hidden91, c]92 → Linear1 → u
L' = L + u，限于原生 |L|≤2；带外 L'=L
```

末层权重和偏置零初始化，使冷启动输出为原生 L。无需新增图像前向、缓存人口或监督；首先验证零残差退化、梯度路径和独立评价 ABI，然后才由 ROOT 绑定并执行。这里没有提出新算法，只是让已知共享头成为可信的竞争解释。

### 参数与计算的公开账本

下表为逐层尺寸的静态代数计算，**不是运行性能测量**。MAC 指 Linear 的乘加，不含 LayerNorm、ReLU、门控、渲染、特征搬运、优化器或运行框架开销；不能把它直接转换为实际时延。

| 头 | 结构 | 总学习参数 | 零 patch 输入下的函数相关参数说明 | 每点 Linear MAC |
| --- | --- | ---: | --- | ---: |
| 已有 C | 562→64→64→1 | 40,257 | 49 个恒零 patch 输入列对应 3,136 个权重不影响当前函数；余下为 37,121 | dense 执行 40,128 |
| 推荐 PR-FL-91 | 257→91；92→91；92→91；92→1 | 40,497 | 无人为补零输入列；不是严格数学等效容量证明 | 40,223 |

PR 参数仅比 C 总参数多 240，单点 Linear MAC 多 95，而且没有 C 的恒零输入列。对照因此不会因为简单移除 e 同时大幅缩小头而天然变弱。但宽度、深度、再注入及条件方式不同，近似参数/MAC 预算仍不能证明相同函数类或优化难度。

C 的两项 LayerNorm 均无 affine 参数；所有 Linear 偏置计入上述数字。恒零列对输入损失没有贡献，不代表这些权重在 AdamW 下绝不变化：weight decay 可以改变它们，但仍不能经恒零输入影响预测。不得将 37,121 写成严格等效“可训练容量”，也不改写历史 C 源码以删除这些列。

单纯把 e 置零、保持原宽度的 `C-e0` 可以作为后续廉价消融，但会同时减少函数相关自由度，**不作为首个强对照**。本轮也不追加多组宽度后挑选有利结果。

## 4. 同预算训练与评价协议

首阶段只比较已有 C 与 `PR-FL-91`，优先完成两个配对下游种子；对照预算固定为 **8 轮、每头 13,288 次更新**。固定末轮，不从 DEV 选择 best epoch。只有完整数据、初始化、缓存、训练长度和评价输入能够被 ROOT 核验一致时，才允许复用历史 C 端点；否则在新的同协议阶段同时重跑两臂。

| 项目 | 必须相同或必须公开的规则 |
| --- | --- |
| 载体 | 同一冻结 E24；不更新骨干、pixel decoder、query、mask embedding 或分类头 |
| 数据 | 原有 FIT/DEV 划分，FIT 741 图、1,661 个 GT；不额外用 DEV 拟合，不改变官方/历史划分身份 |
| 训练点 | 复用经 ROOT 独立核验的每 GT 1,024 点：768 个原生不确定带点与 256 个全图均匀点；固定点跨轮重复、有放回、保留重复，空带沿用既定规则 |
| 监督与匹配 | 同一冻结教师一对一分配，每 GT 一次 instance-mean BCE 更新；不能只为新头改变 GT 匹配、类别筛选或采样人口 |
| 优化器 | 与 C 相同 AdamW：lr 3e−4，weight decay 1e−4，betas=(0.9,0.999)，eps=1e−8；恒定 lr，无增广，无梯度累积，不增加新头专属调参预算 |
| 随机因素 | 同一两个下游种子 202610120701、202610120702，配对图像及实例顺序；不同形状网络不能声称具有相同初始权重，只要求私有种子、初始化分布与原生冷启动规则明确 |
| 推理 | 同一原图网格、原生不确定带、输出阈值、全部 100 候选及顺序；沿用原生类别与 S0，不加 NMS、不重排、不删除空掩膜、不以 GT 选择 query |
| 独立核验 | 原生全部候选及评分必须精确复现；新头实际终止后独立检查输出人口、身份、固定分数和 COCO 全量统计；不得修改一致性门槛以获得通过 |
| 性能成本 | 同设备同约束测量完整 head 训练/推理时延、峰值显存、处理点数及原生教师额外成本，分别记账，不能用静态 MAC 或仅评价耗时替代完整成本 |

同一短预算只用于检验该预算和配方。无论 PR 在 8 轮好坏，都不能据此宣称普通 PointRend 总体无效或 C 已达到充分收敛。若需要充分训练比较，必须在读正式测试结果之前建立新资格阶段：两臂都以同样的 24 轮固定预算、相同优化器连续性规则和至少三个下游种子运行；不能只延长 C。是否延长与具体成本由 ROOT 在启动前登记，不利用 DEV AP 临时修改轮次或宽度。

## 5. 什么结果能改变研究判断

主表必须同时列出每个种子、均值及配对 `C−PR`，不是只列最好种子。首阶段不设读结果后可修改的“发表级”门槛，也不将两个种子当统计显著性证明。

| 实际结果 | 允许的解释与下一步 |
| --- | --- |
| PR 两种子接近或优于 C | 普通粗掩膜条件共享头能够解释当前效用；显式 e 的必要性没有成立。保留工程效用，停止把该结构差异当已确认核心贡献。转向实际剩余误差分析 |
| C 两种子均优于 PR | 显式 e 拼接及其结构组合在该固定预算下有候选价值；仍混合了条件方式、宽深与优化因素，不证明 e 的独立因果作用或新颖性。进行同预算长训及第二先例适配 |
| 差距换号或差距很小 | 判断未决；保留全部结果，先报告配对波动，不挑种子、换 DEV 或选择最好 checkpoint |
| 一臂实现/资格失败 | 记录为实现或执行失败，不能计为低 AP；修复必须形成新 SOURCE 与新预登记阶段，不覆盖失败原件 |

像素诊断使用由原生预测预先固定的 query–GT 配对，分别报告增加/删除面积以及 FP/FN 变化；官方 COCO 的逐阈值重新匹配结果另列。若只看到 AP 而没有局部几何改善，不能写成已解决船体轮廓、近岸杂波或相邻船舶问题。若进一步使用 Boundary IoU，应固定边界带定义并引用作者方法，不在结果后选有利边界宽度。[Boundary IoU 原论文](https://openaccess.thecvf.com/content/CVPR2021/html/Cheng_Boundary_IoU_Improving_Object-Centric_Image_Segmentation_Evaluation_CVPR_2021_paper.html)

## 6. 第二优先级：Implicit PointRend 动态参数机制适配

只在首个 PR 对照之后决定是否执行，不与首阶段堆成大量模块。推荐先做机制隔离版：`IPR-e-dynamic`。由 `LN(e256)` 通过一个可学习参数生成器，为每个 query 产生三隐层、宽 64 的点 MLP 全部权重和偏置；点输入保持同一 `LN(F256),c`。预测相同带内残差，保留相同 L、S0、候选及采样点。**把 L 加为点输入、暂不加 Fourier 坐标，都是显式适配差异**；该对照不是完整作者方法。

最直接且不刻意压弱的生成器为 affine `256→24,897`：动态点函数尺寸为 `257→64→64→64→1`，每实例生成 24,897 个数，总学习参数为 6,398,529，单次参数生成约 6,373,632 MAC、单点评价约 24,704 MAC。生成一次后在同一 query 的各点重用。这里总参数明显大于 C，虽然逐点乘加更少，**绝不能声称容量或总计算已匹配**。可作为额外容量更充足的条件函数竞争解释，并与 C/PR 一起公开训练和推理成本。

不要为了凑 40k 参数把动态点函数缩到极窄后，以失败声称 Implicit PointRend 不如 C。若资源不足以运行上述生成器，先完成 PR 对照并记录限制，而不是隐藏低秩、瓶颈或宽度缩减。任何缩减版都必须列结构差异，且不能替代较强动态先例。

冷启动也不能把全部生成参数设为零，否则 ReLU 隐藏函数可能退化且失去有效梯度。一种待实现方案是生成器权重零初始化、其 bias 填入私有种子生成的隐藏层初值，最终输出层初值为零；这些 bias 本身仍可学习。这只规定原生恒等初始化，不声称与 C 的随机权重相同。实际梯度、数值与内存由 ROOT 在绑定前独立资格检验，本文不做测试。

若动态适配接近或优于 C，当前显式拼接不能被包装为优于已有实例条件函数；若 C 在足够训练后仍有稳定优势，也仅支持当前适配的性能/成本差异。为了论文中的强先例结论，后续仍需保留作者 relative-coordinate encoding、适当 fine feature、采样及细分推理的完整配置证据。

## 7. 不能由这两个结构对照回答的事

**空间 F 是否独立必要**还没有被隔离：C 与 PR/IPR 都读取 F，且 L 已编码 e·F。要主张 F 的独立作用，需要另设仅 L 的非线性控制与合适的容量账本；不能从“全局偏移不够”直接跳到“空间 F 必要”。该额外控制不是本轮优先训练清单。

**真正 fine/image 信息是否必要**也未确认。当前 F 来自冻结 pixel decoder 的原生 mask feature，即使插值到原图，仍不是新取到的图像细节；真实 JPEG patch 也不等价于学习的 FPN P2。若研究方向转向补细节，须新建固定教师的 fine-feature cache，并在相同点集上比较 C、PR 及动态条件头都可读取该特征的配对版本。这样才能把特征源与头结构分开。禁止仅让 C 多一种输入，再把收益归因于 C 结构。

完整先例的采样与推理还需单独登记。PointRend 原配置的动态不确定点选择/细分、Implicit PointRend 的均匀监督与相对坐标，与本轮固定 band 缓存不同。统一采样有利于结构隔离，却不能代表作者整套算法效能。跨数据集、正式测试、教师种子波动、充分训练与核心创新差异均仍未完成，不在本文预先承诺。

5. 经核验的状态及普通设计/SOURCE 随形成同步 GitHub；未执行设计仍明确标待检验。本文不生成新交付包，不上传科学缓存、GT 或权重。

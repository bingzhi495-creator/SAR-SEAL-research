# Same-side edit quotas for frozen refiners on PSeg-SSDD

This replay tests whether a fixed pretrained ranker retains a disadvantage when both endpoint support and actual addition and deletion counts are matched. Free-signed narrow Phoenix (NC) on PSeg-SSDD previously achieved 16.380 mask AP. The source-trained occupancy ranker and static spatial attraction achieved 18.331 and 18.417 AP with the same endpoint set and total flips but equal side counts. The present contrast is a follow-up on these disclosed outcomes. The 74-image Instance-RSDD experiment already compared equal side counts. It is a historical companion, with another carrier.

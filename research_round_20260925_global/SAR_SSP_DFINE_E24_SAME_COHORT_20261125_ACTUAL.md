# SAR-SSP 上 D-FINE E24 同队列冻结复验

这一复验在 RF-DETR 的 SAR-SSP 结果完成后预先锁定，使用同一作者验证划分。D-FINE 载体是 COCO 初始化并在 2,937 张 HRSID FIT 图块上训练至第 24 轮的存档 EMA。其 1,321 参数占用头及标准化器来自 HRSID FIT109 的已核验全量固定拟合。全部对照复用同一 D-FINE 候选、框、分数、顺序和原生栅格。D-FINE 与其占用头均没有接触 SAR-SSP 进行训练或选择。此比较检验同一队列上更换整套载体后结果是否保持，无新增留出队列，也不能把两套结果差异唯一归因于检测器架构。

捕获阶段记录 232 次 CUDA 前向及 25.3 秒执行耗时，其中前向和后处理用时 17.6 秒。全部 59,054 个原生 NMS 后掩膜通过作者二值路径对照。每张图保留原顺序前 100，共 23,200 个候选，其中 7,256 个为空掩膜，全部进入评分。冻结编辑保留 11,310 个面积合格候选，其中 10,797 个内外端点均有效。固定距离配对与同量独立两臂均在 8,201 个候选执行 39,546 次成对交换。三个吸引力预算臂均在 10,393 个候选执行 73,559 次交换。自然量两臂均在 10,484 个候选执行 62,760 次交换。所有编辑面积不变。

D-FINE 没有在该队列提高实际原生候选覆盖的总量，且每套载体的受影响船体均足够核对原锁定比较。两个同量排序结果对 SAR-SSP 的实用提升均有限。框 IoU 是与作者轴对齐掩膜框的逐船几何上界，允许同框被复用；原生掩膜匹配按 COCO 分数一对一完成。逐船集合在载体间可能重叠或不同，表中总体计数不支持严格的逐船覆盖集合大小结论。

首次 CPU 准备在 NumPy 版本门槛处退出，尚未写入编辑数据或读取目标标签。采用独立路径下的 NumPy 1.26.4 恢复既有数值运行要求，原协议、捕获数据和工作程序均保持。随后捕获、准备、独立重放和评分各自观察到退出 0 和对应结果尾签。独立 CPU 重放逐字节核对同一编辑流，并验证真实像素增删数量和盒内边界支持后，评分器才打开作者标注。本轮没有优化更新。

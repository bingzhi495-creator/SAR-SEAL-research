# Frozen D-FINE third-carrier evaluation on the historical Instance-RSDD reserve

## Question and locked input

The primary question is whether the equal signed-count advantage of independent endpoint selection over exact displacement-capped re-pairing also appears on D-FINE-seg. The prior RF-DETR comparison was positive on the 74-chip reserve for mask AP and continuous IoU. The SRNet and PointRend checks showed weaker or uncertain effects under their fixed configurations. The D-FINE source-development result supports trying the same idea with an independently frozen detector and source head. This is a previously scored target cohort and the detector and occupancy head both change across carriers. Within the new carrier all decision arms share the same detector, scorer, supports, candidate counts and realized budgets. ## Control arms

Apply the existing D-FINE native support in [32,1024) foreground cells, native box and two inner/outer Chebyshev rings. Retain at most 32 coordinate-matched endpoints on each side from the source rule using the original native response, row order and 14 features. Use the established factorized F, L and I solver sequence under the same frozen head. N is the unedited native mask. F is the original minimum-square-distance assignment followed by positive score gains, limited to K=min(8, floor(area/10), n), with the original order and ties. Let k be the actual number of pairs selected by F and r² be the longest selected squared distance for k>0. L maximizes the original exact predicted gain over k disjoint pairs within r². I chooses the k best sites on each side without requiring a pairing. Use the released exact bounded solver, including its binary32 probability ordering and tie rules. Prove F objective <= L objective <= I objective, cap feasibility for L, and valid signed k/k writes for all three. Unsupported and zero-budget rows are native; no candidate renumbering or score modification. Run independent readback of the selected masks, support and realized counts before target author scoring. Publish safe sums of candidates, areas, edits and caps with no raw records.

## Evaluation and interpretation

The only reference is the exact author train-side instance polygons corresponding to the historical 74 images (81 hulls) and nested 42 (47 hulls). Bind the original published reserve selection, canonical annotation identity and original author version. Freeze each new D-FINE native score-ordered one-to-one raster IoU 0.50 instance matching; preserve its full denominator and report unmatched, polygon-ineligible, native-area-ineligible and zero-edit counts. Use valid native fixed matches whose initial mask has 32 to 1,023 cells, including eligible no-ops, for primary continuous polygon/cell geometry. Report all-author sensitivity with zero effect for unavailable matches. No forced parity with RF-DETR match counts. Use the published parent and sensor–date map, equal parent weights and 4,096 paired block draws with PCG64(5217). Also report parent draws, AP, AP50, AP75, AP90, APsmall and AR100 over the full original prediction stream, continuous IoU and normalized FP/FN, and changed eligible fixed matches/groups. A native one-pixel Boundary IoU companion and width-two sensitivity use the same native fixed matches and author rasterization as the previous audit.

Primary full-view I minus L qualifies as positive when mask AP improves by at least +0.30 points, the fixed-match continuous IoU block interval lower bound is strictly above zero, and at least 20 changed eligible matches cover eight sensor–date blocks. Apply the symmetric rule for decline. Report L minus F, I minus F and each edited arm versus N regardless, and the nested view as sensitivity only. A positive result supports the tested D-FINE pipeline on this historical cohort. Different detections and separately trained point heads mean it is not an isolated network-architecture intervention. Confirmatory prospective evaluation still uses a truly new frozen acquisition cohort. Archive all outcomes, observed terminals, protocol, verified source and flags, and release aggregated results without private imagery, labels, weights or predictions.

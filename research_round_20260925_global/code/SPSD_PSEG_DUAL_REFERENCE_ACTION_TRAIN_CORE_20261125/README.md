# Fixed-budget signed action training core

Use CandidatePacket with per-candidate native features shaped (points, 2, 14), binary occupancies shaped (points, 2, 2) in PSeg/SPSD order and label-blind signed action weights shaped (actions, points, 2). Feature column 0 is the native decoder probability. The point-side axis is addition, then deletion. Compute weights as candidate-writer foreground minus static-writer foreground, so the deletion coefficient already carries the negative sign. Pass the original positive per-sign quota, exact decoded group and image identity. Supply the pinned original train_core.py source path to train_matched_action through the source_core keyword. That source defines the reused two-output head and fixed batch sampler.

The returned models have keys bce and bce_signed_action. Both use seed 5297, 1,000 AdamW steps, 64 candidate draws per step, and identical batch and initialization identities. Candidate masking balances ragged points and actions before averaging. The action term takes SmoothL1 beta 0.1 between the two references' predicted and actual signed intersection deltas divided by twice the original quota. Its coefficient is 1.0. The BCE arm computes the detached diagnostic. Audit includes observed optimizer step and candidate counts, valid point/action exposure, model identities and loss components. The existing prediction API applies to both fitted heads.

For synthetic verification, set SPSD_ACTION_SOURCE_CORE to the exact prior training source path and run test_train_action_core.py with the project Python environment. Tests cover exact signed arithmetic in both references, real optimizer counters on ragged synthetic candidates, shared initialization and draws, identical trained tensors when every change is zero, and rejection of mutually inconsistent incumbents. Module code has no label or score file reader. Candidate eligibility, label-blind writer construction, sealed FIT provenance and separate validation remain responsibilities of the caller.

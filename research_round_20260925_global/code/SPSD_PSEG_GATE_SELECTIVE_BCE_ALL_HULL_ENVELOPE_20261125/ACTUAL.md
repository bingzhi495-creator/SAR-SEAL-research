# 全船体固定切换名额的联合上限

本次复算使用此前 183 张源域留出图和 180 个解码组。共有 8,706 个学习版与静态版掩膜不同的正预算候选，逐图及逐预算层的名额在读取标注前固定，合计切换 2,844 个候选。PSeg 和 SPSD 各自保留原生 0.50 匹配及全部作者标注。PSeg 为 411 艘、311 个匹配、229 个具备切换资格的匹配。SPSD 为 410 艘、308 个匹配、231 个具备切换资格的匹配。两份参考的静态版与全采用学习版固定 IoU 均与原评分在 1e-12 点内一致。[预锁](PRELOCK.md)

| 目标 | PSeg 上限 | SPSD 上限 | 同时较小增益的上限 |
| --- | ---: | ---: | ---: |
| 相对全采用 BCE 联合写回，固定 IoU 百分点 | +0.071904 | +0.104786 | +0.058554 |

每套参考先以原图完整船体数归一化，再按图与解码组聚合。在每个独立的图像及原编辑量分层内，按同一加权表达式选择固定数量的候选，可精确最大化两参考的加权平均。任意方案的双参考较小增益至多等于其加权平均，因此预锁的五种权重所得最大值中的最小值构成联合上界。PSeg 权重 0.75 给出最紧上界。权重 0.50 生成一个可行方案，PSeg 提高 0.046753 点，SPSD 提高 0.075511 点。两者把该固定菜单的最佳较小增益限制在 0.046753 至 0.058554 点之间。

0.058554 为预设双参考 +0.15 点推进门槛的 39.0%。现有静态／BCE 联合菜单与分层名额下，即使使用两套标注挑选，同一留出队列也达不到该固定 IoU 门槛。该结论覆盖原两份全船体口径，范围限定为这一组候选、参考与采用名额。AP、其他菜单和其他队列没有同样的上界。

CPU 工作体 5.43 秒，观察 6.12 秒，实际退出 0 且结果尾行通过验证。三项解析核验检查了加权逐层最优、联合上限和原生排名平局规则。一次早期观察目录设置错误发生在科学工作进程启动前，修复目录后按原预锁执行。 [聚合结果](actual/RESULT_SAFE.json) · [退出回执](observed/TERMINAL.json) · [复算入口](all_hull_envelope.py)

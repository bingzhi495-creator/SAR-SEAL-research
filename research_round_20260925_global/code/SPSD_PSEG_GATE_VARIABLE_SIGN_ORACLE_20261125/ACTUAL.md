# 固定总翻转量下的增删分配上限

在同批 183 张已见作者训练留出图上，原 D-FINE 候选与早期 BCE 联合写回、原生双侧端点和每个候选的总翻转量 2k 保持固定。标签前验证了 8,785 份正预算候选的两种原写回、57,692 个原增点及等量原删点。只在两份作者参考均原生匹配到同一候选的 206 艘正预算船体上估计效应，分布于 109 张图、107 个解码组。所有 183 图和 180 组保留在分母，PSeg 与 SPSD 的原船体总数分别是 411 和 410。没有共同匹配或原预算为零的船体贡献零。[预锁](PRELOCK.md)

每种分配先固定新增数 a 和删除数 2k−a，再对四类双参考占用进行精确动态规划。可行点计数给出两个交集面积，固定分配下 IoU 随交集单调增加，因此保留两参考的非支配状态即可。每个候选选择两套参考归一化 IoU 增益中较小者最大的方案。206 个严格等量极值均由旧的全枚举独立复现，结果报告群组间的同一重抽样。

相对严格等量真值求解，小幅放宽的逐船较小增益增加 0.2215［0.1779，0.2677］点，PSeg 增加 0.2096，SPSD 增加 0.1161 点。全范围放宽增加 1.0604［0.8178，1.3170］点，PSeg 增加 1.0948，SPSD 增加 0.5276 点。它是两种最优方案各自的逐船较小增益之差。全范围为 184 艘选择增加掩膜面积，15 艘减少，7 艘不变。97 艘在原 k=8 时选 16 个新增端点和零个删除端点，199 艘增加了逐船较小增益。该队列存在缓解面积不足的几何空间，尚需看标签盲态规则能否找到可取的分配并控制船外面积。这里的精确上限仅针对共同候选与固定支持，也不约束 AP。

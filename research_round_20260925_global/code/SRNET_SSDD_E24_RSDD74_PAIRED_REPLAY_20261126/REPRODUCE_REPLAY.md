# Reproduce the frozen SRNet comparison

Start with the registered 74-image parent reserve and the SRNet capture specified in [PRELOCK.md](PRELOCK.md). The capture yields an ordered image and candidate index plus per-image FP32 native probabilities. It retains stock confidence and RLE, the source image digest and the clipped envelope of the native rotated box. Keep these data in a private run directory.

Use the independently accepted RF-DETR HRSID FIT109 seed-5217 all-source bundle and its training and acceptance receipts. Use Python 3.10, NumPy 1.26.4 and CPU Torch 2.10.0. The scorer also uses pycocotools 2.0.11 and Shapely 2.0.2 with GEOS 3.11.2. Set `CUDA_VISIBLE_DEVICES=-1` and use one thread for replay.

1. Prepare a private JSON authority containing absolute paths for `code`, `protocol`, `capture`, `manifest`, `fit_result`, `fit_accepted` and `weights`. Bind `protocol_sha`, `prelock_commit`, `capture_terminal_sha`, `capture_result_sha` and `capture_worker_sha`. The `code` directory contains the release code. The `capture` directory contains `actual/` and `observed_capture/`. The `manifest` file is next to `images/` in the canonical intake.
2. Run `python -I -B -X utf8 replay.py prepare-edits --authority AUTHORITY.json --authority-sha SHA256 --output FRESH/prepare-edits` through the witnessed subprocess observer. Store its `TERMINAL.json` in `FRESH/observed_prepare-edits/`.
3. Run the same command with `verify-edits` and a new output. Its authority additionally binds `prepare`, the parent directory of the first edit output and observer, and its `prepare_terminal_sha` and `prepare_result_sha`. The verifier independently reconstructs endpoints and checks signed operations and whole-ledger equality.
4. Use a separate scoring authority. Keep the protocol and capture bindings. Replace the FIT input paths with `prepare`, `prepare_terminal_sha`, `prepare_result_sha`, `verify_terminal_sha`, `verify_result_sha` and `replay_worker_sha`. Bind the witnessed FIT741 and original HRSID source screens with `source_phase`, `source_result`, `source_terminal`, `source_result_sha`, `source_terminal_sha`, `source_worker_sha`, `hrsid_result`, `hrsid_terminal`, `hrsid_result_sha` and `hrsid_terminal_sha`. Add `census`, `author_train` and `shapely_site`. Run `python -I -B -X utf8 score.py --authority SCORE_AUTHORITY.json --authority-sha SHA256 --output FRESH/score` via the observer. The scorer verifies receipts and edit conservation before reading the registered author TRAIN annotation objects.

Candidates with an ineligible or degenerate support and zero-budget candidates keep their original masks. Images with no candidates remain in evaluation. Both editing policies consume the same count of signed endpoints for each candidate and preserve its mask area. The original nested date sensitivity uses 42 images. The paired confidence intervals use sensor-calendar-date blocks, 4,096 draws and equal-parent weighting. The registered decision counts changed F/I outcomes on eligible original matches.

Use the [witnessed subprocess observer](../LEARNED_BOUNDED_PAIRING_20261126/rsdd/observe.py) with the appropriate phase, worker, expected result and fresh observer directory. Keep the raw data, authority files, candidate index, probability arrays, edit ledger, checkpoints and annotation files in their local storage.

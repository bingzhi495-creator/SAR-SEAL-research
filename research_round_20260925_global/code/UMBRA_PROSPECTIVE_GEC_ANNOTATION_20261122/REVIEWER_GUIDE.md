# 船体判读

将压缩包完整解压。用 Edge 或 Chrome 打开 `打开判读.html`。点击“打开影像文件夹”，选择同目录的 `images`。网页只在本机运行。

逐张查看整幅影像。每艘直接可辨的船体画一个闭合多边形，包含可辨的连续船体响应。请避开尾迹、阴影、岸线和脱离的散射。船体或边界有疑问时选择“不确定”，被窗边截断时选择“被窗边截断”，画能定位的可见范围并记录原因。

看完整幅且未见可描画目标时，选择“完成，未见可画目标”。无法完整查看时，选择“无法完成整图判读”并说明原因。完成带轮廓的影像请选择“完成，有轮廓”。增亮和缩放只影响显示，保存坐标使用原像元。

选“导出判读 JSON”即可保存或中途续作。下次打开影像后，可以用“恢复本人的进度”导入上次保存的本组 JSON。请单独返回本组生成的 JSON，判读过程中与另一位判读者保持独立。

影像来源为 Umbra Synthetic Aperture Radar (SAR) Open Data。原始强度以 CC BY 4.0 提供，项目仅提取原生图块。 [数据与许可](https://registry.opendata.aws/umbra-open-data/)

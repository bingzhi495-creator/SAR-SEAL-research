# Source-fold supervision for quota-only editing

Reconstruct the original RF-DETR center5202 FIT109 point features and native candidate identities from the independently accepted source capture. The 109 HRSID source-prefix groups use the original deterministic five folds. For each candidate with point support, compute the learned small-head posterior with the archived seed 5217, 5218 or 5219 whose training excluded its fold. Keep the original independently ranked endpoint order, including tie resolution by pair ordinal. Derive each candidate's natural equal-side count with the original positive-marginal rule and cap. Enumerate every feasible number of additions at that same realized total pixel count. The pixel choices for each quota are the two frozen ranking prefixes.

Before opening HRSID FIT annotations, save features and endpoint order separately for every source-prefix group. The action inputs are signed and absolute area changes relative to the native foreground area, predicted added and deleted occupancies relative to the balanced action and native area, a conditional-ratio IoU change proxy relative to the balanced action, native foreground area and detection score, the signed expected foreground area correction within the already admitted endpoint support, and the balanced count. The conditional proxy estimates original true intersection as stock foreground area minus the sum of foreground-point false probabilities. It estimates truth area by adding the sum of background-point occupancy. Outside the point support the proxy assumes no area correction. The estimates use the learned probabilities and the unchanged native mask, with no target geometry. The numeric output also retains the ranks, identities, endpoint posterior values, and action ranges for reproducible future feature work.

After those features are sealed, reopen the original HRSID FIT annotations and reuse the original nonignored COCO 0.50 mask matching and native-cell fractional coverage. For each valid fixed match and each action compute the true continuous IoU difference from its balanced action. Save these labels separately, with an explicit supervised-candidate mask. Leave unmatched and neutral candidates without geometry targets. Report counts for every group and fold, full action availability, target coverage, and geometry reproduction. All source groups remain in the features even when they offer no valid supervision. Zero-count candidates have one balanced no-op, with zero target gain if matched.

This is source-only dataset construction. The baseline detector previously trained on FIT; the point posterior for a particular source group comes from an archived first-level held-fold point head. Building a second-level validation experiment on these features could expose its outer holdout indirectly through other folds' first-level point heads. It can be used to train one source fit, with a subsequently frozen DEV705 evaluation, or in a fully nested held-out experiment after recomputing first-level fits. This phase trains no model, reports no AP, and opens no DEV705, Instance-RSDD or official test inputs.

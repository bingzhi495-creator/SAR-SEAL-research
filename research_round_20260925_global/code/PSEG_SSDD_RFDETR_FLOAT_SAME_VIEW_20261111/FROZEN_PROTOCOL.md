# SSDD RF-DETR 小数训练标注固定视图读入核验

复用已闭合 P125/P269 的原始 32 个 SSDD FIT 视图、顺序、增强种子、原封存 JPEG、PyCOCO 和 RF-DETR 1.12 原生载入及 resize 见证。仅加入已闭合 P395 的 FIT741 小数多边形覆盖。其余输入字段保持整数 FIT 原值。对每个视图用相同初始随机状态运行整数原生、整数逐步中心、小数原生、小数逐步中心四格。32 个视图保留，包括两个原本无实例的裁剪。30 个原整数原生格与原封存张量比较图像、掩膜、框、类别。比较四格图像、增强轨迹、非掩膜张量、实例行 ID、随机状态、非空支持及掩膜差异。按直缩与裁剪分开记录。

小数训练输入只从 FIT 专用覆盖读取。若某格实例行或支持发生变化，保留计数并按项目当前支持保持规则核验可构造训练对照，中心只在该源编码的原生和中心均非空时替换，否则保留同编码原生。硬件限定单个预留 CPU 核，GPU 不可见、无线程并行，无模型或优化器调用、无 DEV/TEST/评分。只写聚合和原始终态至新私有目录。

# 同量回退策略的事后诊断上限

对 183 张已见作者训练留出图、180 个解码组中的已封存 BCE 写回进行上限计算。无标注阶段提前核对全部 18,300 个原候选、分数、预算与静态掩膜，固定每张图的切换数量为合格候选数的三分之一向下取整，并在每个原 signed-k 分层按最大余数分配。第二阶段重放无标注名单，随后仅以两份既有留出标注取得原生 0.50 匹配。保留 411/410 个原作者船体图内分母，重现 311/308 个原生匹配、276 个共同候选和 206 个正预算共同候选。非共同和未采用位置的贡献定义为零。没有重训、推理或 AP 计算。[预锁](PRELOCK.md)

联合写回的同量解保留 42 个两参考严格改善的共同船体，77 个较小增益为零，无负增益。解除采用数量并保留全部严格正增益，可达到 +0.1899 个较小重叠百分点。预设采用容量保留该菜单 95.5% 的这项提升空间。

对于以原联合版全采用为对照的实际目标，同量解在共同支撑上仅增加 PSeg +0.0276 和 SPSD +0.0389 个百分点，两参考区间均跨零。即便允许按各参考单独取最优，同配额相对全采用的共同支撑上限也只有 +0.0683 和 +0.1083 点。该证据说明相对静态可减少双参考中较差的一侧，但这个既有联合／静态菜单对全采用控制的共同支撑增益有限。其他原生匹配船体在这里被定义为零，完整留出效用仍需实际选择器评估。参考特异的方案是分别优化得到的松弛上界。

实际观察阶段分别耗时 5.88 秒和 4.91 秒并各自退出 0。现场采用分配、强制容量、未匹配零值与参考特异性的三项合成核验通过。两个安全结果仅保留汇总，无逐图决定或轮廓。 [预先锁定名额](plan/RESULT_SAFE.json) · [上限与重抽样](score/RESULT_SAFE.json) · [执行入口](selective_bound.py)

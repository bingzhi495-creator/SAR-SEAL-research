# FIT source-disjoint three-seed area-consensus coverage

Phase 1 is locked before model outputs or annotation access. Use the same natural-retention center-supervision E24 family with independently accepted downstream seeds 5201, 5202 and 5203 (Q164, 17,640 EMA updates, shared initialization). The 5202 anchor in this family is distinct from the common-retention 5202 oracle carrier. The test asks whether signals from independently trained downstream seeds on the same training set are identifiable across candidates. It does not estimate independent sensor observations or independence across training corpora.

Select 36 distinct HRSID native FIT source filename prefixes disjoint from all groups in the closed FIT114 capture (including earlier FIT36). Select by salted group and filename SHA-256 before opening images; reject missing identities, duplicate encoded/decoded bytes or invalid inputs rather than replacing rows. Source prefixes are a proxy grouping, and the original detectors were trained on FIT. No labels, DEV, TEST or scoring during this phase. Use one CPU thread with CUDA hidden, serial one model at a time, stock FP32 val576, original top 100. Preserve ship-slot masks, scores, ranks and query identity. Capture native 144 by 144 FP32 mask logits for the mapped nonempty candidates to support the later common local point ranking. Keep exact image hashes, row order and immutable checkpoint identity.

For each image, match the anchor separately to each donor by same-category mask IoU among all nonempty mapped candidates. Require reciprocal best, IoU at least .50, and both endpoint best-minus-runner-up margins at least .10. An endpoint with no alternate has runner-up zero. Filter the anchor to area in [32,1024) only after association, with both donors required. Rejection gives no edit. Report all candidates, matches, ambiguity, both-donor coverage, median-area offset sign, and counts by source group. This is prediction-only viability, not a correctness score. Before any true-label diagnostic, require at least 60 covered anchor candidates across 20 groups and at least 30 with nonzero median area offset across 15 groups. Do not relax this gate after outputs.

If phase 1 passes, separately lock a fresh label-scoring contract before labels. Compare equal-width, equal-cost action rankings based on mean minus lower-tail penalty versus mean minus standard deviation, with a shared edit count and local point ranking, plus no edit and equal-add/drop. Separate held source groups for calibration and scoring. The exact scoring implementation, counts and evidence will be tracked independently. No new training of the detector.

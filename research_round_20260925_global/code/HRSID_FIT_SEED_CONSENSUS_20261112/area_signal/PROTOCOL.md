# FIT three-seed signed area signal

Lock before opening any label or result of the current three-seed capture. Requires its natural terminal, independent prediction readback and phase 1 coverage pass. Use the same 36 selected FIT chips and native anchor 5202 predictions and class scores. Establish original COCO IoU .50 matches using the original nonempty top-100 prediction pool. Target area is exact valid source polygon area in original coordinates. Eligible anchors have native mask area [32,1024). Uncovered candidates are unchanged by every estimated-area arm. Include them in the fixed matched denominator, and count estimate changes on unmatched candidates separately. No predicted mask edits, AP, inference or model optimization.

On each covered anchor use the three native mask areas including the 5202 anchor. Compare no change, arithmetic mean delta, median delta and calibrated versions of both. Limit the area estimate change to +/- 2*min(8, floor(anchor area/10)) pixels. This is an area-estimate magnitude limit, not a count of actual changed mask pixels. For calibration only, fit one slope with no intercept from {0,.25,.50,.75,1,1.25,1.50,1.75,2}, with ties to the smaller slope. Fold groups by frozen ordinal modulo three. Each arm uses only the other two folds, using equal weights across represented source prefixes and then across eligible fixed matches within each prefix. Score GT-normalized absolute area error on the original fixed matched eligible population, including unedited candidates. Report equal-source, match-pooled and covered-only metrics, the per-fold slopes and direction signs, and fixed absolute/relative errors.

Prespecified lead requires at least 30 covered valid matches from at least 15 prefixes. Calibrated median must decrease source-equal mean absolute normalized area error by at least 0.50 percentage points versus no change and 0.25 points versus calibrated mean, with positive difference against both in at least two folds. A pass only motivates a distinct prospectively controlled local mask allocation trial. A fail stops this median-area mechanism in this probe. Input chips are spatially disjoint from FIT114 captures and source-prefix-disjoint from the preceding oracle36, while parent prefixes were used in older FIT114 probes and these weights trained on FIT. This is an internal signal diagnostic and does not establish a deployable contour gain.

# Supplemental Umbra native image intake and independent readback

The metadata-only runner must terminate naturally with exit zero and an exact output footer before the new native runner opens a public image object. Bind the exact private manifest, safe metadata result, observed terminal and published cohort lock. Accept the full ordered 18–24 collect roster fixed by those bytes. Its identities run from UMB-101 consecutively. All task IDs, original collect IDs and original author objects must be unique. The source coordinator checks the published commit and manuscript evidence scope before approving any acquisition.

For each frozen original collect, extract one tile-aligned 1,024 × 1,024 window whose center is nearest to the original raster center; break ties toward the smaller index. Use the unchanged original public GEC extractor by exact source checksum. It uses an anonymous direct request to the Umbra S3 catalog, pins object length and ETag, and accepts the exact requested byte ranges on the same object. Retain unsigned native grayscale, the projected affine, the four source intervals and their hashes in the coordinator ledger. The worker reserves at most 64 MiB of response payload. No substitute collect, window recentering, scaling, resampling, label access or detector run is part of intake.

An object read or decode failure retains the original ordered position as unavailable. Raw parity requires uncompressed original tiles. Any compressed source is unavailable for this protocol, and an exact duplicated decoded array retains only the earliest manifest occurrence. Keep the unavailable slot, technical reason and separate coordinator-only provenance. The public aggregates report counts only. A natural intake exit of 1 reports a partial roster with an authenticated output footer; a natural exit of 0 reports a complete roster.

Independent local verification checks the closed extraction terminal, immutable protocol, metadata binding, frozen roster, anonymous PNG bytes and decoded arrays, source- and window-grid composition, positions and extent of all four original intervals, and the raw uncompressed tile hashes reconstructed from PNG pixels. It reads the original extraction code and verification code as immutable sources bound by SHA-256. A subsequent detector protocol may use the originally admitted positions if at least 18 distinct arrays have four verified raw intervals each. Keep every unavailable position in the cohort record and retain gaps in anonymous IDs. This eligibility concerns data intake only. No annotation or detector output is part of the readback.

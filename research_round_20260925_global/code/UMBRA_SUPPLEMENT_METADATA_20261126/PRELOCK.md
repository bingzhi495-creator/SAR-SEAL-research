# Prospective supplemental Umbra scene selection

This is a separate prospective evaluation with identical native ship-mask processing. The previously locked twelve Umbra windows remain a separate cohort with their own coverage and inferential gate. The supplemental acquisition selection is based on public source metadata. Neither the scientific scorer, author references, previous model predictions, annotation reviewers, nor model performance feed the list.

Use the official ship_detection_testdata catalog. Use its sorted unique task UUIDs from the provider list. Attempt up to 128 evenly spaced midpoint probes of the sorted eligible tasks. Where the official ordered snapshot reproduces the original 999-task digest, reconstruct and exclude its earlier 64 metadata probes by the same midpoint rule and verify their ordered digest. If the provider snapshot has changed, use the current documented snapshot and independently exclude all known pixel-exposed records. Record the snapshot, query caps and exclusion counts. No metadata-only prior probe otherwise constitutes pixel/model/annotation exposure.

Exclude duplicate task IDs or collect IDs, the locked 120-collect historical ten-port study, the three technical pixel pilots, the original twelve prospective collects, centers within 100 km of their coordinates, and intersecting known footprints. One GEC asset is chosen per task by the first lexical GEC name with its original paired metadata. Use original UTC since 2021, valid task/collect/footprint/center, 0.35–2.00 m target IPR and enough declared dimensions for a 1,024-square native window if dimensions are present. Target IPR is a product setting, not measured pixel spacing or verified directional resolution. Apply mutual 100 km separation and no footprint intersection between new windows. Retrieve no pixels for this step.

Aim for 24 independent acquisition records with one window each. In the probe order, fill up to 12 with target IPR 1.00–2.00 m, then up to 12 with 0.35–below 1.00 m. Fill remaining slots in the same recorded probe order and with the same spatial rules. Report any deviations and all screening outcomes. Use anonymous UMB-101 onward. Seek at least 18 records for a separate quantitative follow-up. A smaller roster is a feasibility report. Publish the exact locked rule and aggregate identity of the ordered private list before any pixel intake. Preserve that roster and all unavailable slots without performance-dependent replacement.

Intake uses the same original native-center tile alignment, grayscale and anonymous mask pipeline as the twelve-window study. Record any technical failures, check native window and original tile bytes independently, and retain unavailable slots in the cohort flow. Score only after two separate independent blinded original reference exports are sealed for this supplemental roster. Use the same frozen HRSID RF-DETR center5202 E24 detector and seed 5217 HRSID fractional occupancy point head, exact original output order, bins/ranking, edit-count rules, decoder and origin. The primary treatment is independent endpoint ranking versus fixed distance pairing with identical signed edit counts. Preserve native and original general comparison outputs when their exact same-geometry implementation can be bound. Do not fit a target model, expose candidates to reviewers, or use these windows for feature/threshold tuning. This is an acquisition and primary-evaluation lock. A later fixed executable admission receipt may pin source files but may not change these rules.

Use each original collect as one group. Retain the original one-to-one raster native match at IoU >=0.50 and continuous polygon-cell IoU on the same matched native candidates. Missed, absent-quota and unchanged hulls contribute zero paired change. Compare paired acquisition-equal outcomes over each reference's complete hull denominator from the joint-complete windows. Use the original 4,096 group resamples with PCG64(5217). Supplementary confirmation requires each reviewer to contribute at least 30 eligible positive-budget native matches across at least 12 distinct acquisition groups and a positive paired lower confidence bound for the matched treatment. Report outcomes and both reviewer directions regardless of this decision. Do not aggregate this result to turn a failure of the original twelve-window gate into a pass. Independence from unobserved third-party pretraining cannot be verified. Study scope is the sampled Umbra catalog and native window rule.

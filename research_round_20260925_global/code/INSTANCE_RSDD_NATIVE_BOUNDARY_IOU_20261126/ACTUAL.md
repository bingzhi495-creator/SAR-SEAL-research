# Instance-RSDD 原生边界带的冻结对照

同一个原生候选、置信度和逐候选增删数下，比较独立选点和距离配对。使用 Cheng 等人的内侧边界环定义，固定原生宽度为一像元，二像元为预设敏感性。固定原有 COCO 栅格 IoU 0.50 匹配。每个父景权重相同，对配对差值做 4,096 次父景 bootstrap。所有列为百分点，方括号内为配对 95% 区间。[预锁协议](PRELOCK.md) · [Boundary IoU 原文](https://arxiv.org/abs/2103.16562)

高分三号两次冻结检测器共享相同的 583 张影像，每个检测器建立自己的原匹配。两次分别保留原 629／628 个匹配，425 个进入编辑面积范围。两个宽度下，所有入选的作者、原生与写回掩膜在腐蚀后都保留内部前景，预处理非饱和子集等于主队列。5202 和 74 图保留集通过预锁的一像元边界判据。5203 的一像元区间跨零，二像元两次检测均有正向证据。高分三号共同作者分母为 631，保留不合格或未匹配为零贡献的敏感性结果单列。[高分三号核验](gf3/ACTUAL.md)

完整 74 图有 81 个作者船体、13 个父景，47 个合格固定匹配来自 12 个父景。两套写回各有原预锁预算。原距离配对与独立选择每臂为 30,841 对，同支持 PointRend 与占据排序每臂为 31,391 对。父景保留集的日期块重采样得到独立选点 +0.701 [0.231, 1.243]。PointRend 对照的一像元日期块区间也跨零。嵌套的 42 图日期分离敏感性分别得到 +0.736 [0.076, 1.436] 和 +1.397 [0.245, 2.420]，保留其 32 个合格固定匹配与八个父景。完整和嵌套队列各复现 104 项历史 COCO 指标。首次回执少阶段字段，修正记录格式后重新观察，两次科学字段逐值一致。[74 图核验](reserve74/ACTUAL.md)

本诊断支持部分冻结检测器在原生一像元范围的收益，同时标出不同检测器、对照和评估宽度的观测效应及不确定性。公开两份历史作者标注队列的聚合指标与程序。固定匹配的 Boundary IoU 与整场景 AP 分别解释，新采集的 Umbra 独立参考仍待评分。

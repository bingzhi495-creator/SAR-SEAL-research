# SRNet 原生概率和学习残差的作用

两个对照沿用原 74 图、固定嵌套 42 图、89 个候选及逐候选有符号增删量。两次无标签回放逐字节一致，原 N/F/I 的 COCO 评分和固定匹配几何复现。残差单独参与排序时移除显式加性原生 logit 项，原生概率仍作为输入特征。冻结模型、候选置信度和实际增删数保留。[预锁口径](PRELOCK.md) · [原始同预算实测](../SRNET_SSDD_E24_RSDD74_PAIRED_REPLAY_20261126/ACTUAL_REPLAY.md)

完整分数比仅用原生先验的连续几何更好，且整队列固定面积的超分和漏分各降低 0.132 个参考面积百分点。两个对照的改变覆盖均通过，Mask AP 差均低于预设的 0.30 点。移除直接先验的 AP 点估计降低，连续几何区间跨零。现有结果支持保留该加性组合。[加性消融记录与复现](ACTUAL_PRIOR_ABLATION.md)

32 个原始合格匹配上的 2,048 个可写端点，以及 45 个实际可编辑候选的 2,880 个点，均位于各自符号的截断阈值内部。保持已选端点的各箱数量后，真值辅助最优解与无箱约束最优解一致，0.530［0.259, 0.834］点的连续几何余量来自内部排序。拆分后的准确增加和避免误删分别增加 0.209、0.150 个参考面积百分点。这个诊断限定在原端点池和已有参考上。其他像元和其他检测器的情况仍需单独验证。[截断分箱实测与复现](STRATA_ACTUAL.md)

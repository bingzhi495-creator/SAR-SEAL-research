# Matched BCE vs static-relative signed action supervision

This branch is preregistered after the frozen 5297 diagnostic and before fitting its two heads. In the fixed 183-image historical source-gate diagnosis, replacing estimated scores with true signed gains within the same menu recovered +0.366 conservative IoU points, compared with +0.001 for exact IoU normalization and +0.178 for the entire endpoint support beyond the finite menu. The new hypothesis is that supervised static-relative overlap gain improves the selection from the same label-blind menu, beyond otherwise identical binary occupancy training.

Use the existing exact closed FIT frame, frozen D-FINE E24 native candidates, two released reference rasters, original paired native .50 association, fixed two-sided support, and positive static-at-dynamic k. Both fits use only dual-reference FIT examples with a shared original candidate, mutual reference IoU at least .50, n>k>0 and at least one nonidentity action. Bind the same label-free point, fit raster and original-not-test receipts. Use authored binary labels as released. Source-GATE and official test labels do not enter this training.

Each candidate has the exact frozen static action. The fixed action bank contains the original dynamic selection, independent native occupancy top/bottom, hash-seeded quota-matched selection, strongest-unused-versus-weakest-selected replacements of static on add side, drop side, and both sides. All construction uses only the frozen original candidate, support, static indices, native probability component and deterministic index/hash tie order. Remove duplicate pairs and the static action. No oracle, model-fitted menu or observed source gate result chooses actions or candidates beyond this explicit phase advance.

For each action and reference compute the signed gain change relative to static using weights +[selected_action−selected_static] at addition endpoints and −[selected_action−selected_static] at deletion endpoints. Divide by 2k for scale. Fit two equal 1,346-parameter heads, identical initialization from seed 5297, group→eligible image→eligible candidate draws, endpoint exposures, scaling, 64 candidate packets per update, 1,000 AdamW updates, learning rate .002 and weight decay .01. Both see the same complete candidate feature, binary target and action packet. Arms are candidate-equally weighted BCE and the same BCE plus 1.0 candidate-equally weighted SmoothL1(beta=.1) on the two normalized signed action gains. Standardization averages FIT groups, eligible image records, candidate packets and their endpoints in that order. Save exactly the final state, no source validation or checkpoint choice during fitting. Core and all digest bindings must be validated before the first optimizer.

After natural exit and verified state, compare both arms with the same frozen original signed quota, candidate slots, scores and finite robust writer, and retain static, same-head mean and pessimistic controls. The already observed 183 image group collection is only a mechanism check on the redesigned loss. Evaluate both reference-wise all-hull image and RGB-group-balanced IoU, all-slot COCO AP/AP75 and the exact raw predicted-vs-realized action margin. Source advance requires action-vs-BCE fixed-selection IoU at least +.15 points and group-bootstrap lower >0 under both references, AP at least -0.10 against BCE under both, at least 20 shared changed hulls across 8 decoded groups, and positive margins against matched new mean and pessimistic controls. Freeze any future untouched acquisitions before inspecting their labels and report separate seeds. Keep all results and failed qualification.

# Frozen D-FINE DEV705 rival-mask comparison

The HRSID DEV705 neighboring-instance audit motivated this rule. FIT109 then passed its predeclared coverage, intrusion, own-IoU and AP criteria against two controls. This experiment transports the accepted rule from FIT109 to DEV705 and tests it on different images and source prefixes. DEV705 supplied the motivating population, so the comparison remains a secondary development validation.

Use the original D-FINE E24 checkpoint outputs, separately closed image-only 160×160 FP32 planes, original RGB ZIP and independently accepted all-FIT BCE head and scaler. Reconstruct the original endpoint features and head probabilities. Reproduce every historical edited mask and count byte for byte for each native candidate. Preserve all 705 images and 70,500 native rows. The detector and all point model parameters are already fitted.

Apply the exact FIT109 rival rule with coefficient one, score floor 0.50, native intersection over smaller foreground area below 0.50, candidate-level max covering score and q × (1 − rival score) for additions. Use the unchanged FIT109 SHA-initialized within-q-quartile permutation as placebo. Match the historical fixed-pair arm's realized edit count and original independently ranked deletion ordinals in every candidate. All unedited cases remain present.

Complete capture and label-free readback in separate processes. Reproduce old RLEs, fixed budgets, new per-mask XOR and exactly retained native pixels relative to the original independent ranking. Verify both actual process exit codes and result digests before opening labels. Retain the original four empty raster annotations for primary COCO. Report all COCO metrics, plus 1,447 valid fixed IoU matches and inclusive strict 0.90 transitions using the exact original matcher.

Primary analysis uses all 47 original fixed matches within four pixels of another valid polygon, from 14 prefixes. Measure the original matched-vessel IoU and change in added area inside exclusive neighbor polygons. Equal deletion sets cancel on difference. Weight source prefixes equally and keep all no-ops. A truly exposed match has a positive realized count and at least one nonzero rival score. Require at least 12 exposed matches across eight prefixes for inference. Otherwise report coverage and descriptive estimates. Reuse 4,096 paired prefix draws with PCG64(5217). Against each of original independent ranking and the placebo, require a strictly positive lower 95% bound for neighbor intrusion reduction, a lower bound above −0.20 own IoU points, and an overall AP loss below 0.30 points. Report actual changed mask counts and all outcomes. A pass supports transfer to the DEV split under this frozen D-FINE setup. It does not turn the historical DEV population into an untouched evaluation site.

# Prelock: sensitivity to two authored ship-mask references on identical PSeg-SSDD JPEGs

This retrospective reference-sensitivity experiment fixes all 232 official PSeg-SSDD test JPEGs and all 23,200 original held D-FINE scored top-100 masks. The JPEGs in the original Official-SSDD RAR and SPSD validation from the SLGSea author ZIP were confirmed byte-identical on all names. A separate label-only examination found unequal hull content and raster IoU differences before this lock. No SPSD model scoring has been performed. The same images and historical exposure are shared by the two references; no independent-acquisition claim follows. Use all images, without subsets or thresholds chosen on these labels.

Require the naturally terminal accepted PSeg D-FINE replay, its original image roster and candidate streams, and the independently accepted static/dynamic attraction extension. Preserve source rows, order, logits already reduced to original RLEs, scores, and treatment locations. Check the original and attraction receipts, their observed terminal footer and checked streams. Replay eight original arms: native, fixed pairing, independent at fixed count, independent natural, native probability at natural count, dynamic attraction, static attraction at the dynamic count, and learned at the dynamic count. Verify exact per-candidate budget equality within every matched count contrast. No model, forward, fit, or threshold change. The original learned/dynamic/static comparison is retained as a separate budget group from fixed/independent.

Use original PSeg polygons converted with the prior COCO rasterization, preserve original annotation sizes and POIs. Use SPSD category-0 thing instances from same-shape RGB panoptic IDs, excluding only stuff; cross-check mask area and tight bbox against the author's JSON. Align SPSD references by exact filename and original dimensions and adopt original PSeg per-image IDs. Preserve all 546 / 547 ship reference instances respectively. Do not remove any prediction because it lies on a differing annotation. Use original COCO segm category and maxDets=[1,10,100]; report AP/AP50/AP75/AP90/AR100. Require exact prior PSeg metrics in every reported arm as acceptance before interpreting SPSD. Report each reference's metrics and paired differences for independent-at-fixed-count vs fixed, natural-independent vs native, natural-independent vs natural-count native probability, learned vs dynamic attraction, learned vs equal-count static attraction, and static attraction vs dynamic. Calculate these contrasts in unrounded percentages. Do not infer accuracy from cross-reference absolute AP differences.

Per reference, freeze native score-ordered COCO assignment at mask IoU 0.50 before computing arm deltas. Unmatched reference hulls have zero IoU and effect. Use every native matched hull, including pass-through. Average each image's all-hull IoU, then weight the 232 verified unique decoded-image groups equally. Report native matches, edited native matches and nonidentical predictions per contrast, each overall and with image groups. Report paired image bootstrap intervals (4096 draws, PCG64 5297; same draws for both references). Report SPSD minus PSeg contrast shifts from same draws on per-image contrast differences. These are decoded-image groups; sequence or acquisition independence is unverified and no test may overwrite one annotation set with the other.

Outputs contain only aggregate scientific evidence, admitted data and receipt identities, and source code. No original imagery, reference masks, or original model masks may be released.

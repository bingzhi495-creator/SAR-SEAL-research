# Reproduce the frozen reference-sensitivity evaluation

Obtain `Official-SSDD-OPEN.rar` from [Official-SSDD](https://github.com/TianwenZhang0825/Official-SSDD) and `SLGSea_Datasets.zip` from [SLGSea](https://github.com/deng1218/SLGSea#datasets). Preserve both archives. The worker requires a tar build that reads RAR and Python with NumPy, SciPy, Pillow and pycocotools. The completed run used the existing Python 3.10.13 and pycocotools 2.0.11 environment with GPU disabled.

Use `score_reference.py --help` to supply the required local paths. `--protocol` points to the unchanged `PRELOCK.md` colocated with `ERRATUM.md`. `--official` and `--slgsea` point to the source archives. `--code` is the project's published research code root. `--owner`, `--capture`, `--old-readback`, `--original-replay` and `--classical-root` point to the existing naturally closed PSeg official D-FINE frozen inference and the spatial-attraction replay in the project. Their published paths and acceptance protocol are described in the existing [original score entry](../PSEG_TEST232_DFINE_FROZEN_SCORE_20261121/README.md) and [same-count spatial-attraction entry](../PSEG_TEST232_CLASSICAL_ATTRACTION_20261122/README.md). Native private masks and manifests are required local inputs. The worker checks prior source, exact image bytes and reference, prior COCO metrics, realized treatments and terminal records before interpreting new results.

Choose a fresh output filename and use the previous spatial-attraction observer with phase `score`. The result records an aggregate label-only correspondence, COCO scores, fixed-native matching coverage, same-budget treatment effects and paired image bootstrap summaries. Its terminal verifies actual exit plus output SHA-256. No image, author annotation, native candidate, weight or deployment artifact is generated for release.

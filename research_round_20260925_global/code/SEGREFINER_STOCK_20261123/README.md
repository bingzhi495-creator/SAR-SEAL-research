Follow the [frozen protocol](../../SEGREFINER_STOCK_PRELOCK_20261123.md) and [actual coverage checks](../../SEGREFINER_STOCK_EXPOSURE_ACTUAL_20261123.md). Reuse the exact native inputs, source parents and float author labels from the earlier [Phoenix comparison](../PHOENIX_PAIR_OPERATOR_20261123/README.md). The old Phoenix fields are unnecessary for author inference.

1. Acquire the official [checkpoint](https://drive.google.com/file/d/1FrhbdwNyTlQYNbF9IgFF2tY3iQXHFcau/view). Verify 474,603,251 bytes and SHA-256 `d5806a41a4bff6f1e313d1a9dcf18d11dab28e3a8e1497871a156214cd8fe07a`.
2. Obtain the author files at commit `53419a2d38ea3da0b6e2be77e5b45e139195a0b3`. Save [segrefiner_base.py](https://github.com/MengyuWang826/SegRefiner/blob/53419a2d38ea3da0b6e2be77e5b45e139195a0b3/mmdet/models/detectors/segrefiner_base.py) as `base.py`, [segrefiner_instance.py](https://github.com/MengyuWang826/SegRefiner/blob/53419a2d38ea3da0b6e2be77e5b45e139195a0b3/mmdet/models/detectors/segrefiner_instance.py) as `instance.py`, and [diffusion_unet_head.py](https://github.com/MengyuWang826/SegRefiner/blob/53419a2d38ea3da0b6e2be77e5b45e139195a0b3/mmdet/models/dense_heads/diffusion_unet_head.py) under its original name. The adapter pins all three hashes and executes their original inference paths. It provides compatible registry and bitmap interfaces without changing the author's denoiser, sampling or mask writer.
3. Run `exposure_rsdd.py` or `exposure_pseg.py` using the historical CPU geometry environment. The published safe summaries are [Instance-RSDD](../../results/RSDD74_SEGREFINER_STOCK_EXPOSURE_SAFE_20261123.json) and [PSeg-SSDD](../../results/PSEG232_SEGREFINER_STOCK_EXPOSURE_SAFE_20261123.json). Scores are verified against original native baselines. This step measures exposure.
4. Use `infer_rsdd.py` or `infer_pseg.py` with the exact coverage receipt, author code directory, checkpoint, runtime hash, original candidates and source images. Launch through the [actual-exit observer](../INSTANCE_RSDD_PHOENIX_EQUAL_COUNT_20261123/observe.py), phase `inference`, with the GPU interpreter as its subprocess. Runtime SHA-256 is `85a6a95205c6842e1e4f5f24805d911a0ef5bb0eded0d5ff67d7e020fe04d816`. The Instance-RSDD worker's `--smoke` uses the first eligible image and a distinct completion status. Use a fresh directory and separate observer for the full run.
5. Use `score_rsdd.py` or `score_pseg.py` through the same observer, phase `score`, with the historical CPU interpreter and original annotation bytes. The scorer requires the full-run inference receipt. Private RLE output retains original candidate positions and must remain local. Only aggregate SAFE scores and observational status are releasable.

Pass `--help` per source for the exact path names. The protocol SHA-256 is `30007c832d47c6e086445d474d4f319642854de20da7844706ebac8e40a7df9c`.

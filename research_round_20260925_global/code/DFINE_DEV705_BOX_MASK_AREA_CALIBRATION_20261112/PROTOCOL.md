# D-FINE known-DEV fixed-budget area calibration diagnosis

This is a retrospective mechanism test on exact already used D-FINE DEV705, no AP and no claim of independent model validation. Use the stock native top100 original .50 nonignored matches and exact source polygons, reproducing 1,652 original stock matches and 1,329 small slender matches (GT area <1024, exact hull aspect >=2). Retain all 1,329 matches; ineligible edits remain raw. Source is the original filename prefix before underscore, a proxy. Sort prefix by SHA256('DFINE-area-v1|'+prefix), tie prefix, assign folds ordinal mod 5. Each rule fits on four source folds and predicts the fifth. All conditions share exact same data, candidate, confidence, matching and selection positions.

For candidate area P, nominal total flip count M=2*min(8,floor(P/10)); retain P>=32 for edits. Work on two-pixel Chebyshev boundary band; for additions require exact author half-open box clip x>=x1,x<x2,y>=y1,y<y2 at integer pixel centers. Verify original mask lies inside. Rank each sign separately by one-pixel boundary layer first, then two, row-major within layers. Eligible if at least M/2 pixels on both signs; otherwise every rule is raw. Include all feasible compositions a+d=M, allowing signed net delta a−d. Compare raw, balanced a=d, and two equally sized scalar affine models (intercept+slope). Size feature = log2(P). Box feature = log2(clipped continuous detector box area divided by integer tight-mask AABB area). The author box clips the mask, so they are coupled. Fit group-equal ridge least squares with input standardized on train, slope penalty 0.01, intercept unpenalized, and target clip((continuous GT area−P)/M,−1,+1). Fit only editable rows. Project predicted M*y to nearest feasible signed delta; ties smaller absolute delta, then smaller signed delta. All applied modes share identical per-mask M, positions ranked as above. GT chooses no applied positions or test model.

The truth-assisted oracle chooses the best continuous IoU among the same deterministic prefix edits and exact M; it uses the same per-sign rankings and only changes the split. Report full original matched cohort source-equal and pair-equal continuous IoU, IoU≥.75/.90, relative absolute area error normalized by continuous GT area, FP/FN, editable and infeasible counts, folded coefficients and differences, and cost. To motivate confirmation, require area error at least .25 points lower than both raw and size, IoU at least .20 points higher than both raw and size, no loss of strict matches versus raw, and at least four of five positive source folds vs size. Oracle never advances a rule. Different source cohorts remain separate. This experiment only trains a two-parameter cross-fold calibrator; no new detector updates, AP, DEV tuning for official evaluation or TEST.

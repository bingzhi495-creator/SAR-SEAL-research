# 固定动作集合的双参考收益校准

上一轮开发集替换分析表明，把预测收益换成真值平均项或真值差异项，分别提高了 0.326 和 0.239 个逐船取较小参考贡献后按组汇总的 IoU 点。此次训练检验在保持动作集合和推断选择器的情况下，改用对应的预测监督能否产生可测收益。

令 $g_P$ 和 $g_S$ 分别为候选动作相对静态掩膜的有符号交集变化除以 $2k$。三组都保留同一逐点 BCE。回归组沿用两参考分量，平均项组监督 $m=(g_P+g_S)/2$，差异项组监督 $h=|g_P-g_S|/2$。逐候选平均的辅助 SmoothL1 转折值均为 0.1，权重均为 1。静态掩膜满足 $m=h=0$，原训练动作集合和损失分母保持不变。差异项在两预测收益恰等时的绝对值子梯度为零，此时共享 BCE 仍训练参考各自的占据率。

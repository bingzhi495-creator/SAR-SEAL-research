# SAR-SSP 的增删配额与端点排序回顾诊断

第一行复现既有部署差值，其余行都使用作者轮廓。表中保持配额重排与随后开放所有配额的两项改进相加为 +1.327 点，与逐船体累加的原自由方案至全菜单最优差值一致。只改配额的上限保持了每个配额在预测模型里的最佳点集。它有 0.958 点余量，体现原模型在不同配额下已经产生了一些更好的点集。所有端点组合放开后仍可增加 0.768 点，说明候选排序生成的有限菜单自身也有缺口。

精确面积与静态交集替换使用原预测净交集增量，重新选择全菜单分数最大的动作。50 个可编辑匹配中 29 个更改了增删配额，但母景等权 IoU 只变动 +0.005 点。混合目标中的预测交集可能超出实际几何范围，计算保留原净交集预测并检查并集为正。结果支持优先检验配额评分的跨域适用性，无法单独辨别面积、交集和预测增量误差。母景区间由 4,096 次配对重采样得到。这批验证图已有研究接触，真值辅助上限只说明该支持范围的潜力。所有反事实只修改原生固定匹配，不计算 AP。没有目标域拟合或新的检测器前向。[完整聚合](RESULT_SAFE.json)

实际诊断 17.75 秒，观察到进程自然退出 0 并核对结果尾签。第一次启动选中了带不同 NumPy ABI 的 Python，停在库导入，未读取作者标注或产生结果。更换为原冻结评分的 Python 3.11.15 后，同一工作体完成了计算。穷举子集的小规模核验通过。预锁末段把输出臂数写成六项，代码按其逐项定义保留七项。两项原方案和五项诊断均在汇总里。

# SAR-SSP 上的精确期望 IoU 复算

保持历史 SAR-SSP 232 张验证图、原检测候选、冻结 BCE 点头、原生端点和逐候选 $2k$ 总编辑量。每个参考下，假设采样端点占据相互独立，且支持之外的真值与原生掩膜一致。设 $C$ 为动作后的面积，$H$ 为期望交集，$Z$ 为未选端点的占据数，则精确模型期望为 $H\,\mathbb E[(C+Z)^{-1}]$。现有规则用 $H/(C+\mathbb E Z)$，与 RankIoU-RMA 和 expected-intersection-over-expected-union 近似一致。精确计算在相同有限候选集上使用 Poisson-binomial 卷积，双参考仍分别计算相对静态动作的收益，再取两者中的较小值。 [RankSEG](https://www.jmlr.org/papers/volume24/22-0712/22-0712.pdf) · [RankIoU-RMA](https://arxiv.org/abs/2510.15362) · [Ahmed 等](https://openaccess.thecvf.com/content_iccv_2015/papers/Ahmed_Optimizing_Expected_Intersection-Over-Union_ICCV_2015_paper.pdf)

主要比较在 139 艘作者船体、23 个母景中改变 0 个原生匹配。51 艘未匹配船体按既定规则计零。各方案都实际翻转 147,118 个原生像元。有限菜单含 1,393,753 个动作，有证明的边界筛选将精确卷积缩减至 23,177 个。每动作最大参考近似误差上界的总体平均为 0.026 IoU 点，观测到的上界最大值为 0.398 点。这里的上界约束模型目标偏差，原始作者轮廓仍决定实际掩膜精度。

可变配额相对固定配额的旧退化方向在精确期望下保留。相对固定配额，按船体面积归一的船外误分增加 1.378 点，船体漏分减少 0.653 点。在所用独立性和支持外占据假设下，精确计算分母期望没有修复这批历史样本的迁移结果。该复算不验证占据概率校准或该模型假设，也不识别迁移退化的完整原因。

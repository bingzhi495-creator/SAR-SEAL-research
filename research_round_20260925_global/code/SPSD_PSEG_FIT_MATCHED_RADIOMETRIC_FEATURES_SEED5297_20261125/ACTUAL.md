# 同容量局部灰度分布特征对照

本轮固定上一版双参考动作回归、部署动作和实际交换量，检验共享灰度参照能否帮助预测相对静态掩膜的交集变化。两个新增特征组保留原 14 个输入特征，用五个灰度统计量替换网络输入的五个重复位置，总宽度仍为 28。五个统计量分别为灰度、3×3 局部均值、相对 5×5 均值残差的中心化中秩，以及灰度和残差的中位数／四分位距标准化值。联合组从候选的内外两侧端点共同估计参照，分侧组按同一公式分别估计。该设计能保留内外端点在共同灰度尺度上的相对位置，对单个端点依赖的是分布，原配对端点的值没有作为额外输入。

内部 RF-DETR 先例已比较过集合合并与分侧秩，本次具体差异是将强度、局部均值和残差的秩与稳健标准化结合，在固定签名、双参考逐点占据率及动作交集回归下检验。两个新增组的可用输入维度相同，联合与分侧比较用于检验共享参照的作用。图像输入是公开数据解码后的灰度，方法主张限于该表示及采样区域。 [原秩实验协议](../../RFDETR_FIT_SIDE_CONTEXT_RANK_PROTOCOL_20261109.md)

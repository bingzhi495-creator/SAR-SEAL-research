# SSDD DEV187 centroid and polygon shape factorial

Use the exact four closed E24 prediction streams, original masks and scores, and existing 380 paired integer and author-float contours. Before evaluation fix four continuous reference cells: integer or author-float polygon shape, independently placed at the centroid of the original integer or author-float continuous polygon. Compute both centroid locations before moving either contour. Translations preserve polygon orientation and area. If a cross-position translated shape loses positive area outside its image, make that annotation neutral in all four cells and report the count. Validate exact centroid and area in surviving cells.

Use the same frozen integer metadata (annotation IDs, class, area bins, boxes, score order, image IDs and COCO settings) for all four cells, with polygon-vs-prediction-cell continuous overlap from the existing independently checked scorer. Preserve original full stream; no candidate/threshold selection, training, image decode or official TEST. Report AP, AP75/AP90, factorial displacement/shape contrasts and interaction for the center-minus-native effect. This diagnostic estimates effects of exchanging properties of reference annotations on fixed predictions. It does not optimize model masks or estimate effects of retraining.

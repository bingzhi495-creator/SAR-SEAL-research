# PSeg-SSDD 官方测试集的输入核验

2026 年 11 月 21 日在读取本轮标签前锁定了测试成员、图像编号和检查规则。使用候选原始归档中合并 COCO 目录的正式 test.json 及 232 个测试 JPEG。编号末位为 1 或 9，原划分含近岸 46 图、离岸 186 图。图像和标签只用于输入检查，本次模型前向为零。 [作者发布](https://github.com/TianwenZhang0825/Official-SSDD/blob/937ccbec2ee967b7263e201aa085f25c4aecaebd/README.md) · [作者论文](https://doi.org/10.3390/rs13183690)

主进程与独立进程分别解码全部 JPEG。232 个文件的编码摘要各异，全部为 RGB，解码尺寸与对应 COCO 图像条目一致。图宽为 300–668 像素，高为 192–494 像素。测试总表共 397,010 字节，其 SHA-256 为 `021d52858ffa3fda9a2d28ee21f1ca114800554edf08007704f6d06a412d50bf`。依图像名排序的原始编码身份清单 SHA-256 为 `ace3e722369657d9dd6a552eeac13244b3fa88772701ae0769e676816b46152e`。

原始船类编号为 0。546 条实例标注各有一条多边形，232 张图均至少含一个有效、界内、在原始分辨率栅格化后面积为正的实例。无空掩膜、几何无效、越界、忽略或 crowd 标注。522 条多边形含非整数顶点，7,257 个顶点中有 6,902 个至少一轴为非整数，14,514 个坐标值中有 13,671 个为非整数。独立进程使用 COCO.annToMask，并逐项复现主程序的 37 项统计。 [本地读数](LOCAL_SAFE.json) · [独立读回](INDEPENDENT_SAFE.json)

在远端身份核验中，对本地归档全部 32,658 个记录头校验了 CRC，并精确定位一份 JSON、232 张 JPEG 所占的三个连续区间。每个区间两次经作者 Drive 公共地址直连，六次均未收到 HTTP 响应。当前远端认证 0/233；三个区间的本地摘要已保存，以供后续正常网络直连复核。作者 Drive 的文件名与字节数与本地归档一致。此前已认证的 TRAIN 记录另有独立范围。 [远端尝试](REMOTE_RANGES_SAFE.json) · [作者归档](https://drive.google.com/file/d/1glNJUGotrbEyk43twwB9556AdngJsynZ/view)

原始主进程执行块 d1eb03 以 0 退出；独立读回执行块 e24c74 以 0 退出。远端进程 PID 8340、会话 4349，以 shell 观测退出码 1 结束，用时 242.765 秒。 [主进程记录](LOCAL_EXECUTION_SAFE.json)

项目过去已查看此划分的结果，本轮又在预锁输入核验中读取测试标注。既有关闭记录确认 10 张测试图与 SSDD 训练侧 12 个副本编码相同，全部训练侧副本属于项目 FIT741。完整 232 图和排除这些测试重复的 222 图适用于事先指定的敏感性报告。以上记录尚未给出模型在两个总体上的效果。

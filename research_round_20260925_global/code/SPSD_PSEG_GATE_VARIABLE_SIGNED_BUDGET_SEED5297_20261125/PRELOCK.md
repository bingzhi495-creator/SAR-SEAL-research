This branch uses no oracle or new learned labels. Comparing to a fixed-allocation optimum under the same prediction model controls the direct change in action constraint.

Given the native mask M and its original sampled disjoint support E, set A_out to the number of native foreground pixels outside E. For each reference j, estimate reference area G_j=A_out+Σ_E p_j and native intersection I_j^0=A_out+Σ_E∩M p_j. Treat the native mask as the assumed reference outside E. New reference counts remain identical between actions. For additions U and removals V, use edited mask area A=|M|+|U|−|V| and estimated intersection I_j=I_j^0+Σ_U p_j−Σ_V p_j. Estimated IoU J_j=I_j/(A+G_j−I_j). Scores use change of J_j relative to original static action J_j^static. This is a ratio of plug-in expected pixel counts under a native-outside-support assumption. It does not integrate IoU over a mask posterior or estimate unobserved area corrections.

Evaluate every feasible integer addition count a in [max(0,2k−n),min(n,2k)], with deletions 2k−a, where n is the original count per sign.

# Fractional polygon-cell supervision on FIT109

Test whether fractional polygon-cell area improves endpoint ranking in the existing 1,321-parameter D-FINE point head. Use the original 109 FIT images, 10,900 candidates, five source-held-out folds, matched annotation identities, selected endpoints and feature order. Fit no detector and run no detector forward.

Use three BCE target definitions. Fractional supervision uses the exact source polygon-cell area as in the original evaluator. Threshold supervision hardens that same area at 0.50, with equality as foreground. Raster supervision reads the binary area at the identical native pixel in the original annotation's COCO RLE. Retain the original valid training-slot population, even where a hard label is constant. Preserve all within-fold standardization, original duplicated input, optimizer, batch sizes and 200 optimizer updates per fold.

Use paired Torch and PCG64 seed bases (5217, 20261112), (5317, 20261212) and (5417, 20261312), adding the same fold ordinal. The first fractional schedule must reproduce the historical training records, four historical score arms, geometry, strict-threshold transitions and exact edit budgets. All three target arms within each schedule and fold must have identical initialization-state and sampler digests. Retain all seed outcomes. No target-controlled hyperparameter or stop decision.

Force every candidate in every target arm to reuse the original first fractional run's realized fixed-pair edit count, including zeros. Rank the independent endpoints by each fitted head's own posterior under the original tie rules. Preserve the same raw mask, candidate identity, confidence, area and endpoint support. Check exact per-arm edit counts and balanced native XOR.

Report all COCO mask AP/AP75/AP90/AR scores, strict 0.90 gains and losses, observed target disagreements and threshold counts. Preserve all 412 original valid fixed matches, including no-ops, and measure exact polygon-cell continuous IoU. Report the two paired contrasts, fractional minus threshold and fractional minus raster, per seed and averaged. Bootstrap 4,096 paired source-prefix draws with PCG64(5217) over the 93 groups. For the combined interval, average the three seeds within each group before resampling groups. Keep AP and IoU effects separate. A mechanism claim of consistent improvement would require positive AP differences in all three seeds and a positive group lower bound for seed-averaged continuous IoU against both hard controls.

The detector saw FIT109 and only the point-head fits hold out source groups. This source-side comparison isolates the effect of the training target within the specified head/readout. It does not measure target benefit on an independent detector or dataset.

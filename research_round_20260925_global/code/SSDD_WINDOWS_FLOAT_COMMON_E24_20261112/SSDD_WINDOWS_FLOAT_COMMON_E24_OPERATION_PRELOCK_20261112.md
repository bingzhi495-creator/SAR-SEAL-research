# Windows PSeg-SSDD 浮点标注共同行 E24 原操作预锁

两臂分别用相同的官方 COCO RF-DETR Seg Nano Q100 初值重新训练。初始化和训练种子均为 5201。仅使用已通过 CPU 输入核对和真实 CUDA 短窗资格的浮点 FIT741。两臂使用相同的 576 输入、单图微批、四批累积、原生 BF16、TF32 设置、AdamW 与 EMA。训练总计划沿用 E100 的 18,600 次调度和 558 次预热。每臂 24 轮、每轮 744 次访问和 186 次更新，共 17,856 次访问、4,464 次更新。741 张原图外的三次补齐仍由原训练器执行。唯一定稿权重是第 24 轮原生归档的 EMA。短训权重不进入初始化。原浮点共同行短窗独立资格摘要为 78d2c6d1b99a1b05755324e061c1ad1bd4c5a460578e06e73720fa8c748ea8e0。

两臂分别使用原生或逐步中心位图，保留两种采样都非空的同一有序实例。无目标访问继续保留。逐访问核对原数据读入、实际图像、增强、框、类别、随机状态、实例顺序和最终掩膜。原空掩膜保护仍执行，其实际移除应为零。训练阶段不打开 DEV 或正式 TEST，也不计算 AP。评价阶段另行使用固定 DEV187 入口和预锁主口径。

复用原已完成 Windows E24 的 FIT-only 训练入口、JobObject、资源保护及档案回读。新增桥接只把已核验的浮点共同行绑定和观察器接入 E24，将全局访问序号转换为真实轮次及批次，并核对两份已消费记录和原生访问台账。首臂先运行并独立验收，第二臂随后使用同样条件。原资源门槛继续为主机可用内存 16 GiB、CUDA 即时可用量 12 GiB、CUDA 分配上限 6 GiB、工作进程 RSS 10 GiB 和每臂原墙钟限 36,000 秒。

新入口和已锁定输入通过零前向 CPU 预检。桥接的两个回归覆盖真实 E24 序号边界及合成 24 轮中有序实例、无目标访问和目标数量错配。原训练入口的七项回归通过。预检未启动 CUDA 或训练。训练入口绑定未发布的私有运行输入，发布源码不含原数据、权重、请求文件、账号或设备地址。

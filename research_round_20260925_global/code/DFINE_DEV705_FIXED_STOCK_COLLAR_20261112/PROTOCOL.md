# D-FINE DEV705 fixed-stock collar ceiling

This complements the prediction-side FIT109 collar test on exact previously scored D-FINE E24 historical DEV705. Reuse the original stock .50 top100 nonignored assignments and the 1,329 small slender matches to valid continuous polygons (GT area <1024, hull aspect >=2). Keep original candidate identity, box, score and binary mask. No FIT, TEST, AP, new forward or training. Source groups use filename prefix as proxy.

At t=.75 and .90 use w_i=(1+t)*q_i-t, q_i the source polygon occupancy of each native unit pixel. A binary mask meets target when sum(w_i*b_i)-t*T >=0. T is full in-frame continuous truth area. Relative to raw stock, define A as sum of positive weights in the native 2px author rectangle collar; D as absolute sum of negative weights on original foreground; N as sum of positive weights in original-box background. A/D/N supports are disjoint. Raw+A bounds additions in the collar with stock fixed; raw+A+D adds optional removal of existing foreground; raw+A+N adds optional original-box foreground but no removals; raw+A+D+N is the expanded box free optimum. Ground truth is used only to calculate these exact reachability maxima. Compare on the same individual candidates using native half-open author box and clipped image raster.

Use epsilon 1e-7 times max(1,T,original box raster area). Classify distinct positive and negative margins; near zero is indeterminate. Keep the previously established exact 206 definite original-box exclusions at .90 and 134 with positive free 2px margin among those exclusions. On that fixed 134, report theoretical reaches with the fixed stock collar only, with any removals but no new inside pixels, with any additions inside/outside but no removals, and with both kinds. Also report all 1,329 matched and all definite stock misses to establish coverage denominators. No deployment inference about score quality or improvements in AP.

# SAR-SSP cross-carrier native coverage complement

This single retrospective target diagnostic uses the already scored identical 232 SAR-SSP val2017 JPEGs, frozen RF-DETR 5202 and D-FINE E24. It has no new inference, optimization, thresholds chosen by performance, operational ensemble, or AP. Work only from independently closed native capture receipts, independent native readback/score receipts and exact candidate bytes. Bind the two original score result identities and require exact image IDs, name, JPEG SHA-256 and native size across captures and indexed author archive; independently rehash the author JPEG members. Both receive the same 232 source inputs before labels; keep all 139 noncrowd ship hulls and all 31 parent groups with 23 positive. Preserve original RF mapped 22741 and D-FINE author-retained top-100 23200 candidate slots in original order, including empty masks. The D-FINE post-NMS tail is outside study scope. Verify category mapping, original score, RLE size and pixel area and clipped native boxes.

After the input parity gate, decode exact official raster truth and retain its axis-aligned bounding boxes. At thresholds 0.25, 0.50 and 0.75, compute four-way reference coverage for masks and boxes: RF only, D-FINE only, both, neither. Coverage means a qualifying overlap by any candidate in the same chip and allows candidate reuse. In each image separately also report maximum bipartite cardinality for RF only, D-FINE only and their union under the same thresholds; the union has at most 200 opportunities per chip and is a geometric ceiling, with no common detection budget.

Reconstruct original independent score-ordered COCO mask matching at .50, std maxDets=100, all-area and no ignore. Do not call COCO accumulate, summarize, or AP. Require 92 RF matches, 88 D-FINE matches and 47 RF-unmatched hulls. Require exact agreement with a separate deterministic greedy matching implementation, ranking candidates by original scores with original stable ties and using original COCO same-IoU truth tie order. RF matches remain fixed. For the 47 RF-unmatched hulls, compute maximum one-to-one coverage by D-FINE candidates under .50 masks and separately .50 boxes. An admissible donor has a .50 edge to at least one uncovered hull. It is ambiguous if it also has a .50 edge to an RF-matched hull in the same modality. Repeat the cardinality analysis after deleting all ambiguous donors. Count donor opportunities, ambiguities and original parent groups affected. Tie in maximum-cardinality assignment by maximum total overlap over qualifying edges, then the fixed scipy implementation on original ordered arrays. With labels selecting the edges, none of these rows is actual deployable recall.

The practical gate for further source-only donor engineering is at least 8 additional conflict-free .50 mask matches across at least 5 different parents, about 5.8 absolute recall points on all 139 hulls. Record parent scene spread and a group-balanced rescue fraction with 4096 paired parent bootstrap samples among 23 ship-bearing groups (PCG64 5323). Retain all source memberships but emit only totals and no identifiers. A box-only result cannot pass the mask gate. If gated off, existing two-carrier donor insertion is low priority at .50; the number cannot decide new detectors or target data. If gated on, only motivates a fixed-budget source-fit router compared with score/rank/NMS alternatives on a different scene cohort. Keep the investigation retrospective and label-guided.

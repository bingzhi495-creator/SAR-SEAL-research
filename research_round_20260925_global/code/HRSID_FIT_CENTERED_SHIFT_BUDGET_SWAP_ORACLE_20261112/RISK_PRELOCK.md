# Fixed topology and neighboring-instance diagnostics

The permitted swaps use independent add and remove sets. The greedy pairing is exactly attainable within the declared area and budget constraints, which do not couple pair positions, components or neighboring masks. Report counts of swaps increasing or decreasing the eight-connected component count and of swaps making maximum continuous original-raster IoU against any higher-ranked native candidate cross from below .20 to at least .20. Also report counts where that maximum increases. Compare original and edited mask on the same higher-ranked candidates with original rank and score. These are risk diagnostics, not post hoc vetoes or part of the existing utility gate. No such risk reading is needed for the fractional rigid action because it preserves native continuous topology and the current comparison uses it as an oracle ceiling.

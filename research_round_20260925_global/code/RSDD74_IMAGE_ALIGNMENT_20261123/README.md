# Image-only displacement on Instance-RSDD

The [locked protocol](../../RSDD74_IMAGE_ALIGNMENT_PRELOCK_20261123.md) uses the [closed 74-image Phoenix comparison](../../INSTANCE_RSDD_PHOENIX_EQUAL_COUNT_ACTUAL_20261123.md). It shifts the image input one native column in either direction while retaining the original 7,346 candidate masks, boxes, confidences and endpoints. Each modified arm makes 29,900 additions and 29,900 deletions. The original static attraction arm has zero response by construction.

1. Run <code>occupancy_retry.py</code> under the earlier study's <code>observe.py --phase edits</code>. Supply the same B5 stock root, PointRend label-free archive, classical verification archive and terminal, Phoenix request and terminal, and the three frozen source-occupancy checkpoints. The worker verifies exact unshifted-mask replay for all three seeds before accepting the six displaced arms. The initial <code>occupancy.py</code> read the precision setting before the original image-decoder import. Keep its failed run separate.
2. On the qualified Linux Phoenix CPU environment with multiprocessing <code>fork</code>, run <code>infer_shift.py</code> under <code>observe.py --phase inference</code> once with <code>--shift-columns -1</code> and once with <code>--shift-columns 1</code>. Use a fresh output directory each time. Supply the new protocol as <code>--diagnostic-lock</code>, its fingerprint as <code>--diagnostic-lock-sha256</code>, and the accepted prior <code>infer.py</code> as <code>--original-worker</code>. The remaining options are the [prior inference arguments](../INSTANCE_RSDD_PHOENIX_EQUAL_COUNT_20261123/README.md#dgx-author-inference) with the original request and lock and four workers with two threads each. The worker checks the lossless RGB content before performing the horizontal index shift, copying the nearest edge column.
3. Run <code>score.py edits</code> with the two closed Phoenix endpoint files and receipts, the occupancy edits and receipt, and the original request and original edit archive. Then run <code>score.py score</code> with the same parents, the closed assembly and archived evaluation, and the author's <code>annotation_coco/train.json</code>. Observe each phase separately and use <code>--help</code> for the specific argument names. Keep the raw images, private endpoints, candidate masks, original annotations and host receipts in authorized storage.

The primary outcome compares the left-to-right mask-centroid response of Phoenix with the mean response of the three occupancy seeds. It uses the pre-existing 47 fixed matched hulls and paired sensor/date bootstrap. The scorer separately recomputes full COCO rematching for all arms using unchanged candidate confidences. This is an intervention on an already scored cohort.

# HRSID signed-distance selection on nested fixed-budget RLE support

Run a new no-label selector on the exact first HRSID FIT36 binary-vote carrier. This cohort is previously analyzed, and this is a source-side screen before further training or a target replay. Hypothesis: newly reachable useful pixels indicated by just one donor are selectable using ordinary shape evidence. Keep the same 2,620 original mapped nonempty candidates, confidence, order, 468 accepted triplets, and exactly the observed binary vote per-mask additions and deletions. All unedited candidates remain raw. Closed original binary mask, exact association, actual vote and same-count geometric anchor controls are fixed. Never access logit planes, no model forward, training, DEV or TEST.

On the union bounding box of the three native masks plus a three-pixel margin, compute signed Euclidean distances to opposite-class pixel centers: positive inside, negative outside; pad the grid with one false cell for the inward distance, then remove it. Clip each signed distance to [-3,+3] native pixels and take the unweighted sum across the anchor and two donor masks; sum and mean are equivalent for ranking. Truncation limits deep interiors and far background. Restore the original grid without resizing. With a fixed native two-pixel Chebyshev anchor band and existing per-mask counts, select additions by highest sum and deletions by lowest sum, with row-major ties. Use the same score on three nested domains: both donors disagree, at least one donor disagrees, and full band. A candidate with zero original edits has zero edits in every arm. Keep the archived actual majority vote and its original equal-count anchor-geometry control. Verify identical count and after-edit area in every arm and immutable label-free edit stream before opening FIT labels.

Evaluate stock COCO mask AP/AP75/AP90/AR100 over all 36 images and 2,620 original candidates. Fixed geometry uses original stock IoU .50 nonignored matches of 69 valid small anchors with exact source polygons and 31 source groups. Report source-equal continuous IoU, strict hits and FP/FN, candidate and group coverage, edit location distribution and actual compute. The lead is fixed: at-least-one donor, using signed distances. Continue to held-out confirmation only if it adds ≥.30 AP points and ≥.20 continuous IoU points vs both original binary vote and signed-distance ranking on the two-donor domain, with no AP75 or fixed .90 hit decrease vs original vote. Full band is a mandatory strong support comparison and cannot replace the lead. An already explored source result never establishes training or cross-dataset generalization.

Before execution, the ranking invariance is also recorded. On this band the anchor opposite-state distance is at most sqrt(8). Every both-donor-disagreement site has directional score at least 2−sqrt(8), while a site where all three masks agree has at most −3. Each inherited per-sign budget already fits the both-donor domain. Consequently the same-score full-band arm must be pixel-identical to the at-least-one-donor arm. Keep it as an implementation invariant, not an independent efficacy result. Count selected one-donor-only positions and cutoff ties.

The matched-domain simpler control ranks the exact same at-least-one-donor support using only the anchor signed Euclidean distance. It uses the same per-sign budget, row-major tie and clip. The lead must also pass the stated AP and fixed-IoU margins against this control. Full band identity is verified before scoring, so a duplicate COCO scoring pass is unnecessary.

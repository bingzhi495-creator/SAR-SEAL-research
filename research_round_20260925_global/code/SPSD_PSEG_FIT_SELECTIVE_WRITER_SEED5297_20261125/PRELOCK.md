# FIT-only calibration for selecting fixed-budget boundary writes

Freeze before any new training trace or gate outputs. Earlier safe evidence suggested abstaining to a static same-count incumbent when the learned action's benefit is uncertain. The older truth-based oracle is motivation. This experiment uses no oracle outputs as inputs. It studies selective adoption of the original two-reference BCE robust policy relative to the identical fixed-count static action. The production head is the exact archived candidate-balanced seed-5297 BCE head from SPSD_PSEG_FIT_MATCHED_SIGNED_ACTION_SEED5297_20261125_01, same-family as the five complement occupancy fits. Target action keys are bce_robust and bce_mean under the already accepted matched signed-action source gate. No source-gate labels, predictor vectors or outcome enter this fit.

Use exactly the old 848 original FIT candidates in 447 images and 439 decoded groups, the frozen signed endpoint geometry, static-at-dynamic native k, binary two-reference occupancies, and exact group-fold OOF BCE predictions from the previous bank workflow. Regenerate and verify exact original association/tensors, folded groups and ordered probability digest. Each OOF probabilities file entry is predicted by a candidate-balanced BCE fit excluding its whole decoded group and image, complement-only feature scaling; estimated candidate targets are never used by the action selector. The five OOF complement fits each use 1,000 updates as pre-admitted. Do not use richer action labels for occupancy. Some FIT candidates may already write static; those are ineligible for the trained adoption model. Scope and counts are fixed even when no such candidates occur. Reconstruct both original robust and mean actions with the exact finite selector and static incumbent; only robust adoption gets a fitted policy. Keep the entire mean policy as a separate control.

For exact static-relative signed endpoint vector W and native pair quota k, predict gain per reference as the dot product with its occupancy divided by 2k. Build 9 scalar features for each nonstatic robust action, ordered as average predicted dual gain, half absolute predicted gain difference, same-action signed native decoder-probability gain divided by 2k, original log2 foreground mask area and original detector score, k/8, available endpoint pairs/32, and changed add-index and drop-index fractions relative to k. Retain the normalized minimum estimated gain separately as the raw margin control. The true target is min of the two exact signed intersections / (2k), using original raster occupancy and the same selected action, relative to static. The sole learner is candidate linear ridge, lambda 0.02 on standardized slopes with an unpenalized intercept. Group balance by giving each exact decoded group equal probability, each active image within group equal probability and each eligible candidate within image equal probability. Use corresponding weights to estimate center, scale and intercept, use scale one when variance is degenerate. Closed linear solve only, no trial variants or calibration threshold fitting. No shallow non-nested validation of the second stage is inferred from OOF occupancy.

After actual fit exit and independent readback, prelock gate evaluation separately and verify exact earlier same-family frozen masks. Consider positive-k candidates whose original BCE robust write differs from static. For each image, set M=floor(N_distinct/3). First allocate floor(n_k/3) to each native k stratum with n_k eligible candidates, then allocate each remaining adoption to a stratum in descending order of n_k modulo 3, ties by smaller k. The two policies choose from the same stratum with the exact same allocated count. One fixed learned ordering uses ridge score; one fixed control uses normalized minimum predicted gain. Break exact ties by original native rank. All other positive-k candidates use static. This holds both adoption counts and sum of realized per-image signed quotas fixed between selective arms, in addition to fixed original confidence, mask set, source and total edit capacity. Unconditional robust, unconditional mean, cell-pessimistic, dynamic, static, and native are references. Global realized adoption can be below one third due to per-image floors. This experiment tests a fixed-coverage policy against a matched-coverage margin control, and says nothing about calibrating absolute probabilities or tuning thresholds.

Require the two matched selective raw scorers to use identical signed edit counts per candidate and the same image×k adoption totals before labels.

# 固定交换量下的选择性写回校准

本轮固定候选、静态掩膜、两参考 BCE 模型和联合选择器。针对每个候选，方法学习何时采用联合动作，何时保留同量的静态动作。比较以每图合格候选数的三分之一向下取整为采用数，再按原交换量分层分配额度。学习排序和原模型最差参考预测收益排序使用相同的每图额度和各层额度。两种选择策略在相同候选内使用原有写回预算，保留原置信度与候选顺序。

拟合重建既有五折预测。每个训练候选的占据率由未见该图及同组图的补集模型给出。岭回归使用九项特征，分别为预计平均收益、两参考预计半差、原始解码概率的同量收益、掩膜对数面积、置信度、归一化交换量、归一化点数，以及两侧更换索引的比例。拟合目标是相对静态掩膜的真实最差参考有符号交集变化除以 $2k$。求解中按解码组、组内图像及图内候选依次等权，标准化和系数仅由 FIT 得到，固定岭惩罚 0.02。联合和均值写回均从原选择器重建，单独拟合联合动作的采用次序。

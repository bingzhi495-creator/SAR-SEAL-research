# Frozen Instance-RSDD comparison

[Original protocol](../../INSTANCE_RSDD_FROZEN_HRSID_PRELOCK_20261122.md) · [Observed results](../../INSTANCE_RSDD_FROZEN_HRSID_ACTUAL_20261122.md)

1. Use the [author label release](../../INSTANCE_RSDD_AUTHOR_FILES_ADMISSION_ACTUAL_20261122.md) and the [RSDD image mirror](../../INSTANCE_RSDD_IMAGE_ACCESS_ACTUAL_20261122.md). `intake_test740.py` obtains the original ZIP records from the author image roster, and `readback_intake.py` checks the exact RGB decoder. Each script lists its required inputs with `--help`.
2. `capture_instance_rsdd.py` runs the original HRSID center5202 E24 model on the verified image-only roster and independently verifies its original masks. Run the original observed `capture` and `verify-capture` stages. The published [UEIKAP carrier](../UEIKAP_RFDETR_CARRIER_20261122) documents the source model, native semantics and compatible runtime.
3. `replay_rsdd.py` prepares and verifies the seed-5217 edits. `seed5218/replay_rsdd.py` applies the next frozen HRSID refit to the same closed capture under the [replication protocol](../../INSTANCE_RSDD_FROZEN_HRSID_SEED5218_PRELOCK_20261122.md). Use the observed `prepare-edits` and `verify-edits` stages and the pinned inputs supplied by each entry point. Each readback reorders and checks the edits independently.
4. `score_rsdd.py` uses standard COCO segmentation metrics and fixed-match continuous geometry. It reads the exact author test labels only after both observed label-free receipts pass. Supply the phase authority JSON and independently computed digest as indicated by `--help`; the permitted input field names are listed in `main`. The original file's geometry and author area remain intact. The COCO matching arrays reserve zero, so the scorer replaces only annotation IDs with a globally positive bijection when needed. Use the qualified Python 3.10.13, NumPy 1.26.4, pycocotools 2.0.11, Shapely 2.0.2 and GEOS 3.11.2. `test_score_rsdd.py` takes the released code root and the Python 3.10 Shapely dependency directory as arguments.

The release contains protocols, code and aggregate results. Original label and image files, weights and per-candidate streams are obtained locally using the documented sources.

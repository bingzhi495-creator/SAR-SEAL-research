# Group cross-fit grayscale rank probe for common edit gain

Run only on the closed source FIT population, before reading any new source-gate output. Reuse the exact original heuristic action packets and digests from the 5297 FIT phase. Its 5,042 proposals use the image, native response, attraction, and fixed random permutations without any trained author-label occupancy model for the proposal geometry. The presence of a shared eligible native hull is conditional on both author masks. This is an action prediction probe, not a mask evaluation or an independent acquired benchmark.

For each original nonstatic action subtract its static incumbent exactly and divide by 2k. The response is the mean of the two author intersection gains. Analyze native decoder score alone and native score plus one grayscale cue: raw grayscale, centered midrank across all inner and outer endpoints, or centered midrank within the same side. The midrank divides counts of strictly smaller endpoints plus half the equal count by the relevant endpoint population, then subtracts 0.5. No coordinates, per-scene labels, or test strata are added. Use the same signed summation for every cue. The three two-cue fits have equal capacity and all use the same folds and sample weights. A zero-gain static input maps to zero because the models have no intercept.

Use the frozen deterministic five-fold exact-decoded group assignment from the preceding bank workflow; it depends only on the group hash. Fit a linear ridge coefficient for each arm on the complementary four folds, using group→image→candidate→action equal weights and training-fold weighted RMS scaling without centering. Fix ridge lambda=0.001. Report out-of-group MAE and RMSE as percentages of the signed write budget, with 4,096 paired exact-RGB-group draws for MAE (PCG64 seed 5297). Primary exploratory contrast is pooled rank versus raw grayscale; pooled rank versus side rank measures specificity. Interpret improvement only if the paired MAE interval is below zero. Do not transfer any parameters into the main experiment, open labels outside FIT, perform new detector forwards, or change the frozen task gate.

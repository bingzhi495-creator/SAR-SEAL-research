Run `prepare-edits` and `verify-edits` with the existing [observer](../HRSID_DEV705_CLASSICAL_ATTRACTION_20261122/observe.py). The verify phase independently orders the endpoints and checks every reference mask and edit. `test_edit_rf.py` takes the absolute released `code` directory as its argument.

Run it only after observed successful label-free replay. `test_score_rf.py` uses synthetic images and polygons. Use the versioned runtime and original assets indicated in the earlier [UEIKAP protocol](../../UEIKAP_RESERVED_HULL_PRELOCK_20261122.md). The release provides source and aggregate receipts. Obtain original imagery and labels from the linked publisher.

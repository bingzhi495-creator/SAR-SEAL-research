The parent protocol fixes the 583-image Gaofen-3 cohort and the 74-image reserve, including its nested 42-image view. Both use the original RF-DETR 5202 stream. The Gaofen-3 comparison retains head seeds 5217 and 5218. The reserve retains head seed 5217. Each candidate inherits its exact signed count and maximum individual squared displacement from the writes selected by F. The archived candidate scores are fixed.

`render.py` restores the original source point head, checks the historical capture and replay closure, and requires exact archived endpoint-write mask identity before producing the new bounded masks. It imports the released Phoenix matching solver by digest and uses only frozen learned probabilities. The receipt exposes only aggregate feasibility, geometric movement, and edit counts. Read only the label-free render when its supervised execution record closes normally and verifies the receipt footer.

`score.py` accepts the exact observed render result and observed terminal file for each prescribed seed. The private render manifest maps each head seed to a record with `result`, `terminal`, `result_sha` and `terminal_sha`. The scorer checks the original capture, candidate scores, masks, write counts, and archived AP and continuous-IoU parity. Its metric scope consists of the original public author reference polygons, stock COCO mask scores, and the original fixed-mask matches. Acquisition resampling retains shared anchors over both heads and uses the archived sensor/date blocking for the reserve. The only release-safe output is the aggregate result JSON, the code, and documented provenance.

Use the frozen Python 3.10.13 CPU replay environment with `-I -B -X utf8` and one thread per numerical worker. Use the original observer's `prepare-edits` and `score` phases.

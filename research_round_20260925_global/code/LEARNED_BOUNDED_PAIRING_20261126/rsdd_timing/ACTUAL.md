# 冻结端点选择的本机耗时

使用 Instance-RSDD 原 74 图保留集的冻结 RF-DETR 5202 和 5217 点头。三种策略处理同样的 7,346 个候选，其中 4,092 个有正预算，每臂实际执行 30,841 次成对交换。缓存复核逐候选通过，三臂所有压缩 RLE 掩膜与已验收的原输出完全相同。计时使用 Intel Core i7-13700KF，固定到同一个逻辑处理器，数值库单线程。每臂完整预热一次，随后执行 F、L、I 的全部六种次序。

| 策略 | 选择，毫秒／图 | 选择，微秒／正预算候选 | 共同 RLE 写回，毫秒／图 | 两项合计，毫秒／图 | 两项合计，74 图中位数［最小，最大］秒 |
| --- | ---: | ---: | ---: | ---: | ---: |
| F 原距离配对 | 0.214 | 3.864 | 25.937 | 26.125 | 1.933［1.782，2.317］ |
| L 后验最优限距配对 | 113.132 | 2045.883 | 25.230 | 138.588 | 10.255［8.806，10.971］ |
| I 独立端点选择 | 0.311 | 5.629 | 27.133 | 27.433 | 2.030［1.708，2.514］ |

图均值由完整队列耗时归一，表中每列独立取六次复算的中位数。F 和 I 的选择段都在 0.4 毫秒／图以内，本机局部耗时主要来自共同 RLE 写回。L 的选择段包括计算端点距离和精确约束匹配。不同策略产生的掩膜沿用同一解码、赋值和编码实现。

比较从已准备好的端点、二进制单精度占用概率、原始配额和距离上限开始。F 沿用已缓存的配对行，每次重算分数差和稳定排序。I 每次对两侧重做稳定排序，并沿用原配对行的并列次序。原距离配对的求解在缓存阶段。检测、端点构建、冻结点头计算和文件读写均在计时范围之外。数值反映该 CPU、该实现及该批候选的局部耗时。

缓存复算约 51 秒，计时工作进程包含校验与全部重复，共约 100 秒。两段均自然退出 0 且结果尾签校验通过。实验未读取标签、未前向运行检测器、未训练。

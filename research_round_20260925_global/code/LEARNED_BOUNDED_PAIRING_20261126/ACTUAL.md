# 冻结占据头的等预算限距配对

同一冻结 RF-DETR 5202 和相同的 1,321 参数占据头，在每个候选上保持原生掩膜、置信度、端点集合与实际增删预算。原方案先最小化配对距离，再按占据收益选出正收益的 `k` 对。限距方案保留这 `k` 对中最大的单次位移，以原占据分数为目标重新求解 `k` 对无重复端点的全局最优配对。独立选点解除配对距离约束并维持相同增删数。限距方案固定的是最大单次位移，端点分布、总位移与拓扑可以变化。[评分前公开的方案](PRELOCK.md) · [精确求解器](../PHOENIX_BOUNDED_MATCH_20261123/matching.py)

数值均以百分点计。方向判据联合检查 0.30 AP 点、配对几何区间方向与改变的原生匹配覆盖。表中连续 IoU 用同一原生匹配和多边形覆盖面积计算。按历史分组做 4,096 次配对重采样，HRSID 是 27 个采集前缀，高分三号是 68 个父景，74 图保留集是保持父景等权的 11 个传感器日期块。重复点头共用各自队列的影像和匹配，42 图属于 74 图的嵌套敏感性。[HRSID 逐头实测](hrsid/ACTUAL.md) · [Instance-RSDD 逐组实测](rsdd/ACTUAL.md)

HRSID 同时支持配对顺序和原位移上限两项作用。74 图的限距重配改善几何而 AP 近乎持平，独立选择保留额外的 AP 与连续 IoU 收益。高分三号两项几何区间均为正，效应在 AP 上较小。四个视图均未满足限距重配实际恢复原收益的预设容差。三臂的估计占据收益具有顺序，实际指标分别由作者标注计算。已有一像元 Boundary IoU 比较使用独立臂和原距离优先臂，度量原生栅格内边界带。该指标和本次连续 IoU 在论文中分别报告。[一像元边界诊断](../INSTANCE_RSDD_NATIVE_BOUNDARY_IOU_20261126/ACTUAL.md)

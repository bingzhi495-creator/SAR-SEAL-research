# 双参考最小增益排序的同预算实测

在已用过的 183 张作者 TRAIN 留出图、180 个精确解码组上，比较 BCE 加动作增益回归与 BCE 加双参考最小增益的成对排序。两臂各有 1,346 参数、1,000 次相同样本和初始化的最终更新，复用原先锁定的同一 FIT 组外预测动作库。按原配方重新执行的共享准备共 5,000 次更新，两组使用的结果摘要一致，成本单独计入。回归臂训练张量及三种写回均精确复现旧部署型动作库对照。存档写回保留为单列复核组。[预锁](PRELOCK.md)

全部 18,300 个原候选、原生分数和置信度顺序不变。8,785 个正预算候选上每个写回臂同样新增 57,692 个像元并删除 57,692 个。固定 IoU 从每套参考各自的原生 COCO IoU 0.50 关联计算，411／410 个作者参考全数保留，原生漏配记零。差值以 4,096 次配对解码组等权重抽样计算区间。原生、动态、静态及存档三写回的 RLE 和指标逐值核对。

## 固定同一组选项后的顺序测量

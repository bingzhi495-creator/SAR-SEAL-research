# Can the frozen HRSID ranker benefit from an area quota?

This geometry diagnostic uses HRSID DEV705, the existing 5202 frozen carrier, and its original 1,461 valid native COCO 0.50 associations in 27 source-prefix groups. The study uses a historical development population. Candidate selection for computation comes from the old independently scored association ledger. Candidate identities, scores, footprints, endpoints, matching and polygon geometry remain fixed. No Instance-RSDD evaluation input is used.

The prior study found a 2.111-point equal-count, equal-area localization gap between the learned SU rule and truth-ranked editing. Free truth-ranked allocation of additions and removals added 1.001 IoU points. We test whether allocation can also help when the individual endpoint ranks remain frozen. This determines whether an allocation predictor is worth developing for the current small point head.

Recompute the frozen S head for seeds 5217, 5218 and 5219 on the original native endpoints of the 1,461 valid associations. Use the exact original image reader, probability path, stored CUDA correction when its candidate is included, and the independently accepted full-FIT weights. Rank additions by decreasing S posterior, deletions by increasing S posterior, and ties by original pair ordinal. Obtain the edit count \(2k\) from the archived SU choice. The first \(k\) entries on each side must reconstruct that choice in exact order. Require exact identity, endpoint parity and previously scored native/SU geometry. Save ranks before reopening the original DEV ground truth. The fixed-match roster used to select computation was created by that earlier scoring.

Enumerate the feasible addition counts given exactly \(2k\) total flips. For each addition count use the leading additions and deletions of the unchanged learned ranks, and use the original verified polygon occupancies only for scoring. Select the count with the greatest true IoU. If scores tie, prefer the count nearest to balance and then the smaller addition count. The baseline SU is the balanced member of the enumeration. Compare the resulting quota-only ceiling Q with SU and the original fully truth-ranked balance U and area-free F. Check \(F\ge Q\ge SU\) and \(F\ge U\ge SU\), allowing at most \(10^{-12}\) arithmetic error. Use the original mask area, true polygon area and native-cell intersection. A zero budget remains unchanged. Report group-equal mean effects, after averaging the three seed effects per candidate, with paired 95% intervals over 4,096 source-prefix bootstrap draws using PCG64(5217). Report all seeds, counts, changed net area directions, strict 0.75 and 0.90 gains, FP/FN and runtime. Bootstrap intervals describe this population.

Since Q can choose the balanced action, its advantage is nonnegative by construction. The next source-only quota predictor is warranted only if the mean Q−SU is at least 0.20 continuous IoU points, the lower paired bound is above zero, at least 20 distinct anchors improve, and improved anchors cover at least eight source groups. A pass establishes headroom given these ranks. A fail constrains the quota-only route at the current support and budgets. This truth-guided diagnostic does not score AP, modify detector or head weights, or test any deployable new policy. Prior gates are preserved.

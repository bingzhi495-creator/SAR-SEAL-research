# 相同交换预算下的部署动作训练

2026 年 11 月 25 日。此前在源域留出集核验 8,785 个正预算候选时，两种训练方式实际写回的动作能量分别约有 60% 和 62% 落在旧动作集合的线性跨度之外。本实验只改变参与辅助损失的训练动作集合，检验让动作集合更接近部署选择器后，是否值得独立评估。

对 439 个有效 FIT 解码组做五折交叉拟合。每个候选只由未见该图及同组图的 BCE 点头预测。部署动作集合取自相同冻结选择器的 11 个分侧权重方案及静态动作所生成的有限集合。按预测双参考有符号交集变化的最差值降序取方案，静态动作既参与部署选择，也保留为每个训练动作的参照。每个候选仍使用原有动作个数、端点和每侧交换量。部署集合不足时按原顺序补入旧动作。

| 拟合量 | 旧动作对照 | 部署动作 |
| --- | ---: | ---: |
| 共享 FIT 解码组、图像、候选 | 439 / 447 / 848 | 439 / 447 / 848 |
| 原始成对端点、每臂离线动作 | 26,983 / 5,042 | 26,983 / 5,042 |
| 参数、AdamW 更新 | 1,346 / 1,000 | 1,346 / 1,000 |
| 采样候选、端点、动作暴露 | 64,000 / 4,079,674 / 380,295 | 64,000 / 4,079,674 / 380,295 |

初始参数、抽样顺序和标准化严格相同。两个最终训练臂均使用 BCE 与系数为 1 的 SmoothL1，转折参数为 0.1。每个候选两参考的有符号面积变化都用 2k 归一化。五个给定的互补折各执行 1,000 次 BCE 更新作为独立计量的方案准备。最终训练和准备共观察约 22.55 秒，未运行检测器，也未读留出域标注或历史正式测试。三个合成测试和独立权重回读通过。

部署方案沿用交叉拟合选择器的 5,028 个动作，并在 9 个候选中补入 14 个旧动作。所有 848 个候选均更换至少一个动作，与旧动作集合合计仅共享 17 个动作。847 个非静态交叉拟合最差值最优动作全部进入新动作集合。这一结果只说明训练干预确实发生，留出域效用由独立比较确定。 [拟合汇总](../../results/SPSD_PSEG_MATCHED_DEPLOYMENT_ACTION_BANK_SEED5297_20261125_SAFE.json)

## 历史对照复现范围

首次配对拟合因旧臂未逐位复现历史终点而自然退出 1，未生成可用的干预权重。按当前 CPU 单线程设置独立复跑两次原训练程序，两个终点逐位一致，但仍不同于历史终点。历史与当前旧臂的最大、平均和均方根参数差异分别为 0.22679、0.00283 和 0.01015，两次原程序复跑分别约 17.10 和 17.21 秒。额外的双线程复跑得到另一组不同的终点，表明线程设定能影响同一程序的终点，历史执行配置仍未查明。新配对在读取干预结果前另行锁定，两组共享当前运行环境，旧动作臂逐位匹配两次当前环境复跑。历史模型保留为敏感性比较。 [首次停止及复查](ATTEMPT01.md) · [修订协议](PRELOCK.md)

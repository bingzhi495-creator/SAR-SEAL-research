# FIT fixed-query registered-shift evidence for local area-preserving repairs

Lock before reading the shift response stream. Reuse the 36 fixed center-trained HRSID Q164 FIT views and original native detections. Original query projection and scalar bias remain fixed. The point logit columns are original, x minus, x plus, y minus, y plus, all registered to original image coordinates. Shifted point evidence comes from the actual frozen spatial basis, not a resampled copy of the native logit field. The frozen point roster lies within the two-pixel native boundary band. All model fields and candidate rankings stay fixed. Labels only determine training responses and score after original .50 nonignored fixed matching. No DEV or TEST.

Primary cohort: the original mapped predictions of area [32,1024) with both inside and outside points, valid source polygons and an original fixed match. Keep predictions vetoed by higher-ranked neighbor IoU >=.20 in the reported denominator and give them a zero action in every arm. Other candidates use K=min(8, floor(area/10), outside count, inside count) additions and K removals for each main arm. Compute exact target continuous polygon occupancy per original pixel cell. Rank outside pixels by greatest predicted occupancy and inside pixels by least; ties follow locked point order. Apply the native footprint changes for continuous IoU and normalized FP/FN. Keep original areas and candidate IDs. Include no-edit and direct average-logit ranking baselines.

Use three grouped folds from the 36 original distinct-source images in fixed capture order (ordinal modulo 3). Every held image is scored using regression fit only from the other folds. All predicted occupancy regressions have six features and unit ridge penalty, with training-only standardization, no intercept penalty, and equal training-image weight. Within each image give matched candidates equal weight and each candidate's sampled points equal weight. The target is continuous source occupancy. Shared features are native z0, original signed distance, mean of the five registered logits and standard deviation. Generic augmentation uses |odd x| and |odd y|, where odd is (plus-minus)/2. Directional arm replaces the last two features with the signed projection of odd x/y on the original outward normal and its absolute value. A same-capacity orientation control uses the perpendicular tangent. Use identical captured inference cost, point support, widths and K. No model update in the detector.

Primary lead requires fixed matched mean continuous IoU >=.25 points above no-edit and >=.10 points above both generic augmentation and the perpendicular control. Directional difference versus both should be positive in at least two of three held-out folds. Report strict IoU .90 gains/losses, FP/FN, topology or neighbor risk, effects on 36 images and the FIT-only shared-base limitation. If strict count falls or no gate passes, keep all results and stop this direction for now. This is a scout on a pre-existing FIT cohort, with held-out readout fitting only. Even a lead must subsequently repeat on fresh source groups. Neither oracle labels nor the per-target oracle budgets set the prediction actions.

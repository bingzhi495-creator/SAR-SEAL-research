# 完整自主UNet++的共享实例接口：未执行研发草稿

日期：2026-10-17。以用户原完整结构作为图像主干；本目录只实现实例接口，不重写或取代原主干。

`make_adapter(torch, backbone, feature_module_name, feature_channels, query_channels=256, hidden=32)`由调用方明确传入Torch和已选主干。对full可取CONV0_4、64通道；其他版本须核准实际模块名和通道，不能按文件名猜测。

`encode(image)`临时hook所选特征模块，运行原主干一次，保留梯度并投影为公共特征；finally移除自己的hook，无常驻特征缓存。`predict(encoded,e_q,M200)`只运行查询小头，返回与公共特征相同网格的残差；`forward`分批query但仅encode一次。实例头末层零初始化。

原主干、GT、初始化权重、冻结载体、原分数/类别/顺序、原图预处理及最终logit渲染均不由此模块隐式决定。其输入M200是原始预测粗logit，不能输入GT。接口不改变主干训练模式或requires_grad；原语义输出头仍被调用但不在实例损失中时不会有梯度，正式训练需预锁有效参数及优化器集合。

若完整主干U是400网格，残差也是400；不能直接套用N28的200网格契约。实际400→800填充网格→裁剪→原尺寸的几何与零残差身份仍待数值核验。共享主干只解决重复计算组织，不证明实际显存、速度或精度。

开发证据：单项公共行为测试先观察到缺实现的RED（e10a00，exit1，明确未导入Torch）；实现后仅AST通过（5650c0）。**尚未运行GREEN、任何真实张量、原始UNet++、真实影像或COCO。** 测试使用tiny真实nn fixture，未来验证非零读出下逐query/分批/置换一致及每图主干一次；即使通过也不等于完整主干或真实任务通过。

# SSDD 小数标注 E24 的验收与 B 臂接续

原生 A 使用已发布的修正入口。模型、COCO Q100 初值、种子 5201、741 张 FIT 图、官方小数多边形、共同非空实例和 24 轮预算按原协议。A 已实际完成前两轮，共 1,488 次 FIT 访问、372 次 AdamW 和 372 次 EMA。第一、第二轮耗时 127.054 和 125.139 秒，各含 744 次访问及 3 条补齐，共同监督分别 1,440、1,471 条。原空掩膜保护移除数均为零。原训练仍在运行，完整 E24 独立验收、中心 B 和 DEV187 待后续实际运行。 [小数训练预锁](../../PSEG_SSDD_OFFICIAL_FLOAT_COMMON_TRAIN_PROTOCOL_20261111.md)

原生 A 自然退出后，独立验收器以原外层等待、原子进程退出、精确调度、EMA、权重及有序账本验收 E24。中心协调器只有在原生独立回执与原权限记录、原权重逐项吻合后才开放 B；中心子进程沿用 A 的同一科学工作体。两组均完整闭合才验收实际非掩膜输入、随机流、共同监督及不同的所选掩膜。这些新入口已通过两项中心启动门测试及既有九项端点验收回归，尚未在两组完整 E24 上执行。私有原件、运行状态与本机数据由原执行目录维护。

# Instance-RSDD overlap representation sensitivity

The [prelock](../../RSDD_STRICT_CONTINUOUS_PRELOCK_20261123.md) reuses the [accepted 5202 main-table replay](../SAR_B5_MAIN_TABLES_20261123/README.md) and [closed 5203 test and reserve runs](../INSTANCE_RSDD_CARRIER5203_20261123/README.md). It opens no model and evaluates the original masks at the original confidence scores. Use the B5 CPU runtime with CUDA visibility disabled.

Run <code>score.py --code CODE --detector-seed SEED --cohort N --run-root RUN --protocol LOCK --protocol-sha256 SHA --author-labels FILE --output FRESH</code> with <code>python -I -B -X utf8</code> under the [phase observer](../GULF_AIS_FROZEN_20261123/observe.py) in <code>score</code> mode. Set <code>RUN</code> to the closed author-test reproduction directory for 5202 with 740 images, the closed 5203 test directory with 740 images, or the closed 5203 reserve directory with 74 images. Use the original author <code>test.json</code> for 740 and <code>train.json</code> for 74. Each prior stage's native prediction and edit hashes must be exact.

The evaluator checks all 13 archived raster metrics, replaces only the IoU matrix and repeats COCO matching on matching support and area bins. Events at IoU 0.90 keep the original candidate identities, tie order and truth IDs internally. The bootstrap repeats groups by count in the original sorted order and emits only aggregate intervals and transition counts. Run <code>test_ap90.py</code> and <code>test_continuous.py</code> for synthetic timing-independent checks. Predictions, masks, author annotation files and per-image events stay local.

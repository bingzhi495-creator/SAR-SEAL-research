# Frozen PointRend transfer comparison on Instance-RSDD

All five arms share one HRSID-trained RF-DETR checkpoint, the author test population, native candidate identities and scores. The [prelocked protocol](../../INSTANCE_RSDD_POINTREND_TRANSFER_PRELOCK_20261122.md) specifies the source refit, support and evaluation. [Prior transfer results](../../INSTANCE_RSDD_FROZEN_HRSID_ACTUAL_20261122.md) document the two occupancy-head seeds and the original test release.

1. Fit the PointRend adaptation with `refit_pointrend.py` and the exact `SOURCE_REFIT_PRELOCK.json`. The source inputs are the independently accepted HRSID FIT109 carrier features and matched source masks used in the earlier [five-fold study](../../RFDETR_POINTREND_FIT109_ACTUAL_20261121.md). The final source-only checkpoint has no scaler.
2. Run `capture_basis.py` on the image-only roster accepted by the [original transfer capture](../INSTANCE_RSDD_FROZEN_HRSID_20261122). The original checkpoint, inference settings, candidate streams and raw logit planes are verified before accepting the detached spatial bases. Effective CUDA matmul precision is `high` because RF-DETR 1.12.0 sets it at import. The reference carrier disables cuDNN TF32.
3. Run `replay_pointrend.py prepare-edits` and `replay_pointrend.py verify-edits` in separate observed processes, with the closed source-fit and basis receipts. The workers have image-only and frozen-source inputs. The second pass independently renders each candidate again and verifies exact per-image masks and counts before scoring.
4. Use `score_transfer.py` with the successfully observed verification receipt. It first validates the native population, archived occupancy arm, realized balance and exact paste counts. It then opens the identified author annotations and applies the common COCO evaluator and acquisition-group geometry protocol.

The worker command-line options describe the path inputs and receipts. Capture runs with the checkpoint's qualified CUDA environment. Replay and evaluation use the corresponding CPU-only environment. The original data are available through the [data admission references](../../INSTANCE_RSDD_AUTHOR_FILES_ADMISSION_ACTUAL_20261122.md). This tree contains research source and verified aggregate evidence. Private carrier features, weights and target annotations are obtained separately.

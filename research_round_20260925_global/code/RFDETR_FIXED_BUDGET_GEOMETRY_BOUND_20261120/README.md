# 固定编辑预算的几何上界诊断

本草稿完成标准库合成验证，用于比较同一有效匹配、同一像素支持和已实现 `2k` 编辑预算下的两个几何上界。实际数据接入由原评分结束及既定诊断条件决定。

```python
candidate_oracles(t_add, t_drop, I, P, T, edits,
                  *, add_indices, drop_indices)
```

调用者提供原始交面积 `I`、二值预测面积 `P`、连续目标面积 `T`，以及背景添加和前景删除单元的真实占据与唯一原生像素索引。调用者保留原匹配、源组及种子身份，`edits=2k` 沿用已实现预算。

`O_U` 恰好添加和删除各 `k` 个单元。`O_F` 在相同总数下枚举全部可行添加数，允许面积变化。每个分配取最高添加占据和最低删除占据的前缀，计算

\[
I'=I+\sum t_{add}-\sum t_{drop},\qquad P'=P+a-d,\qquad
J=I'/(P'+T-I').
\]

固定分配时 `J` 随 `I'` 递增，故前缀最优。平衡分配属于面积自由的可行集合，得到 `O_F-O_U >= 0`。输出保留两个最优 IoU、编辑索引、面积变化、差值、两侧支持基数及 `k_zero`。零预算原样返回，正预算要求两侧均可容纳 `k`，负收益仍保持固定编辑数。

容差与既有评分函数对齐，原始及更新交面积允许 `1e-8` 物理残差，单元占据允许 `[0,1+1e-12]`，原始与更新并面积均须为正。所有值原样参与 binary64 计算，不裁剪或舍入。IoU 精确相等时按排序后的不可变编辑像素键确定平局，侧内占据相等亦按像素键排序。

4 项测试通过，用时 0.034 秒。765 个四单元分数占据与预算组合形成 1530 次独立穷举对照。另覆盖固定负收益、面积偏置、零预算、空支持、相邻 binary64 数值、输入重排、容差原值保留及越界拒绝。新增容差测试先 RED 后 GREEN，AST 通过。未导入数值库，未读取实际图像、标注、预测或运行结果。

该量衡量给定支持与预算下的几何可达空间。它不等同于可部署预测器、AP 收益或因果结论，`O_F` 也不是实验中的 `SF` 策略。

Pass the exact PROTOCOL.md from this directory to the capture and scorer. The image-only intake uses the frozen author accession and excludes the 32 earlier scored RGB fingerprints. Keep the author JSON, private images and mask streams in the local research inputs.

The capture uses the admitted source D-FINE E24 EMA and original author CUDA runtime. The CPU writer restores the original source point head. The scorer verifies actual successful process closures, native rank selection and mask areas before reading the target archive. Its reference-code flag points to code/SCHWEGMANN_FROZEN_TRANSFER_20261110. Its intake-source flag takes the intake.py in this directory. Set SAR_SEAL_RUNTIME_ROOT to the private work root for the source paths. Set SCHWEGMANN_DIAGNOSTIC_WORK_ROOT to the directory containing the retained run and receipt folders for readback.py.

The public intake, scorer and readback use portable paths. Historical results retain the exact worker digests for the original runs.

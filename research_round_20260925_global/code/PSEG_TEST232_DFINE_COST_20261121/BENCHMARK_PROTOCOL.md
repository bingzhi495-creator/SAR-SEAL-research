# Frozen D-FINE natural boundary refinement CPU stage

Population is the complete 232-image PSeg-SSDD official test roster in immutable capture order. All top-100 inputs remain in their original ranks. The detector, source HRSID FIT109 head, weights, scaler, native geometry, point occupancy, positive-only independent endpoint policy and write-back follow the closed D-FINE transfer. The benchmark consumes closed predictions, FP32 probability planes and JPEGs, without any labels or new detector calls.

For each image warm up raw and natural once and then perform two measured raw/natural pairs, reversing the order across repetitions and alternating the first arm across successive images. Use the same decoded image, native masks, box/rank audit and in-memory probability planes for every method call. The raw operation returns a new list of the original top-100 row references. Natural starts with the same list, constructs the historical native shape adapter, image features, point neighborhoods, head probabilities, independent endpoint selection and the COCO RLE for each actual edited mask. Only the natural arm is computed. File serialization, startup, past capture, data admission and parity verification are outside the method timers. Preserve exact complete natural records versus the closed production replay for every warm and measured repetition. Any mismatch fails the benchmark.

Report per-image paired natural-minus-raw wall-time mean, median, p95, and aggregate from the mean of two measurements on each image. Also report the two full repetition totals, raw/natural wall-time summaries, process CPU time, staged input timings, method coverage and environment. No runtime-based exclusion. The original archive reports historical detector forward plus postprocessing separately on CUDA. The CPU timing uses one thread per numerical library and shares the Windows host with an unrelated HRSID CPU run. Its current load may change and was not controlled. This tests incremental host cost after the required candidate data is resident. Transfer, detector integration and GPU throughput require separate measurements.

# D-FINE FIT109 free endpoint pairing versus fixed pairing

This training-visible detector FIT follow-up uses the same accepted D-FINE E24 top100 predictions, 109 source groups, 10,900 candidates, 194,640 frozen endpoint pairs, original five source-disjoint point-head folds and exact unchanged independently fitted BCE full gray head. Repeat 200 AdamW steps of 64 pairs per fold with identical initialization, sampling and training features. Require exact original fixed-BCE training audit, AP, geometry, realized edit budget and strict transition replay. All arms keep the original scores/ranks and binary mask area. No new detector model work or input pixels.

On each candidate, rank the same distinct add endpoints by decreasing sigmoid probability and the same distinct drop endpoints by increasing sigmoid probability, ties by original action ordinal. No support is created or discarded before ranking. Pair equal ranked positions. The natural free policy retains strictly positive add-minus-drop marginal gains up to the original cap min(8,floor(P/10),available pairs). For the matched-count comparison, take the original fixed-BCE candidate k and keep precisely the top k free endpoints of both signs, including nonpositive marginal gains if needed. Count such steps separately. This uses the predicted optimal summed utility at that fixed k. The untouched original RLE is used if k is zero. Original fixed pairing and its known oracle remain in scope as readout witnesses.

Before FIT labels, bind the exact original candidate/point receipts and this protocol. Score original stock COCO AP, AP75, AP90 and AR100 for all 10,900 candidates. Evaluate exact continuous source polygons on the same original nonignored stock .50 valid matches, with paired 4,096 source bootstrap and original fold effects. Report realized add/drop counts and edited versus untouched scope for each arm, strict .90 identity losses and new hits, and natural versus matched-count effects separately. Gate only the natural arm: +.50 AP versus raw and +.30 AP versus original fixed policy, +.20 source-equal IoU versus each with lower paired 95% bound above zero, AP75 retained versus raw, and zero loss of original strict .90 matches. No threshold sweep, DEV, official TEST, RD, GPU or new detector forwards/updates. Preserve previous stopped hypotheses.

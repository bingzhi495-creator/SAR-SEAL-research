# D-FINE DEV705 original Windows export owner

This owner covers the fixed image-only export worker and the independently replayed terminal attestation. It reuses the project's published WindowsJob class, whose SHA-256 is 81bac5b6124bbc1b5bb2e401596c5e671485a30f4a5eea5106a8de6662efe9cc. The child begins suspended, is assigned as the sole job process, and resumes only with the original external resource reservation still in force. The child bootstrap verifies the exact exporter bytes immediately before execution.

The actual export is available only after the D-FINE FIT E24 owner naturally closes, independent acceptance binds 24 epochs and 17,640 updates, and the resource custodian gives the evaluation its exclusive reservation. Provide the original reservation JSON and digest plus the sole evaluation reservation key. The reservation records GPU owner active, GPU training inactive, DEV active and FIT, TEST and AP false. The outer owner only reads the existing reservation. It aborts on changes, less than 12 GiB free GPU memory, less than 16 GiB host headroom, a worker tree above 10 GiB RSS, or the 1,800-second wall limit. Use a fresh control path. The export worker writes label-free output under the new control directory.

Run the owner with isolated Python, no bytecode and the `export` command. Its exact args are listed by `export --help`. Use the fixed D-FINE CUDA worker interpreter and the published companion worker and protocol. Keep the exact original outer tool launch and terminal objects in a private JSON object with keys `launch` and `terminal`. The outer success event must name the digests of its actual result and child closure. An exit0 with live descendants is rejected even if the job successfully drains them.

Run `attest` only after the original outer tool returns. Supply the fresh closed control path, the original closure SHA-256, and the exact original outer tool wait file and SHA-256. The attester independently binds outer exit0 and its event to the pinned child result, job wait and log digests. It emits the existing evaluator status HRSID_DFINE_E24_DEV705_EXPORT_OS_CLOSED_V1. Pass that receipt and digest to the evaluator's separate CPU `verify-export` command. The CPU score command waits on that independent readback before reading labels.

The no-data qualification covers actual Windows JobObject handling of natural exit and of an orphaned descendant, rejection of a competing reservation or training state, and rejection of mismatched outer wait evidence. An isolated dummy export also passed the same owner-close and attestation commands with a deliberately synthetic result. The qualification has no model, data, GPU or evaluation output.

Mask AP 评价全部候选。固定匹配按原生掩膜 .50 关联，23 个有船母景等权，139 艘参考实例中 88 艘原生匹配、51 艘各方案 IoU 均计零。原生、动静态、旧学习排序及旧固定配对和独立选点的 AP 系列、IoU、FP 和 FN 均与既有实测逐值复现。

**主要外测门槛未通过。** 相对同头固定分配，自由分配影响了 48 艘原匹配船体、20 个母景，Mask AP 差 −0.139 点，固定 IoU 差 −0.212 点，95% 区间［−0.547，+0.104］。相对静态，AP 为 −0.165、固定 IoU +0.010 点。相对旧独立选点，AP 为 −0.221、固定 IoU +0.022 点，旧独立选点使用另一个预算。相对旧同吸引力预算的学习排序，AP 为 −0.106、固定 IoU +0.239 点，区间跨零。

相对同头固定分配，自由分配平均减少 0.653 个真值面积百分点评价的漏分，增加 1.378 个百分点的船外面积，配对区间分别为［−1.079，−0.328］和［+0.750，+2.067］。去除触边船体后，IoU 差 −0.096［−0.489，+0.263］。自由分配给 6,316 个候选扩大掩膜、3,356 个缩小、721 个面积保持。结果显示已有模型在这个队列上倾向用船外误分换取漏分下降，论文中的增删分配收益应按已验证数据和载体分别报告。

CPU 冻结写回工作体 60.42 秒，独立掩膜读回和评分 18.47 秒。两段实际退出 0 并通过尾签。三项原写回器合成测试在同一运行环境通过。早期闭合输入探针误用只接受无标注阶段的历史校验函数，首次出新结果前已改用原有评分尾签核验。 [盲态写回](render/RESULT_SAFE.json) · [聚合评分与全部对照](score/RESULT_SAFE.json) · [复算入口](reproduce_transfer.py)

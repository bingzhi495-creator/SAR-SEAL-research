# N23 同点训练域对照：批次适配器草稿

状态更新：适配器已随全741图N23真实接入通过；覆盖统计发现Omega零点，须先修共同采样。模型训练和评价仍未执行，不支持AP、机制效用或创新成立。[真实结果](../../N23_REAL_FULLFIT_CACHE_COVERAGE_RESULT_20261017.md)。

## 用途

为后续比较同一残差读出器的两种可编辑训练域准备共享输入：A 为 Omega 门控，B 为完整 C 门控。适配器只保留真实匹配 GT 对应的原采样点、顺序、重复次数、特征、原生 logits、真实目标和重要性权重，分别生成 Omega/C 标记。不重新采样，不增加实例条件特征，不创建或训练模型，不选择损失归一化方案。

Omega 定义为 abs(L) <= 2。C 成员身份来自已核原始缓存写入器的采样域，不能从稀疏 L 猜测。调用方须核验缓存来源和两个写入器源码身份；这些检查不能由合成测试代替。

## 文件与调用

- `dataset_adapter.py`：不含文件读写或模型导入；调用 `build_shared_batches(np, packet, row, expected_cache_binding)`，返回共享批次及覆盖审计信息。
- `test_dataset_adapter.py`：4 项 NumPy 合成测试。未读取真实影像、缓存或权重。

在本目录运行：

```text
python -B -m unittest -v test_dataset_adapter.py
```

依赖 Python 3.8+ 和 NumPy。生产接口接受原始 CPU、无梯度张量；合成 NumPy 数组必须显式指定 `synthetic_only=True`，不能冒充真实接入。

## 合成验证与未决问题

4 项测试覆盖：仅保留真实匹配及原点重复；缺少采样的 GT 只记录而不补造；拒绝若干坐标、身份、域来源及 K 错配；输出数组不改写原始特征/目标，并拒绝生产模式下的数组夹具。

原缓存每图 4096 次有放回采样，包含匹配与背景两层；适配器排除背景负样本，不把空代理目标作为真实 GT。原写入器只采 K>0 且 C 非空的 query，因此缓存不覆盖 K=0。一个真实 GT 也可能没有抽到点，必须保留缺失记录，不能声称监督覆盖完整。

同点并不自动保证公平训练。真实接入后须统计每个匹配实例的 Omega 点覆盖、零可编辑点和权重分布，再锁定损失归一化、更新计数及强参考；避免把 Omega 稀少导致的梯度稀释误作改进。原重要性权重原样返回，不代表其对后续 GT 条件化损失仍已无偏。相同参数、初始化、预算和固定终点都尚未执行验证。

# Locked selective adoption of archived BCE ship-mask edits

This is a repeated source-development experiment on the 183 previously used author TRAIN gate chips in 180 exact decoded groups. All masks, scores, sorted candidate slots, point packets and original static quotas come from the accepted first matched signed-action gate and its archived candidate-balanced BCE head. Exact earlier raw head posterior, native static, learned robust and same-head mean/cell-pessimistic RLEs and old scores remain the anchors. No part of the later action-supervision, contrast or spatial heads enters this replay.

Training of the selective score takes place only on FIT, using group-out-of-fold candidate-balanced BCE predictions of the same form and paired PSeg/SPSD hull targets. The binary adoption decision ranks by the learned signed worst-reference intersection gain estimate against the static edit. The independent margin control ranks by the archived BCE head's own normalized predicted worst-reference signed gain between exactly the same robust proposal and static edit. Both scorers see image-side features only at replay. They use the same number of proposals per image and each proposal keeps its exact original signed area budget.

Eligible proposals are original ranks with positive realized quota k and distinct exact archived robust and static masks. Fix the number of adopted proposals per image to M=floor(n eligible/3). Within each original k stratum, first assign floor(n_k/3), then distribute the remaining M−sum in decreasing remainder n_k mod 3, smaller k breaking ties. Rank separately by each score within the same allocated strata. Break equal scores by increasing original native rank. Zero adoption slots, zero quota, and identical robust/static proposals use static when available or exact native pass-through when no edit exists. Both policies use these fixed quotas without an effect threshold, losing score dependence below a fixed adoption count. Both preserve the same selected count and k histogram per image. No post-score selection, alpha, budget threshold, or quota retuning.

Render holds all 18,300 slots, 8,785 original positive quotas, 57,692 actual additions and 57,692 actual removals per edit arm, and 183 exact image identities. Retain original native, dynamic, static, BCE always-robust, same-head mean and cell pessimistic and, as unchanged controls, all three older action-regressed writer streams. Validate archived scores and signed edit counts exactly and verify policy writes equal either same-slot archived robust or static. The scorer independently checks the render's natural successful terminal, exact bounded scorer and input identities, policy membership and matched quotas before opening either source reference. No detector forward, external test, optimizer operation or additional mask editing is authorized at gate.

Efficacy compares selective to BCE always-robust and specificity compares selective to margin-ranked, separately. Both require at least +0.15 group-equal fixed IoU points with positive paired 95% lower and AP difference ≥−0.10 in both author references, and at least 20 changed shared positive-quota hulls in at least eight groups. Both contrasts must pass, and selective must have positive worst-reference paired mean IoU difference relative to same-head mean and static. Preserve metrics for every archived and new writer whether these criteria pass or fail. COCO AP, AP50, AP75, AP90, APs and AR100 use every slot, original scores and exact native records. Fixed IoU keeps native COCO IoU .50 association and zero for unmatched hulls. Aggregate all 411 PSeg and 410 SPSD author hulls within image, across images per exact decoded group, then equally across groups. Draw 4,096 paired PCG64(5297) group resamples shared across references.

Risk is descriptive and uses exact same-image author pairs matched at reference IoU .50 and identical original native detection, on all eligible common positive-quota hulls. Compute true per-reference signed intersection difference of the eligible robust action versus static, with raw and 2k-normalized minima. Static fallback has zero gain by definition. Report realized group-equal policy risk, paired effects and change exposures, and counts of negative, zero and positive selected gains with adoption denominators. Among shared positive-quota but ineligible hulls report count only. Same-head mean receives benchmark AP/IoU but is not part of the same proposal-adoption risk table. This is a single seed and an exposed source-development cohort, so outcome cannot qualify as independent transfer without external confirmation.

# Paired and independent boundary writes with the same frozen Phoenix scores

## Question and fixed inputs

Test whether releasing geometric pairing still helps when endpoint scores come from the unrelated, pretrained Phoenix XL1 instance refiner. This isolates the writing operator from the learned local occupancy head. Compare the already admitted 74-chip Instance-RSDD reserve on frozen HRSID RF-DETR 5202 with historical 232-image PSeg-SSDD on frozen HRSID D-FINE. Retain the original 42-chip date-separated and 222-image exact-fit-overlap exclusion views as prespecified sensitivities. These are retrospective fixed-carrier comparisons. The two datasets use different carriers and both have prior project evaluation. [Instance-RSDD exact signed comparison](INSTANCE_RSDD_PHOENIX_EQUAL_COUNT_ACTUAL_20261123.md) · [PSeg signed comparison](PSEG232_PHOENIX_BALANCED_RANK_ACTUAL_20261123.md) · [Phoenix authors](https://arxiv.org/abs/2607.29059)

Use the same original narrow native endpoint sets on each sign and the original dynamic spatial-attraction realized quota for each candidate. Preserve 7,346 RF-DETR candidate slots with 4,107 positive quotas and 29,900 additions and removals per arm on Instance-RSDD, and 23,200 D-FINE slots with 11,054 positive quotas and 73,770 additions and removals per arm on PSeg. Reuse exactly 259,242 and 665,634 admitted native endpoint probabilities, respectively. Keep detector boxes, native masks, scores, and candidate order unchanged. No detector or refiner forward, training, hyperparameter or threshold change. Use the already verified previous independent balanced masks as an exact parity target.

## Interventions

For each positive-budget native candidate, enumerate additions and removals in native row-major order for the geometric assignment. Pair them by minimum total squared Euclidean distance, using the same SciPy assignment convention as the local editor. For fixed pairing, rank these pairs by original Phoenix addition probability minus removal probability. Compare exact dyadic differences of the binary32 source values, and resolve equal gains by row-major addition position (the resulting order of assignment rows). Use the top (k) pairs, including nonpositive predicted gains when needed to match the realized quota. For independent selection, use the exact previously accepted top (k) additions and top (k) removals separately. Individual equal posterior values retain the original admitted stored endpoint tie order. Check both masks, exact added and removed counts, native signs, ranks, support and original area before opening any target labels. Include a check that the sum of predicted signed gains under the independent choice is no lower than under the fixed pairing. Record ties, changes and genuine realized edit counts. ## Evaluation and decision

Use the original full-candidate COCO mask AP, AP75, AP90, small AP and AR100, plus continuous polygon IoU, areas normalized by original reference polygon, retained original .50 associations and descriptive independent rematched coverage. Freeze the same original native associations and include unchanged pairs. In Instance-RSDD preserve the original 47 area-eligible hulls from 11 sensor--date blocks and parent-equal weighting. The date-separated sensitivity contains 32 hulls in eight such blocks. In PSeg preserve 293 hulls in 143 decoded-image groups, with 279 in 138 for the deduplicated sensitivity. Use the original 4,096 paired PCG64(5217) cluster draws. The confidence intervals concern fixed hull geometry.

For the independent-minus-paired comparison in each complete cohort, require at least 20 differing original hull masks across at least eight defined groups, at least +0.30 mask AP points and a strictly positive lower paired continuous-IoU bound. The opposite joint condition defines a loss. Apply the same criteria to both sensitivity views. An operator effect across both cohorts requires both complete-cohort positive gates. Otherwise report the scope, effect sizes and failure categories separately. No choice of method after these tests revokes the historical evaluations or the separate blind Umbra protocol.

# DGX 原生 RF-DETR 连续长训四端点实测

训练和评估遵循[连续长训协议](RFDETR_NATIVE_E100_REMOTE_CLOSED_EVAL_PROTOCOL_20261108.md)与[同 DGX 补充协议](RFDETR_NATIVE_E100_DGX_ALT_EVAL_PROTOCOL_20261108.md)。长训在 FIT741、种子 5201、原生 RF-DETR 1.12.0 BF16 下连续完成 74,400 个微批次和 18,600 次 AdamW 更新，实际训练用时 6.15 小时。独立检查验证远端训练子进程 OS wait=0、原进程组闭合、三个归档的原始字节。原本机训练 SSH 会话的退出回执缺失，原执行资格保留该证据缺口。

Windows 首份归档回传留存 69,664,768 字节，未达到完整归档校验。四端点均实际改用预锁的同一 DGX 原生 eager FP32/TF32 路径。首次评估资源预检退出 1，前向未发生。受限资源下的新运行四个子进程均退出 0，原评估 SSH 与 CPU 评分 SSH 均退出 0。验收核对所有归档原始哈希、每端点严格装载 545 个 EMA 张量、完整 187 张图和 380 个整数 GT 实例，以及官方 pycocotools 2.0.11 的全部十二项。独立 E24 的 15,434 个映射预测完整文件与此前同机结果逐字节一致。 [资源记录](RFDETR_NATIVE_E100_DGX_ALT_EVAL_RESOURCE_ADMISSION_20261108.md)

## 热启动控制可行性

对独立闭合 E24 的 CPU 读取显示，28 个 AdamW 组共登记 544 项，543 项保存了第 4,464 步的一阶矩和二阶矩，均有非零量。归档未保存参数名，恢复前还需用固定作者构造和独立模型参数顺序核对位置映射。在线参数与 EMA 在掩膜头上的相对 L2 差约 0.505%，Transformer 约 0.439%，骨干约 0.216%。这些差异仅说明把 EMA 用作在线初始化会同时改动起点。后续若测试 AdamW 状态，应固定在线权和 EMA，避免混入这一因素。 [CPU 安全汇总](results/RFDETR_E24_STATE_BRANCH_FEASIBILITY_SAFE_20261108.json) · [直接先例与作者源码](RFDETR_OPTIMIZER_STATE_PRIMARY_PRIOR_20261108.md)

# Paired single-thread cost of three frozen refinement policies

Use the closed Instance-RSDD 74-image reserve, 7,346 native candidates, the fitted HRSID occupancy head and PointRend adaptation, and the accepted feature planes and writebacks. Measure three standalone paths on the same CPU and locked environment: capped occupancy L with its own natural count, capped PointRend B using the accepted per-candidate count, and whole-RoI PointRend P. Each PointRend path independently runs its own 3,136-points-per-RoI subdivision. B ranks original endpoints and writes exactly the accepted signed count, while P pastes the refined RoI. Hard prefix counts, candidate RLEs and signed changes must agree with the original benchmark shifts after each timing. [Closed accuracy comparison](INSTANCE_RSDD_RESERVE_POINTREND_ACTUAL_20261123.md)

Use resident original native masks and logits, RGB for L, and detached spatial basis for B and P. Timed work includes the applicable native features, support and quota, head evaluation, writeback, and RLE encoding. Record common asset loading and candidate preparation separately. All paths execute in the same process on one CPU thread with one unmeasured first-image warm-up for each. Run the entire roster twice, rotate L/B/P by image and reverse each image's path order in the second pass. Verify full candidate and edit equality outside each timer. Publish per-pass totals and image mean, median and 90th-percentile times with scope and hardware. This is an input-resident CPU refinement comparison; separate detector forward, feature capture, transfer, models' loading, and asset I/O costs are outside the primary clocks. B's budget is supplied from the closed policy. Its work time therefore excludes determining that budget with an occupancy head.

# UNet++ 模块内部改动与实际连接的补充确认

日期：2026-10-17。回应用户“UNet++ 里面的模块我是调整了的，你看到了吗”。本次重新只读核对 D:/SAR/UNet++ 中未受当前实验绑定的 model_full.py、archive/old_code/root_legacy_models/model_new1.py 和 model_sampling_boundary.py；不执行模型、不加载权重、不改变原文件。以下行号来自本次所读文件。

## 确实存在模块内部改动

`model_full.py:86–121` 的 `CBAM_block` 是复合卷积残差块：两层卷积及 BN，中间 ReLU；随后依次做通道、空间注意力，与原输入或投影 shortcut 相加，再 ReLU，最后返回 `out + SimAM(out)`。SimAM 实现在该文件140–164行。因此应同时评价卷积变换、残差保留、两种注意力的组合顺序和最后的增强支路。

令 C 表示这段卷积变换，A 表示通道后接空间注意力，P 表示恒等或投影 shortcut，则实际连接可概括为 z = ReLU(A(C(x)) + P(x))，输出 z + SimAM(z)。这是本地代码关系的还原，不是已经验证的作用机制。

作者[原始 CBAM 代码](https://github.com/Jongchan/attention-module/blob/master/MODELS/cbam.py)的 CBAM.forward 为通道后接空间门控；[SimAM 原论文](https://proceedings.mlr.press/v139/yang21o.html)提供已有无参数注意力机制。应如实引用这些基础方法，同时单独评价本项目自行确定的复合块、放置尺度和连接组织。已知基础算子不能单独否定整体设计贡献，也不能据组合本身判定首创。

`model_full.py:239–271` 的 `CBAM_block_up` 与编码块不同，没有最后的 SimAM 支路。本轮再次逐行跟踪发现，261–262行虽执行 `out = bn1(x); out = relu(out)`，263行却是 `out = conv1(x)`，重新使用原输入。因此前置 BN/ReLU 的计算结果没有进入后续输出；实际有效主支是 `conv1(x) → bn2 → ReLU → conv2 → 通道/空间门控`，再加 shortcut 并 ReLU。此前把它概括为已经生效的前置 BN/ReLU 不准确，在此纠正。训练模式下 bn1 的运行统计仍可能更新且增加计算，不能简单称整个模块未执行。

## 改动与网络组织确实相连

| 位置 | 实际有效路径 | 已确认的设计含义与边界 |
| --- | --- | --- |
| `model_full.py:401–413` | H/4 的 CBAM/可选 encoder_x2 支路，与独立普通卷积输入的 x/y DSConv 支路拼接，经 con2 融合 | 在特定尺度组织语义与方向分支；实际作用和启用 Transformer 的历史权重身份仍需验证 |
| `model_full.py:435–463` | 较低分辨率的六个解码节点用 CBAM_block_up；最高分辨率嵌套节点用普通卷积 | 编解码模块及不同分辨率之间采用不同处理规则；不能只按模块数量评价 |
| `model_new1.py:329,340,351,362,365–398` | 生成经 CBAM 的 up_x 副本，先门控再上采样；原节点保留在继续编码或同尺度稠密连接中，按尺度共享门控 | 可讨论跨尺度传输与本地表示的分工；最浅 x_0_0 本身也经过 CBAM，不能泛称整个网络原始特征均不经门控 |
| `model_sampling_boundary.py:21–59,117–144` | 实际 BlurPool 下采样、双线性上采样加门控细节残差，并参与最终返回 | 这是有效的采样/重建路径；与 full 中未消费的 BlurPool 结果须区分 |

若原意是让解码块采用前置归一化，最小修正候选是在独立研究副本中让 `conv1` 接收上述 `out`。本次没有修改原模型或历史权重，也未运行该修复。后续应先验证实际数据流和梯度，再在同初始化、同预算下单独比较原实现与修正版；不能据此追认旧结果无效，更不能预先声称修复必然涨点。该问题也不影响对编码复合块、方向分支与跨尺度副本连接确实存在的确认。

仍有定义或计算但未进入输出的内容：`model_full.py:65` 的 `max = self.pool(x)` 没有参与返回的注意力；CBAM_block 构造的 self.pool 也未在其 forward 使用；encoder_x4 没有实际 forward 调用。这些不能计入已生效的机制。这里只指出连接事实，不自动认定历史实验失效。

## 评价应进一步细化到所改模块

值得优先保留的是“复合残差注意力块 + 特定尺度方向融合 + 分层解码”的整体假设，以及 model_new1 的跨尺度副本传输设计。模块内部调整和整体连接都有具体内容，应给予明确承认。

最后的 z + SimAM(z) 同时改变幅值。按本地 SimAM 公式，在空间元素多于1、正常有限输入及正 e_lambda 的条件下，它等价于逐元素 (1 + sigmoid(s))z，且 s≥0.5。因此仅看到收益不能自动归因于选择性建模，应加入固定增益或适当归一化的替代对照，区分幅值作用与空间变化的作用。该结论是源码代数分析，没有执行数值或观察到真实增益。

后续最小模块对照应保持相同骨架、数据、初始化、训练长度及评价：普通残差卷积块、残差卷积+CBAM、残差卷积+SimAM、当前完整组合；需要时加固定增益对照。再单独比较 up_x 门控位置及 H/4 方向分支。一次只锁定一个主要假设，先完成有意义的公平训练，不将所有候选合并后追逐开发集。

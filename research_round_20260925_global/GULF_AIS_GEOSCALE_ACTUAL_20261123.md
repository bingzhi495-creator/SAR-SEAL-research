# SAR Ship Gulf 固定船体关联的地理尺度与航向诊断

在已经闭合的 25 艘共同可测样本上，固定候选、八连通分量、编辑量和名义栅格主轴。将像元角点 从原 VV 产品地理定位格网映射到 WGS84 后，原生表观船长平均偏差从 **+105.42 米**变为 **+107.05 米**。采用真实地理尺度未消除高估。在航向可用的 23 艘子集上，沿 AIS 航向投影较地理栅格主轴降低 **7.60 米 MAE**，配对 95% 区间 **[1.88, 14.89] 米**，原生表观长度平均仍高出 AIS 声明 **71.27 米**。[诊断方案](GULF_AIS_GEOSCALE_DIAGNOSTIC_LOCK_20261123.md) · [原物理实测](GULF_AIS_FROZEN_ACTUAL_20261123.md) · [复现入口](code/GULF_AIS_GEOSCALE_20261123/README.md)

## 同一关联的空间对照

复用原 25 艘、19 个轨道日期组、20 个源景和相同 23 个有正固定预算的船体。原生掩膜和两条等量策略及自然独立选点的旧误差、组配对区间与推进条件先逐项复现。新的地理换算使用从源注释网格双线性插值的全像元角点。原始轴用裁块中心的列、行方向映射为同一个真实方向。各策略使用同批分量，地理坐标、原像元坐标、已记录的真航向都不改变关联身份或写回。像元中心按 ESA 产品定义的零基原始索引，角点相对于像元中心 ±0.5。[ESA 产品规范表 6-91](https://sentiwiki.copernicus.eu/__attachments/1673968/S1-RS-MDA-52-7441-Sentinel-1-Product-Specification-2025-3.16.3.pdf)

所有误差均按原轨道日期组等权，配对区间用 4,096 次组重采样。25 艘地理换算使原生 MAE **增加 1.335 米**，区间 [0.647, 2.056] 米。局部地理尺度的平均列、行步长分别为 10.000、10.154 米，原生主轴的等效尺度为 10.076 米/像元。航向分析保留 23 艘完全相同的样本。两条轴的绝对方向差中位数 6.42°、最大 87.78°。作者的 0 航向值可能代表缺失，本轮按预先声明的条件排除航向不可用的两艘，仅影响航向子集。航向改投影的 MAE 降低量仅用于这 23 艘的事后敏感性检查。等量编辑的地理主轴和 AIS 航向版本都未建立稳定物理收益。[AIS 真航向字段](https://www.navcen.uscg.gov/ais-class-a-reports)

## 裁块中心和时间代理

用公开 VV XML 的定位节点重做作者未缩放二次拟合。25 艘的经纬度经整数截断都返回原归档裁块中心行列。源 XML 前向地理定位的裁块中心与同一 AIS 报告点的距离中位数 9.80 米、最大 17.36 米。这是对作者裁块定位的内部一致性核验。AIS 点也用于原图裁切，回波与船舶的关联仍受雷达定位和 AIS 报告误差影响。[作者裁块代码](https://github.com/mousashaya/sar-atr-study/blob/31387b3f2dbda1a05ca30e48ba5742add5463564/scripts/chip_ships_gulf.py)

源 XML 插值得到的零多普勒图像时刻相对场景中点偏移 −12.67 至 +10.79 秒。AIS 报告时差只有绝对值，两种时间方向分别对应两端距离代理。以已记录 SOG 恒速计算，较大的可能距离代理最大为 48.01 米，原共同样本无人超过 50 米。25 艘中有 14 艘的 SOG 字段为零，作者缺失值也写成零。这一核验只量化日志记录支持的时间不一致程度，实际回波位置仍可能受运动目标多普勒偏移和天线参考点影响。[NOAA AIS 时间与数据说明](https://coast.noaa.gov/data/marinecadastre/ais/faq.pdf) · [Sentinel-1 雷达表观定位](https://www.mdpi.com/2072-4292/9/3/246)

## 证据范围

同一 25 艘的结果显示，更换为地理尺度只使 MAE 增加 1.335 米，影响量级远小于原偏差。使用航向后，同子集保留 71.27 米的平均表观长度偏差。大幅高估的具体来源仍未分离。上一轮在独立新采集中的预锁物理判据原样保留。这轮为闭合队列的解释性对照，复用了原冻结权重和输出，新增检测或优化更新均为零。实际诊断约 5.50 秒，退出码和输出摘要核验通过。[聚合结果与观察回执](results/GULF_AIS_GEOSCALE_ACTUAL_SAFE_20261123.json)

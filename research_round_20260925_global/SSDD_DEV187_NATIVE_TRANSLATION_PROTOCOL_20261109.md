# SSDD DEV187 历史原生掩膜的平移诊断

在读取 SSDD 实例掩膜前锁定。对已闭合的 RF-DETR Seg Nano 原生 E24 EMA 历史端点执行 HRSID DEV705 已验证的同一几何诊断。使用原整数栅格 GT 的 187 个逻辑图和 380 个实例，候选为已封存原生 top100 的 15,434 条船舶映射，其中 5,180 条为空。保留原图尺寸、分数及行顺序。CPU 仅使用旧预测与原 GT。两套数据都属于项目已接触的内部 DEV。 [SSDD 历史端点](RFDETR_E24_DEV187_ACTUAL_EVALUATION_20261107.md) · [HRSID 诊断](HRSID_DEV705_NATIVE_TRANSLATION_PROTOCOL_20261109.md)

在原画布复算 0.50、0.75、0.90 的候选覆盖，核对旧 SSDD 独立覆盖 377、351、103。对实际已映射候选以 0.75 贪心一对一配对，并列取原 GT 顺序靠后者，与 HRSID 相同。主队列为冻结配对中没有任何 0.90 候选的目标，实际分母以配对复算为准。保留已配对且有 0.90 候选的对照。该分配与旧 SSDD 的 0.50 配对单列。

沿用原 COCO 面积小于 1,024、主轴比至少 3 和三段初始 IoU 分层。无裁剪整数平移在原图网格逐对计算，报告两轴半径一和二的真值辅助上限、面积比限制、固定上移及下移一像素的新增和失守数、原始质心与像素 FP/FN。越界固定动作维持原样并单列。比较方向时单列两库的上移净值、下移净值与原始平均纵向偏差。直接并列各初始 IoU 分层，避免把基线离门槛的距离当作形状效应。SSDD 保留 187 个逻辑位置及已有 183 个不同 JPEG 字节组这一事实，本次仅报告描述性分层，缺少可与 HRSID 场景代理相同的组间推断单位。 [SSDD 候选覆盖](RFDETR_DGX_FOUR_ENDPOINTS_GEOMETRY_ACTUAL_20261108.md)

该比较使用两套各自训练的旧基线。SSDD 与 HRSID 的更新数、查询宽度、原图像素尺度和标注来源均不同，结果用于界定历史误差的共同点与差异。旧 SSDD 已有基于局部像素编辑的上限分析。本实验比较的是同一固定候选的整掩膜平移和面积条件，AP、官方 TEST 和当前训练掩膜 A/B 均不参与。 [SSDD 局部编辑](RFDETR_E24_SIGNED_EDIT_ORACLE_ACTUAL_20261107.md)

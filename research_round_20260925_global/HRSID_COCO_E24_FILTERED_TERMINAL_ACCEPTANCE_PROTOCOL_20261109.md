# HRSID 原训练 E24 的独立终止与端点验收

本验收独立于原训练和 DEV705 评分。先核对原所有者和工作进程确实结束、系统等待及原退出码、资源保护状态和原日志摘要。此后才读取训练产物。真实运行结果和日志须逐项一致，训练数据清单由已独立核验的 FIT-only 输入取得。 [修复训练记录](HRSID_COCO_E24_TARGET_GUARD_RECOVERY_PROTOCOL_20261109.md)

独立复核 24 轮访问账本和增强后空掩膜过滤事件的图像与批次对应。每轮 2,940 次访问覆盖固定 2,937 图及原补齐样本，实际 AdamW 与 EMA 每轮均为 735 次。逐个读取 E1、E8、E24 三个闭合档案，校验稳定文件身份、字节摘要、保存的优化器和学习率时钟、EMA 计数、原生模型张量与初始化来源。独立读取只在 CPU 上使用限制加载方式，原档案保持原样。

验收通过才生成固定 DEV705 入口使用的精确桥接回执。后续另由原图预测导出和独立 CPU 评分生成指标，真实 TEST 继续隔离。七项合成测试检查终止前拒读、日志和训练结果不完整、过滤身份错配、EMA 计数和模型数据异常，以及精确桥接格式。当前实际端点验收等待原训练正常退出。 [验收源码](code/HRSID_COCO_E24_FILTERED_TERMINAL_ACCEPTANCE_20261109/acceptance.py) · [固定 DEV705 评分](HRSID_COCO_E24_DEV705_NATIVE_EVALUATION_PROTOCOL_20261109.md)

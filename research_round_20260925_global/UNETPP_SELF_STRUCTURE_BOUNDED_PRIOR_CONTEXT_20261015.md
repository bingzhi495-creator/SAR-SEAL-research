# UNet++ 自主结构的有界先例语境（2026-10-15，有界研究记录）

**结论先行。**“自主设计”可准确指作者自行确定模块放置和信息路由；它不自动等于学术上的首创。按 ROOT 提供的结构摘要，`model_new1` 的可讨论特征是**仅对跨尺度上采样传输支路 `up_x` 使用 CBAM，而原 `x` 保持继续下采样及同尺度稠密连接**。这与原始 UNet++ 不加注意力、Attention U-Net 过滤编码侧 skip 的典型路由有具体区别。但 CBAM、稠密嵌套跳连、注意力门控、保留高分辨率细节均有直接先例；有界检索不能判定该精确路由首创，也没有本轮效果证据。

## 对两种本地结构的准确表述

- `model_new1`：按 ROOT 给出的源码摘要，原 `x` 仍通往下一编码层和同尺度稠密连接，仅 `up_x` 跨尺度传输经 CBAM 后参与融合。由此可提出**位置与路由差异**：注意力优先调制粗语义进入细尺度的通道，而不是先抑制原高分辨率编码特征。这个叙述仍是设计意图/可证伪假说；本轮未读本地源码、图或输出，不能宣称它实际保存细节、更好分割边界或比 Attention U-Net 新颖。
- `full`：按 ROOT 摘要，它保留原生 UNet++ dense-concat 主拓扑，另有 H/4 语义模块、可选 BatchFormer、`x/y` 方向双路融合、编码与部分解码注意力、CoordConv。它可以是自主完成的复合架构，但各部件的存在不构成多项独立创新；本轮没有逐个核它们的一手原文，也未审开关是否实际启用。论文应画出**实际运行配置**的计算图，分清 `model_new1` 与 `full`，勿把前者的单支门控结论自动外推后者。

## 如果要把“整体路由设计”作为贡献候选

最小可否定对照应在同一 UNet++ 骨架、数据划分、初始化、损失、训练轮数/算量与评估规则下比较：无门控；同类 CBAM 放在原 `x` 跳连；仅放 `up_x`；必要时放在拼接后或两支。记录参数、计算量和多随机种子，并具体看高分辨率/边界/小目标错误，而非只报单一总分。若相同容量的常规 skip 门控或简单位置替换达到同等效果，贡献应降为架构实现与任务适配；若 `up_x` 路由在预设条件下稳定优于这些强替代，才可讨论其**有证据支持的设计效用**，仍需更完整查新才可判断新颖性。`full` 的其他模块应另做增量/交互消融，不能由 `model_new1` 的对照替代。

**核查边界。**本轮 4 条检索，成功读取 UNet++、Attention U-Net、CBAM、Han-Net 原文；ANU-Net 仅取得出版社索引摘要（正文拒绝访问）。PMC 原始 UNet++ 镜像及另一近作出版页也不可读，未用其判断精确同构。`model_new1`/`full` 的结构均来自 ROOT 提供的摘要，不是本轮源码复核。未读取活动 E 链、模型、权重或数据；未训练、未运行科学程序、未改其他产物或 Git。该有界检索不能证明“首次提出”或 TGRS 水平。

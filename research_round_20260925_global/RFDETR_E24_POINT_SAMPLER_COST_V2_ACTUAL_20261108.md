# RF-DETR 分层采样 V2 前反向成本实测

在 8 张固定 FIT 图、16 组配对测量中，原生 A、均匀 BCE B 和面积校正分层 D 均执行了 BF16 前向、逐层匹配和反传。B、D 与 A 的五层原生 Dice 完全一致，最大绝对差为 0，模型梯度均为有限值。测试未执行优化器更新。 [预锁协议](RFDETR_E24_POINT_SAMPLER_FULL_STEP_COST_PROTOCOL_20261108.md)

| 臂 | 前反向中位数 | 损失计算段中位数 | 峰值分配显存中位数 |
| --- | ---: | ---: | ---: |
| A 原生 | 130.19 ms | 42.55 ms | 1.33 GiB |
| B 均匀 | 137.74 ms | 45.98 ms | 1.33 GiB |
| D 分层 | 151.84 ms | 58.56 ms | 1.33 GiB |

D/B 的 16 个配对时延比中位数为 1.10255，超过预锁上限 1.10。原进程正常退出，独立复算中位数、Dice 差和停止判断一致。按该实现的预锁结果不进入配对训练。测量覆盖加载之后的模型计算，含用于分段的 CUDA 同步。数据加载与优化器成本另行测量。

V2 已把边界缓存到每个唯一目标，但重复匹配仍逐行发出随机抽样、索引和赋权操作。下一版本按唯一目标对这些行批量独立抽样，再恢复原匹配顺序。用新版本重新预锁并保持原测试输入、点数、风险、时延门槛和失败记录。 [安全聚合结果](results/RFDETR_E24_POINT_SAMPLER_COST_V2_SAFE_20261108.json)

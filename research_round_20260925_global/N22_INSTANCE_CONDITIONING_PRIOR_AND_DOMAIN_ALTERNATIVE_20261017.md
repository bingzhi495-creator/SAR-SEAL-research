## 项目已有工作与重复风险

- **直接拼接e已经实际执行。** [N07固定8轮结果](../docs/N07_fixed8_fullDEV_point_refinement_result_20261012.md)的C读取F/e/L；[N10公平比较](N10_FULLDEV_STATUS_20261013.md)中，C与PR采用同一冻结教师、配对初始化、采样和8轮预算，C−PR两个下游种子为+0.1250985/+0.3524163 AP点，均值+0.2387574，未达到当时预锁的均值至少+0.30继续条件。它不证明充分训练后总体无效，也不能被改名当作新方法。不得把旧C的8轮结果与当前PR的24轮结果直接比较机制优劣。
- **F⊙e未找到已执行证据。** [既有机制备忘](C_CONDITIONED_POINT_HEAD_NOVELTY_MEMO_20261013.md)第32行明确当时C没有新增逐通道乘积通路；原生L本来就来自实例embedding与空间特征的点积。因此，PR残差支路未显式读取e，不等于整个模型没有实例条件。这里的“未找到”仅限本次定点核查，不是全历史不存在的证明。
- **全动态实例点函数已有设计，未找到实际训练结果。** [既有控制方案](FAIR_POINT_HEAD_CONTROL_DESIGN_20261013.md)第83–93行设计了IPR-e-dynamic，由e生成完整点MLP权重；参数生成器约640万参数，其成本不能遗漏。该文档是设计证据，不是运行或效用证据。

## N22待测诊断与最少必要强对照

FP落在其他真实船舶或纯背景、Omega内或外的分层，**已加入锁定的待测诊断**；目前没有真实结果，不预判哪一层主导。固定配对几何机会仍不能替代全自然query的COCO AP或跨数据集证据。

即使ideal-C oracle与固定PR oracle存在较大差距，也不能直接归因于实例身份不足。此前“当前PR仅Omega监督”的说法不够准确，现区分：

- **采样及标签域不是仅Omega。** [N13已发布协议](../refine-logs/N13_SAMEK_PR_20261013_01/EXPERIMENT_PLAN_20261013.md)明确每GT为768个区域内点加256个共同全域均匀点；K=0时为全域均匀1024点。不能把带外点不存在作为事实。[训练汇总](N13_FIXED48_TRAINING_QUALIFIED_RESULT_20261013.md)也区分全部监督点与可编辑点。
- **对残差u有效的梯度域需要另论。** 同一协议规定LOG支持为|L|≤2，训练使用L'=L+editable_flag×u。按该公式，editable_flag=0处的BCE对u梯度为0；带外点可进入整体损失统计，却不直接训练该残差。这是协议所支持的数学推论，不是“没有带外采样”。
- **当前权重对应关系仍有核验边界。** 本轮仅核已发布普通文档，未在N22运行中读取绑定训练源码、checkpoint或资格链，未重新核实当前固定端点的实际门控对应。因此，将“Omega外有效残差监督不足”保留为待核的条件解释，不写成针对当前权重新验证的事实；低分辨率特征缺细节、容量与优化也仍是替代解释。

若诊断支持继续检验修正能力，先在相同full-C训练域、采样、监督和预算下比较普通PR、旧C与一个候选条件头，保持评价C/K、原query和S0一致。若检验有效监督域，必须统一各臂残差门控与采样变化；仅添加带外点而仍将u门控为零，不等于给残差增加带外监督。不得只给新条件头扩大训练域。普通PR若已解释收益，应收缩条件机制主张；候选若不能胜过旧C，也不能把“加入实例信息”作为新贡献。效用得到支持后，再补较强的动态点函数适配，完整计算参数生成器及推理成本；不要以极窄动态头代替完整强先例。

仅当“其他实例泄漏”得到真实证据支持时，才进一步考虑预测竞争query的相对条件；竞争对象必须由预测选择，GT仅供离线诊断。这仍是未查清、未执行的候选方向，不能据此宣称创新、SOTA或TGRS投稿条件已成立。N20原停止决定保持。


## N22真实诊断完成后的独立结论边界

本节为后续更新；上文“尚无真实结果”是本节形成前的历史状态。N22采集及独立CPU已实际正常结束并经Root接收；本节只复核已完成的小JSON，不重载模型或张量，不改写原报告中的pending标记。条件机会存在得到支持（claim_supported: partial）；“修正头是主瓶颈”“实例竞争机制成立”“新方法已有收益”均不受支持。本轮没有完成指定Codex MCP复审或完整实验诚信审计，标记[pending Codex review]，不以此阻断下一项定点研究。

32张独立选定FIT图采集全部3200个自然query；实例IoU诊断实际只覆盖53个原matcher真实GT配对，另外3147个未分配query不冒充真实背景。此样本无未配GT，实际也没有原生IoU=0配对；这是样本事实，不是事后按IoU筛选，但不能提供低IoU配对的实证结论。R是同一次full-C PR实际动作限制在Omega的结果，不是历史S-only前向或完整AP复现。

| 条件固定配对方法 | 平均IoU |
| --- | ---: |
| native | 0.902233441043 |
| R | 0.913613659039 |
| 固定PR有益动作oracle（P） | 0.936569266811 |
| 理想C内错误翻转oracle（G） | 0.961579981806 |

路由机会P−R均值为0.022955607772，修正动作机会G−P为0.025010714995；但固定0.50至0.95十阈值的向上跨越总数为22对20，0.95处为12对10，方向排序相反。跨越总数允许同一配对被多个阈值重复计数，不能当作不同实例数或AP。按已锁冲突规则，先做定点case，不能因平均差距略大就选择“头主导”解释。

仅用已接收的逐配对有理数，可确定6个“逐对IoU差距排序与阈值跨越排序相反”的案例：313:1:621、467:26:831、46:1:61、187:1:426、264:1:566、703:98:1430。前5例是R→P跨0.95，而更大的P→G增量不再跨阈值；末例R→P从0.924460到0.949275不跨0.95，P→G到0.967153才跨。应按该规则审阅全部6例的空间错误、阈值边距、K与修复/伤害位置，不能挑最好看的一例解释总体。

Omega外原生错误2489/3850，实际PR有益动作694、有害动作1007，说明有必要检查有效学习域与动作伤害；这些聚合像素数不能直接证明带外编辑无效，更不是AP贡献分解。落入其他真实船舶的FP仅50/2142，当前样本不支持把实例间泄漏指定为主要问题。C包含原生前景，FP被C覆盖部分是定义所致，不能包装成新的覆盖能力。

最少下一步是完成上述冲突case，再选择一条假设。若案例支持联合学习选择与残差，应以固定C/K、输入、采样、共同监督和预算，保留“二者冻结、仅学习选择、仅学习残差、联合学习”的最小比较；明确训练松弛与推理硬选择的区别及实际成本。只换选择器会重复N16路径；只堆邻域scout会重复N20路径；只加e则重复旧C。N16/N20原停止决定保持，不因这次oracle机会自动重开原配方。

### 联合学习及IoU监督：四项补充直接先例

- [PointRend，CVPR 2020原论文](https://arxiv.org/abs/1912.08193)已有不确定选点、点预测及逐级细化流程；这不等于可学习硬top-K联合优化，但不能把选点加修正的流程本身当新颖。
- [MagNet / Progressive Semantic Segmentation，CVPR 2021原论文](https://arxiv.org/abs/2104.03778)已有多尺度渐进精修与按预测不确定性选点。项目N16已有同协议MagNet式控制，不能通过改名忽略该强对照；作者完整系统与项目适配仍需区分。
- [Lovasz-Softmax，CVPR 2018原论文](https://openaccess.thecvf.com/content_cvpr_2018/html/Berman_The_LovaSz-Softmax_Loss_CVPR_2018_paper.html)直接研究IoU优化的可微替代；加入IoU任务损失本身不是新机制，也不自动保持离散编辑K。
- [DPMO-RPS，2026年8月9日v2原预印本](https://arxiv.org/html/2604.01742v2)的Method及式4明确以候选mask与GT的IoU作选点奖励，并描述联合优化点选择与实例mask预测。其K=5是提示候选数、最后选1，不是本项目像素编辑预算；它也不是冻结载体上的同C/K残差纠错。因此“按下游IoU学选点”“联合选点和掩膜学习”已有直接先例，不能泛称首次。

本轮未证明已经存在与拟议“同C/K像素残差联合学习”完全相同的系统，也未证明该组合新颖。只有案例必要性、具体运算差异、强控制、真实AP、重复及跨集证据形成后，才可讨论贡献。当前数值均为固定配对几何诊断，没有新训练或新方法AP，不等于SOTA或TGRS发表依据。

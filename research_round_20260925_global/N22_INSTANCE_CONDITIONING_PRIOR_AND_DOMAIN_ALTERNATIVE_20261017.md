# N22实例条件修正：直接先例与训练域替代解释

2026-10-17。定向文献及已发布项目记录核查；不是完整查新认证或作者系统复现。**N22真实采集尚未开始，尚无已核验的真实机会统计、AP或新方法结论。** “当前固定PR的实例条件可能不足”仅是候选解释，不能预先写成模型瓶颈。

## 项目已有工作与重复风险

- **直接拼接e已经实际执行。** [N07固定8轮结果](../docs/N07_fixed8_fullDEV_point_refinement_result_20261012.md)的C读取F/e/L；[N10公平比较](N10_FULLDEV_STATUS_20261013.md)中，C与PR采用同一冻结教师、配对初始化、采样和8轮预算，C−PR两个下游种子为+0.1250985/+0.3524163 AP点，均值+0.2387574，未达到当时预锁的均值至少+0.30继续条件。它不证明充分训练后总体无效，也不能被改名当作新方法。不得把旧C的8轮结果与当前PR的24轮结果直接比较机制优劣。
- **F⊙e未找到已执行证据。** [既有机制备忘](C_CONDITIONED_POINT_HEAD_NOVELTY_MEMO_20261013.md)第32行明确当时C没有新增逐通道乘积通路；原生L本来就来自实例embedding与空间特征的点积。因此，PR残差支路未显式读取e，不等于整个模型没有实例条件。这里的“未找到”仅限本次定点核查，不是全历史不存在的证明。
- **全动态实例点函数已有设计，未找到实际训练结果。** [既有控制方案](FAIR_POINT_HEAD_CONTROL_DESIGN_20261013.md)第83–93行设计了IPR-e-dynamic，由e生成完整点MLP权重；参数生成器约640万参数，其成本不能遗漏。该文档是设计证据，不是运行或效用证据。

## 六个直接来源与技术边界

| 原始来源 | 与本问题直接相关的机制 | 当前设计必须承认的边界 |
| --- | --- | --- |
| [CondInst，ECCV 2020原论文](https://arxiv.org/html/2003.05664v3) | 实例动态卷积与相对坐标；原文讨论相似实例之间的区分 | 实例动态投影不是新原语；需要证明具体新设计相对该类条件函数的必要性 |
| [PointRend / Implicit PointRend作者点头代码](https://raw.githubusercontent.com/facebookresearch/detectron2/main/projects/PointRend/point_rend/point_head.py) | StandardPointHead读取细粒度特征与coarse预测；ImplicitPointHead接收每实例完整W/b，并支持位置编码 | 共享点MLP和动态实例点函数均有直接先例；项目固定带残差适配不等于作者完整系统复现 |
| [RefineMask，CVPR 2021原论文](https://arxiv.org/abs/2104.08569) | 分阶段融合细粒度信息进行实例掩膜精修 | 将原生低分辨率F插值到原图，不等于取得新的细节信息；本轮使用原摘要支持该机制概述 |
| [QueryInst，ICCV 2021原论文](https://arxiv.org/abs/2105.01928) | 动态mask heads及并行监督，利用query与mask RoI特征的对应 | 不能笼统主张首次使用query驱动实例掩膜建模；本轮核对原摘要与会议记录 |
| [MaskDINO作者解码器](https://raw.githubusercontent.com/IDEA-Research/MaskDINO/main/maskdino/modeling/transformer_decoder/maskdino_decoder.py) | forward_prediction_heads第463–470行由query产生mask embedding，再与空间特征点积 | 现有查询式载体已经具有实例条件掩膜；加入额外条件分支必须明确新增信息或运算 |
| [SAMRefiner，ICLR 2025原论文记录](https://arxiv.org/abs/2502.06756) | 从粗掩膜生成距离点、上下文框和高斯式mask提示；另有IoU适配版本 | 冻结模型外接实例提示精修已有先例；额外基础模型和适配成本不能隐藏；本轮机制概述由原摘要支持 |

检索也覆盖2024–2026及近六个月的相关表述，但没有据此声称穷尽最新研究，或声称不存在其他直接先例。简单拼接e、逐通道乘积、FiLM或低秩动态投影均不能仅凭形式命名为核心创新。

## N22待测诊断与最少必要强对照

FP落在其他真实船舶或纯背景、Omega内或外的分层，**已加入锁定的待测诊断**；目前没有真实结果，不预判哪一层主导。固定配对几何机会仍不能替代全自然query的COCO AP或跨数据集证据。

即使ideal-C oracle与固定PR oracle存在较大差距，也不能直接归因于实例身份不足。当前PR原监督域是Omega，带外失效可能来自训练分布不覆盖；低分辨率特征缺细节、容量与优化也仍是替代解释。

若诊断支持继续检验修正能力，先在相同full-C训练域、采样、监督和预算下比较普通PR、旧C与一个候选条件头，保持评价C/K、原query和S0一致。不得只给新条件头扩大训练域。普通PR若已解释收益，应收缩条件机制主张；候选若不能胜过旧C，也不能把“加入实例信息”作为新贡献。效用得到支持后，再补较强的动态点函数适配，完整计算参数生成器及推理成本；不要以极窄动态头代替完整强先例。

仅当“其他实例泄漏”得到真实证据支持时，才进一步考虑预测竞争query的相对条件；竞争对象必须由预测选择，GT仅供离线诊断。这仍是未查清、未执行的候选方向，不能据此宣称创新、SOTA或TGRS投稿条件已成立。N20原停止决定保持。
